## 0. 族通用说明（本族其他页面不再重复）

### 0.1 这个族解决什么问题

买家从「想进货」到「看到具体商品」的最短路径：逛市场 → 筛/搜 → 看详情 → 加进货单或下单/拼单。

不做会怎样：买家只能在首页推荐里点，找不到品类、找不到同款、看到价格不知道能不能拼单，最后转去 1688。

### 0.2 角色与权限

| 角色 | 能看 | 能操作 | 越权表现 |
|---|---|---|---|
| 游客（未登录） | 市场/列表/详情全部可浏览 | 浏览、搜索、筛选、看评价 | 收藏/加进货单/询价/下单 → 原型**不拦**（缺口，附录 A-3） |
| 登录买家 | 同上 | 全部 | — |
| 会员 / 认证买家 | 同上 | 同上（会员价未接入，本期无差异） | — |
| 商户账号（同一账号体系） | 同上 | 同上（买家视角不区分身份） | — |

> **本期原型无登录墙**：所有写操作（收藏、加进货单、立即下单、发起拼单、询价）均可直接点。这是**有意简化**，不是遗漏；接口期统一在提交时校验登录态。

### 0.3 端间落点

| 维度 | 运营管理端 | 商户端 | 买家端（本族） |

| 商品 / 品牌 | 商城运营维护商品、品牌馆、上架/下架 | 商户维护本店商品 | 只读展示，下架不展示 |

### 0.4 核心数据对象

| 对象 | 关键字段 | 谁产生 | 谁消费 |
|---|---|---|---|
| 商品 `item` | `itemId`、标题、主图、单价、起批量、库存、已售、评分、标签、店铺、阶梯价、是否支持拼单 | 运营端 / 商户端 | 本族全部页面 |
| 阶梯价 `tier` | `min`（起量）、`price`（单价） | 运营端 / 商户端 | 详情页、规格弹层 |
| 商铺 `shop` | `code`、名称、楼层、区域、主营、评分、累计单量、营业状态 | 运营端 | 市场导览 |

| 拼单下限 | 团长与参团人下单均 ≥ **起批量 × 20%**（本商品 100 → 20），与所选档位无关（M01 BR-2a） | 端上计算 | 详情页拼单 |

### 0.5 状态机

| 对象 | 状态 | 转换 | 禁止路径 |
|---|---|---|---|
| 商品 | 上架 / 下架 | 运营端上下架 | 下架后买家端**不可见**（不置灰、不留占位） |
| 商品 | 普通 / 清仓 | 运营端标记 | 清仓不可发起拼单；清仓不参与阶梯价 |
| 商品 | 支持拼单 / 不支持拼单 | 商品开关 | 不支持时**隐藏**发起拼单按钮与弹层按钮，不置灰 |
| 商铺 | 营业中 / 空闲招商 | 运营端维护 | 空闲铺位不展示评分与单量，进入商铺被拦截 |

### 0.6 名词与口径

| 名词 | 口径 |
|---|---|
| 起批量 | 商品最小下单量；加进货单/立即下单不得低于此值 |
| 阶梯价 | 按**下单数量**落档取单价；档位从低到高，取满足条件的最高档 |
| 拼单数量 | 拼单模式下 ≥ **起批量 20%**；支付后团开始，**累计达任一档才成团**（10b FR-22 / M01 BR-3） |
| 数量步进 | 步进 10 双；手输非 10 倍数时向上取整并提示 |
| 已售 | 展示单位「万 / 千」，后台给整数，端上格式化（`2.3万`、`8.7千`） |
| 相似度 | 拍照识别结果按 `0-100%` 展示，仅作参考，不参与排序计算 |
| 清仓价 | 演示为原价 50%；真实口径以后台清仓价字段为准（接口期） |

## 1. 商品列表 `product-filter.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 目标 | 承接搜索/筛选结果，让买家快速对比并进入详情 |
| 角色 | 全部（游客可见） |
| 入口 | 市场页「确定 (12件)」；首页搜索 |
| 前置 | 已携带筛选条件（当前为写死 4 条） |
| 后置 | 进详情 / 返回市场重新筛选 |

### 1.2 本页端间关系

| 维度 | 说明 |
|---|---|
| 数据来源 | 运营端商品库（上架商品） |
| 操作波及 | 无写操作；收藏/加购在详情页 |
| 依赖的其他端页面 | 运营端商城运营-商品列表（下架即不展示） |
| 不涉及的端 | 商户端（本页不展示商户视角数据） |
| 一致性要求 | 价格/起批量以后台为准；结果数与筛选条件一致 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部栏 | 返回、标题「筛选结果」、结果数徽标「12件」 |
| 已选条件卡 | 4 个条件 chip（可单删）+「清空全部」 |
| 排序条 | 综合推荐（默认）/ 销量优先 / 价格从低到高 / 好评优先 |
| 商品列表 | 纵向 6 条：图 100×100、标题 2 行、标签、价格 + /双、起批量、评分、已售、店铺 |
| 空态 | 筛选无结果时的说明 + 「清空筛选条件」按钮（`?empty=1` 演示） |
| 底部吸底 | 「返回市场」（链接）+「重新筛选」（跳市场并自动开面板），高 60px + 安全区 |

| 子视图 | 触发 | 规格位置 |
|---|---|---|
| 空态块 | `?empty=1` 且仍有已选条件 | §1.5.3 / §1.6 |

### 1.4 列表、筛选与排序

| 项 | 规则 |
|---|---|
| 默认排序 | 综合推荐 |
| 可切换排序 | 4 种；**原型只切高亮并 toast，不重排数据**（⚠️ 演示限制） |
| 分页 | 原型 6 条写死，无分页 / 无触底加载 |
| 组合逻辑 | 条件之间 AND；同组内单选（由筛选面板保证） |
| 空态 | 有条件但无结果 → 空态块；点「清空筛选条件」回到列表 |
| 导出 | 不适用 |

### 6.4 列表、筛选与排序

| 项 | 规则 |
|---|---|
| 地图渲染 | 网格布局，按后台铺位顺序 |
| 搜索 | 铺位号或名称**包含**匹配，忽略大小写 |
| 筛选 | 品类单选；匹配铺位保持不透明，其余置 0.25 透明度 |
| 排序 | 不适用（铺位固定） |
| 空态 | 搜索无结果 → 文案；筛选无匹配 → 全部置灰（无文案，⚠️） |

### 6.5 字段规格

#### 6.5.1 铺位格

| 字段 | 标识 | 类型 | 必填 | 规则 |
|---|---|---|---|---|
| 铺位号 | `code` | string | 是 | 如 `A01`、`2A01` |
| 商铺名 | `name` | string | 是 | — |
| 主营 | `cat` | string | 是 | 显示在格内（如「男袜」） |
| 位置 | `location` | string | 是 | 「A区01号」 |
| 评分 | `rating` | number | 是 | 0-5，1 位小数 |
| 累计单量 | `orders` | int | 是 | 0 表示空闲 |
| 状态 | `status` | enum | 是 | 营业中 / 空闲招商 |
| 类型 | `cellType` | enum | 是 | shop / food / restroom / elevator / entrance / idle / parking |

#### 6.5.2 搜索结果

| 字段 | 规则 |
|---|---|
| 命中数 | 「找到 N 家，已高亮」 |
| chip | 「铺位号 + 名称」，点击定位并滚动 |
| 无结果 | 未找到匹配商铺 |

#### 6.5.3 商铺弹层

| 字段 | 规则 |
|---|---|
| 名称 / 铺位 / 主营 | 只读 |
| 状态 | `orders>0` → 营业中（绿）；否则空闲招商（灰） |
| 评分 / 单量 | 空闲时单量显示「—」 |
| 简介 | 后台文案 |
| 按钮 | 收藏、进入商铺 |
