## 0. 族通用说明（本族其他页面不再重复）

### 0.1 这个族解决什么问题

买家有两类「非标准品」采购需要：**没有现货、要商家报价**（询价），或**要按自己的设计做**（定制）。本族把这两条链路的发布、比价、选标、设计、打样、下单讲清楚。

不做会怎样：买家只能在商品详情里问客服，报价散落在微信里；定制没有参数与价格口径，打样费、起订量各说各话。

### 0.2 角色与权限

| 角色 | 能看 | 能操作 | 越权表现 |
|---|---|---|---|
| 游客 | 询价列表 / 公开需求 | 浏览 | 发布、选标 → 需实名（原型有认证卡点，可模拟切换） |
| 已实名采购商 | 全部 | 发布需求、看报价、选标成交、定制下单 | — |
| 未实名采购商 | 公开需求可看 | **不能发布、不能看需求详情报价** | 原型：认证卡 → 引导认证 |

> **实名是本族的前置卡点**：`inquiry.html` / `inquiry-publish.html` 顶部都有认证状态卡；未认证时发布按钮与详情入口应被拦（当前为演示态，可手动切换）。

### 0.3 端间落点

| 维度 | 运营管理端 | 商户端（卖家端） | 买家端（本族） |
|---|---|---|---|
| 询价需求 | 需求监管/代录 | **需求池 + 报价** | 发布、看报价、选标 |
| 报价明细 | 可查 | 报价方 | **仅需求方本人可见**，公开需求不暴露 |
| 选标成交 | 订单监管 | 接单 | 确认成交 → 生成询价订单 |
| 定制 | 定制单监管 | 接单、打样 | 参数配置、AI 设计、打样、下单 |
| 打样 | — | 收样费/免费寄样 | 申请打样、看进度 |

> **关键边界**：买家端**不参与竞价**。公开需求页明确写「竞价由卖家在卖家端参与」，只做社交证明与引流。

### 0.6 名词与口径

| 名词 | 口径 |
|---|---|
| 最高单价 | 买家可接受的单价上限，卖家报价高于此值不展示或标红（端上当前只展示） |
| 报价统计 | 报价数、最低价、平均价，**仅需求方可见** |
| 选标 | 买家选定一家报价 → 生成询价订单，其余报价方收结果通知 |
| 拼单/定制门槛 | 定制起订量按规格变化（默认 50 双）；拼单另见 F04 |
| 样品费 | **由商户报价时填写**，三档：免费 / 收费可抵大货 / 收费不可抵；买家端不得自行定价或展示预设金额（10b §2.0.5） |
| 定制方式 | 仅打样 / 直接大货 / 先打样后大货；决定是否寄样、是否生成 SP、是否可直接转 CZ（10b §2.0.6） |
| 需求号 | CP（个性定制）/ CE（企业批量）；打样单 SP、定制单 CZ（10b §2.0.3） |
| 定制单价 | 由材质、工艺、数量共同决定（当前端上为演示映射表） |
| AI 方案 | 生成结果标注「AI生成」，需人工复核；采用后覆盖当前参数 |
| 报价改价次数 | 演示限 2 次变更，超限需重新报价（M01 §2.3） |

## 1. 采购询价 `inquiry.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 目标 | 询价总入口：看自己发布的需求与报价进度，浏览公开需求 |
| 角色 | 已实名采购商（未实名只读） |
| 入口 | 市场页「采购询价」 |
| 前置 | 实名认证（卡点） |
| 后置 | 发布 / 我的发布详情 / 公开需求详情 |

### 1.2 本页端间关系

| 维度 | 说明 |
|---|---|
| 数据来源 | 需求 + 报价统计 |
| 操作波及 | 无写操作（发布在下一页） |
| 依赖 | 卖家端报价、运营端需求监管 |
| 一致性 | 报价数、最低价与详情页一致 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 返回、标题「采购询价」、副标题「发布需求 · 商家竞价 · 选标成交」 |
| 认证卡 | 已认证（绿）/ 未认证（黄，含「去认证」）；可切换演示 |

| 三处同步 | 任一参数变化 → ① 预览卡摘要 ② 参数区「当前方案」条 ③ 提交弹层摘要 同时更新（`syncUI()` 单入口渲染） |
| AI 产出 | 生成 2 套**完整参数候选**（每套含效果图 + 主色/材质/图案/筒高/工艺），本质是预填值 |
| 采用动作 | 写入同一套参数 → 所有 chip 跳到对应选中态、预览图切换、来源徽标置「AI 方案」、滚回顶部 |
| 手动微调 | 采用 AI 后再改任一参数 → 徽标变「AI 方案 · 已手动调整」，不再声称是 AI 方案 |
| 覆盖保护 | 处于「已手动调整」时再采用另一套 AI 方案 → 二次确认「采用这套参数会覆盖你刚才的手动调整，是否继续？」 |
| 重置 | 恢复默认参数（藏青 / 纯色 / 精梳棉 / 经典条纹 / 中筒 / 39-42 / 200针提花），来源回到「手动配置」，数量回 500 |
| 禁止表现 | ① AI 结果只改文案不改参数 ② AI 采用后 chip 与摘要不一致 ③ 用「AI推荐方案」之类的字符串顶替图案名 |
