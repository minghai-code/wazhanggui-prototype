## 0. 族通用说明（本族其他页面不再重复）

### 0.1 这个族解决什么问题

把「一个人吃不下起批量」的采购凑成团：团长按起批数量的 20% 起下单并支付即成团，其他人同样以起批数量 20% 起参团，共享该档拼单价。

不做会怎样：小买家凑不到起批量只能放弃，或线下自己找同行拼，平台拿不到这部分交易。

### 0.5 状态机

> 依据：**后台 `10b §5.3`（2026-10-26 定稿）**——拼单活动三态；**成团看累计档位，不看团长是否支付**。

| 对象 | 状态 | 进入条件 | 出口 |
|---|---|---|---|
| 拼单 | 进行中 | 团长发起并支付首笔 | 累计达任一档 → **已成团**；到期未达起拼档 → **已失效** |
| 拼单 | 已成团 | 累计数量 ≥ 任一档阈值 | 锁档结算 → 逐笔生成订单 → 履约 |
| 拼单 | 已失效 | 到期未达起拼档 | 全额退款，终态 |
| 团长 | — | — | **可退出，份额保留、身份不转移，团继续**（不是解散） |
| 参团人 | 已参团 → 已生成订单 / 已退款 | 参团支付成功 | 成团 → 有订单；失效 → 退款 |

列表 Tab 归并：**进行中 → 「进行中」；已成团 / 已失效 → 「已结束」**。

### 0.6 名词与口径

| 名词 | 口径 | 依据 |
|---|---|---|
| 拼单价 | 所选档位单价；降幅 = `(原价−拼单价)/原价`，四舍五入百分比 | M01 BR-2 |
| 起批量 | 商品字段，下单最小量（本团 100 双）；**与阶梯起始数量是两个字段** | M01 BR-2a |
| 起拼档 | 阶梯价中起始数量最小的、且不低于起批量的那一档（本团 100 双） | M01 BR-2d |
| 参团门槛 | `ceil(起批量 × 20%)` = **20 双**，团长与参团人同标准 | M01 BR-2a |
| 团长下单量 | 买家输入，≥ 参团门槛，可更高 | 同上 |
| 已拼数量 | 团长下单量 + 各参团人数量之和；**累计达任一档即成团** | 10b FR-22 |
| 参团步进 | 10（随商品单位） | M01 BR-4 |
| 计量单位 | 取商品 `unit`（双/件/套），不写死 | M01 BR-6 |
| 倒计时 | 距截止 `HH:MM:SS`，到 0 置「已结束」 | M01 BR-7 |
| 合计 | `数量 × 拼单价`；省额 = `数量 × (原价−拼单价)` | — |
