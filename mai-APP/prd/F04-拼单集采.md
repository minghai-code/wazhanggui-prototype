## 0. 族通用说明（本族其他页面不再重复）

### 0.1 这个族解决什么问题

把「一个人吃不下一整个阶梯」的采购凑成团：团长在商品详情**选定目标档**（阶梯价里的某一档）并按参团下限起下单，其他人以同一门槛参团；**累计件数达到目标档才成团**，全团按目标档单价结算，**超档不升价**；到期未达目标档则失效、全额退款。

不做会怎样：小买家凑不到起订量只能放弃，或线下自己找同行拼，平台拿不到这部分交易与履约数据。

### 0.2 角色与权限

| 角色 | 能看 | 能操作 | 越权表现 |
|---|---|---|---|
| 游客 | 拼单列表、拼单详情 | 浏览 | 参团/发起 → 原型**不拦**（接口期需登录） |
| 登录买家 | 同上 + 我的拼单 | 参团、发起、邀请、看订单 | — |
| 团长（发起人） | 自己发起的团 | 邀请、查看进度、**退出本团（份额保留、身份不转移）**、**取消本团（仅进行中，二次确认）** | 团长不能改档位/改价/改数量；两个动作不可混：退出=团继续、取消=整团终止 |
| 商户 / 运营 | 后台视角 | 申请取消本团（需运营审核）、强制取消 | 商户端不可改档位、不可新建团（只由买家发起） |

### 0.5 状态机

> 依据 `10b v2.1 §2.0.13`：团 **4 态**；成团看累计是否达**团长所选目标档**，不看团长是否支付；商户/平台取消需运营审核。

| 对象 | 状态 | 进入条件 | 出口 / 可执行 |
|---|---|---|---|
| 团 | **进行中** | 团长选目标档、支付首笔 | `cum ≥ targetQty` → 已成团；到期 `cum < targetQty` → 已失效；团长取消 / 商户申请（运营审核）/ 平台强制 → 已取消 |
| 团 | **已成团** | `cum ≥ targetQty` | 按 `targetPrice` 锁档结算 → 各 GB 单转「待发货」→ 履约，终态；**超档不升价** |
| 团 | **已失效** | 到期未达目标档（**即便已过第一档也不算成团**） | 全员原路全额退款（3 个工作日），终态 |
| 团 | **已取消** | 团长取消 / 商户申请 / 平台强制 | 全员全额退款，终态、不可恢复 |
| 参团人 | 待成团 → 已生成订单 / 已退款 | 参团支付成功 | 成团 → GB 单转待发货；失败或取消 → 已退款 |

- **列表 Tab 归并**：进行中 → 「进行中」；已成团 / 已失效 / 已取消 → 「已结束」（"已结束"是聚合词，不是单据状态）。**不设「即将开始」Tab**（恒空态，2026-11-11 删除）。
- **参团人视角文案**：进行中 →「待成团」；已成团 →「已生成订单」；已失效 →「拼单失败，已全额退款」；已取消 →「拼单已取消，款项已退回」。

### 0.6 名词与口径

| 名词 | 口径 | 依据 |
|---|---|---|
| 阶梯最小档 `tierQty` | 该规格阶梯表中起始数量最小的一档的起始数量；只用于算参团下限 | 10b v2.1 §2.0.13 ⑤ |
| 目标档 `targetQty` | 团长发起时**选定的那一档**的起始数量；成团阈值；`targetQty ≥ tierQty` | 10b v2.1 §2.0.13 ① |
| 目标档价 `targetPrice` | 所选档位单价；全员预付价 = 成团锁档结算价 | 同上 |
| 参团下限 `groupMin` | `max(10, ceil(tierQty × 20%))`，对齐 10 的倍数；与团长选哪档无关 | M01 BR-2a |
| 拼单价（展示） | 展示 `targetPrice`；降幅 = `(原价 − targetPrice) / 原价` | M01 BR-2 |
| 累计 `cum` | 团长首笔 + 各参团人数量之和；进度 = `cum ÷ targetQty`（封顶 100%） | 10b v2.1 |
| 超档不升价 | `cum > targetQty` 仍按 `targetPrice` 结算，不降价、不退差价 | 10b v2.1 §2.0.13 ② |
| 参团人数 `people` | 仅展示，**不参与成团判定** | 10b v2.1 |
| 参团步进 | 10（随商品单位） | M01 BR-4 |
| 计量单位 | 取商品 `unit`（双/件/套），不写死 | M01 BR-6 |
| 倒计时 | 距截止 `HH:MM:SS`，到 0 置「已结束」 | M01 BR-7 |
| 单号 | 团 `T…`；成团后每人各生成一笔 `GB…` 订单（支付即生单） | 10b §2.0.1 |
