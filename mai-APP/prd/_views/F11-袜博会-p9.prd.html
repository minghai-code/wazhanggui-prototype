0. 族通用说明（本族各页面共用）

0.1 这族解决什么问题

第 18 届袜博会的移动端入口：看展会信息与日程、在线参观登记领入场码、现场扫码核销、按登记/核销状态解锁资料、展商在线自选展位并提交申请。

不做会怎样：观众靠纸质名单核对入场，资料人人可下载，展位靠邮件+手绘平面图分配，到场率无法统计。

0.5 状态机

参观登记（6 态）

端上 key后台状态端上表现
pending待审核结果页「等待审核」+ 登记编号
approved已通过生成入场码 V+年+届次+4位，可扫码
checkedin已核销入场证 + 资料全解锁
rejected已驳回驳回原因 + 重新登记
noshow未到场仅后台可见（端上无入口）
cancelled已取消仅后台可见

展位申请（2026-10-28 v1.1：取消在线支付后 3 态）：待审核 → 已通过（报名成功 · 参展商）；异常 已驳回 / 已取消。缴费状态与参展资格解耦：未缴费（线下转账） / 组委会已登记到账，逾期不取消展位。

资料访问策略：public 公开 / registered 需登记通过 / checkedin 需现场核销。

9. 扫码核销（核销员） expo-checkin-scan.html

9.1 页面说明

项内容
页面目标现场工作人员扫码 → 看到持码人信息 → 本人确认完成核销
入口袜博会首页「扫码核销」卡（仅核销员角色可见）
使用前提账号在统一角色管理中被授予「袜博会核销员」；同一账号可同时是买家/展商，不影响其本来的展会身份；无该角色打开只显示「无核销权限」

9.2 页面结构

区块内容
顶栏返回、标题「扫码核销」、当前核销点（A 口）
取景区230×230 取景框 + 扫描线动画 + 提示「对准参展证 / 入场证」
演示区模拟扫参展证 / 入场证 / 无效码（仅原型）
兜底「手动输入证件号」
统计今日我已核销 N 人
结果弹层证件类型、姓名、单位、展位或身份、核销状态 → 确认核销 / 已核销提示
成功态大勾 + 核销时间 + 核销点 + 「继续扫下一张」

9.3 交互规则

动作结果
扫到有效码弹结果卡，显示持码人信息与当前核销状态
点「确认核销」调核销接口 → 成功态；计数 +1；再扫同码提示首次时间
扫到无效码Toast「无效码：非本届证件或签名校验失败」，不进入结果页
手动输入证件号查询 → 同一结果卡；后台记「手工补录」
非核销员进入整页拦截，提示联系现场负责人

9.4 异常与边界

场景处理
摄像头权限被拒提示开启权限，或改用手动输入
已核销证件按钮置灰，显示首次核销时间
网络异常本次核销本地暂存，恢复后自动补传
核销点未绑定提示「请先选择核销点」
