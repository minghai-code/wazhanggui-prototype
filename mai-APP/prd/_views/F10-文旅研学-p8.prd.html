0. 族通用说明（本族各页面共用）

0.1 这族解决什么问题

把大唐袜业城的研学（路线/场次/报名/责任书/签到）与文旅资源（活动日历、场馆资源）搬到手机端，让家长与学校自助完成"选路线 → 报名 → 签责任书 → 现场扫码签到"，让游客查看活动与场馆信息。

不做会怎样：报名仍靠微信群接龙、责任书靠纸质签署，出现安全事件无法追溯"谁签的、什么时候签的"，现场点名也无法沉淀数据。

0.5 状态机

报名单（9 态，端上 key ↔ 后台中文）

端上 key后台状态可做的动作
pending待审核等待（演示：审核通过/补材料/驳回）
supplement待补充去补充材料、重新提交
rejected已驳回修改后重新申请
unsigned已通过（待签署）签署责任书、取消
signed已签署（待出行）查看签到码、取消、模拟签到
checkedin已签到活动结束后评价
completed已完成查看评价
noshow未到场重新报名（签到码失效）
cancelled已取消重新报名
stateDiagram-v2
  [*] --> pending
  pending --> supplement: 要求补材料
  supplement --> pending: 补件重提（原编号）
  pending --> rejected: 驳回
  pending --> unsigned: 审核通过
  unsigned --> signed: 签署责任书
  unsigned --> cancelled: 取消
  signed --> checkedin: 现场扫码
  signed --> noshow: 签到截止未到
  signed --> cancelled: 取消（24h 前）
  checkedin --> completed: 活动结束+评价

场次：可报名 / 仅剩少量 / 已满（已满只可候补登记，暂不自动递补）。 活动：报名中 / 已结束 / 待开放（端上只读状态徽标）。

项口径
