0. 族通用说明（本族其他页面不再重复）

0.1 这个族解决什么问题

买家有两类「非标准品」采购需要：没有现货、要商家报价（询价），或要按自己的设计做（定制）。本族把这两条链路的发布、比价、选标、设计、打样、下单讲清楚。

不做会怎样：买家只能在商品详情里问客服，报价散落在微信里；定制没有参数与价格口径，打样费、起订量各说各话。

5.4 方案状态模型（唯一数据源）

核心原则：一个需求只有一套参数。「AI 生成」不是第二套方案，而是「帮我填参数」的入口。

项规则
状态载体单一参数集 color / palette / mat / pat / height / size / craft，页面不存在「AI 方案」和「手动方案」两份数据
三处同步任一参数变化 → ① 预览卡摘要 ② 参数区「当前方案」条 ③ 提交弹层摘要 同时更新（syncUI() 单入口渲染）
AI 产出生成 2 套完整参数候选（每套含效果图 + 主色/材质/图案/筒高/工艺），本质是预填值
采用动作写入同一套参数 → 所有 chip 跳到对应选中态、预览图切换、来源徽标置「AI 方案」、滚回顶部
手动微调采用 AI 后再改任一参数 → 徽标变「AI 方案 · 已手动调整」，不再声称是 AI 方案
覆盖保护处于「已手动调整」时再采用另一套 AI 方案 → 二次确认「采用这套参数会覆盖你刚才的手动调整，是否继续？」
重置恢复默认参数（藏青 / 纯色 / 精梳棉 / 经典条纹 / 中筒 / 39-42 / 200针提花），来源回到「手动配置」，数量回 500
禁止表现① AI 结果只改文案不改参数 ② AI 采用后 chip 与摘要不一致 ③ 用「AI推荐方案」之类的字符串顶替图案名

5.5 字段规格
