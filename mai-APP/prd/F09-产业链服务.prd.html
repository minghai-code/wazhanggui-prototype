0. 族通用说明（本族其他页面不再重复）

0.1 这个族解决什么问题

买家（袜业中小企业 / 采购商 / 求职者）在采购之外还有六类产业需求：融资、用工、知识产权、技术、政策、中介。平台不自己提供这些服务，而是把分散的机构、政策、岗位、成果聚合到一处，并承担「信息真实 + 留痕 + 状态回显」三件事。

不做会怎样：小买家只能自己一家家打电话找服务商，真伪无法判断、政策看不懂、技术需求发不出去；平台也拿不到产业服务侧的活跃数据。

7.5 字段规格

字段标识类型必填规则
服务商名namestring是卡片主标题
类型type / typeLabelenum是finance / legal / consult / cert / test + 中文徽章
评分ratingfloat是1 位小数 + 星级
服务次数countint是「服务 N 次」
描述descstring是一句话
标签tags[]string[]否2–3 个
服务价格pricestring是底部展示
服务项目services[{name,charge,price,period}]object[]是折叠区，只读
咨询方式consult{mode,value}object是phone 电话 / link 官网
状态statusenum是offline 不展示

7.6 交互规则

动作结果
点类目 chip前端过滤并重渲染（不带参数）
点「服务项目（N）」页内折叠展开/收起
点「拨打电话」location.href='tel:' 真实拨号（4 家）
点「前往官网」window.open(value,'_blank') 真实外跳；2 条外链均已带 https://
点推荐卡同咨询动作
空态按钮「查看全部服务商」回到「全部」类目
