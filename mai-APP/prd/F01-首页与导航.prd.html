0. 族通用说明（本族各页面共用）

0.1 这族解决什么问题

买家端的骨架与流量分发：5 个底部 Tab 定框架（首页 / 视频看货 / AI 工具 / 进货单 / 我的），首页把「四大市场 / 产业链 / 文旅 / 榜单 / 爆款 / 资讯」铺成入口，再提供搜索、消息、资讯详情等通用页。

不做会怎样：用户进来不知道从哪里开始找货，所有业务页都成孤岛。

3.4 列表规则

定位（2026-11-04 业务确认）：视频看货不是核心功能，前期商户与上传量都少，不做推荐算法/权重体系/流量池，只做「能筛选 + 有排序 + 能加载完」的简单版，优先满足验收。
项规则
加载首屏 8 条（双列 4 行），触底自动加载下一页 8 条（顶部筛选条常驻不随页滚动）；无下一页 → 显示「没有更多了」+ 结果总数
默认排序综合分降序（见 3.4.1），不是发布时间倒序
可选排序综合推荐（默认）/ 最新发布（发布时间倒序）/ 播放最多 / 收藏最多
筛选·关键词匹配商品名称 + 视频标题 + 商家名，边输边筛（不区分大小写）
筛选·品类品类 = 视频所挂商品的「商品分类」（唯一来源，商品侧维护），筛选项由当前视频库中出现的商品分类去重生成；本页不建类目、不维护类目。无关联商品的视频归「平台内容」，不参与品类筛选（仅「全部」可见）

3.4.1 综合分（简单可解释，不做机器学习）

因子权重说明
播放量×1基础热度
收藏量×20收藏=采购意向，权重最高
点赞量×5轻互动，权重最低
精选标记+5000运营在后台勾选，用于新品/活动扶一把
新鲜度≤7 天 +2000 / ≤15 天 +1200 / ≤30 天 +600 / >30 天 +0防止老视频长期霸榜
  • 公式：综合分 = 播放量×1 + 收藏量×20 + 点赞量×5 + 精选×5000 + 新鲜度加成
  • 同分时按发布时间倒序（新的在前）
  • 后台不需要配置权重：常量写在系统里，运营只用勾「精选」

7. AI 创作对话 ai-chat.html

7.1 页面说明

项内容
页面目标AI 生图 / AI 文案 / AI 卖货助手的统一对话式生成页：一句话描述需求 → 出图或出文案，首屏给案例照着改
使用角色买家（小 B 商家）
入口ai.html 工具宫格（?f=image / ?f=copy / ?f=sell）；ai.html「最近使用」卡片
前置?f= 缺省或非法时按 AI 生图渲染
后置结果保存 / 转发微信（原型为 toast）；生成记录回流 ai.html「最近使用」

7.2 本页端间关系

项内容
数据来源千问大模型（生图、文案同源能力）；案例与示例为端上静态 mock
跨端影响无
依赖页面ai.html（入口与记录回流）
不涉及商户端
一致性同页按 ?f= 切主题与内容，入口名与 ai.html 工具位一一对应

7.3 页面结构

区块内容
头部返回 ai.html + 入口名（AI 生图 / AI 文案 / AI 卖货助手）+ 副标题 + 右上「记录」
欢迎语按入口不同：生图问「想做哪种图」、文案问「要写哪种文案」、卖货问「要转卖什么货」
首屏示例生图：3 张效果缩略图（白底主图 / 场景图 / 促销海报）；文案、卖货：1 条示例文案卡
案例区按入口过滤：生图→商品主图 + 促销海报；文案→朋友圈 + 转卖；卖货→转卖 + 朋友圈；点「用它」直接发送
快捷问法按入口 4 条（生图：白底主图 / 场景图 / 促销海报 / 换背景；文案：朋友圈 / 商品标题 / 详情页 / 转卖；卖货：转卖 / 更短 / 批发价话术 / 朋友圈版）
结果区生图→4 张主图；海报→1 张海报；文案→3 条文案；转卖→1 条转卖文案，均带「换一组 / 换配色 / 转发微信 / 保存」等后续按钮
底部输入输入框 + 发送；提示「生成内容为 AI 辅助产出，发布前请核对规格与卖点」

页内子视图：无（单列对话流）。
