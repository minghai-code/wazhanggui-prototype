0.1 这族解决什么问题

买家端的骨架与流量分发：4 个底部 Tab 定框架，首页把「四大市场 / 产业链 / 文旅 / 榜单 / 爆款 / 资讯」铺成入口，再提供搜索、视频看货、AI 工具、消息、资讯详情 5 个通用页。

3.4 列表规则

定位（2026-11-04 业务确认）：视频看货不是核心功能，前期商户与上传量都少，不做推荐算法/权重体系/流量池，只做「能筛选 + 有排序 + 能加载完」的简单版，优先满足验收。
项规则
加载首屏 8 条（双列 4 行），触底自动加载下一页 8 条（顶部筛选条常驻不随页滚动）；无下一页 → 显示「没有更多了」+ 结果总数
默认排序综合分降序（见 3.4.1），不是发布时间倒序
可选排序综合推荐（默认）/ 最新发布（发布时间倒序）/ 播放最多 / 收藏最多
筛选·关键词匹配商品名称 + 视频标题 + 商家名，边输边筛（不区分大小写）
筛选·品类品类 = 视频所挂商品的「商品分类」（唯一来源，商品侧维护），筛选项由当前视频库中出现的商品分类去重生成；本页不建类目、不维护类目。无关联商品的视频归「平台内容」，不参与品类筛选（仅「全部」可见）
筛选·精选「精选推荐」开关，只看运营标了「精选」的视频
筛选关系各条件且关系；筛选变化后回到第 1 页
计数筛选条下方显示「共 N 条视频」，并标注当前品类 / 仅精选
角标有 goods → 「可下单」；无 → 「纯内容」；pick → 左上「精选」
排序切换影响播放流进入播放流后按当前筛选结果的顺序上下滑，进度显示 n/N，首尾不循环
空态「没有符合条件的视频」+ 副文案「试试清空搜索词或切回「全部」」

3.4.1 综合分（简单可解释，不做机器学习）

因子权重说明
播放量×1基础热度
收藏量×20收藏=采购意向，权重最高
点赞量×5轻互动，权重最低
精选标记+5000运营在后台勾选，用于新品/活动扶一把
新鲜度≤7 天 +2000 / ≤15 天 +1200 / ≤30 天 +600 / >30 天 +0防止老视频长期霸榜
  • 公式：综合分 = 播放量×1 + 收藏量×20 + 点赞量×5 + 精选×5000 + 新鲜度加成
  • 同分时按发布时间倒序（新的在前）
  • 后台不需要配置权重：常量写在系统里，运营只用勾「精选」
