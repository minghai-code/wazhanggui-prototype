## 0.1 定位

袜子厂买原料的地方：找料（纱线 / 化纤 / 染料助剂 / 辅料橡筋 / 包装 / 纺配）→ 看商户与商铺 → 看店铺在售商品 → 进商品详情下单。

与「袜子市场」是**同一套后台、不同品类**：后台模块（场所、商户档案、店铺、商品）全部共用，靠**主营品类**把两类市场分开，不另建一套原料专用后台。

## 0.2 三条数据源（核心口径，2026-11-03 定）

| 区块 | 数据源 | 判定条件 | 后台落点 |
|---|---|---|---|
| **原料品牌馆** | 店铺（外采店铺属性） | `店铺类型 = 品牌店铺` **且** 店铺主档 `主营品类` 含原料大类 | 外采店铺属性（`categories[]`）+ 我方店铺管理（类型/资质） |
| **原料商户** | 后台实体商户管理（04 商户档案） | 商户**主营品类含原料大类**，且商户状态 = 正常经营（可对外展示） | `04-商户管理` 商户档案；档口/店面信息取 `02` 资源单元 |
| **原料商品** | 店铺在售商品 | 该店铺属原料市场（`店铺主营品类含原料大类`）→ 取该店铺在售商品 | 外采商品库（按店铺 ID 反查） |

**三条都靠同一个开关：店铺/商户的「主营品类」是否命中原料大类**。所以品类字典是这套区分机制的**唯一支点**（见 §0.5 缺口）。

> ✅ **2026-11-03 决策（业务已定）**：**「主营品类」要成为店铺的必备属性，外采店铺表也要加这个字段。**
>
> | 数据源 | 现状 | 决策 |
> |---|---|---|
> | 04 实体商户档案 | **已有**主营品类 | 不动 |
> | 买家端「申请线上开店」 | **已收**店铺主营品类（`merchant-open-shop.html`，字典多选、必选 ≥1） | 保留，作为店铺品类的**写入来源** |
> | **外采店铺属性** | **没有**主营品类，只有商品有分类 | **新增 `categories[]` 字段**（改造项，见 §0.10） |
>
> 原因：袜子市场与原料市场**都要同时展示线下店铺与线上商品**，必须有一个字段能区分"卖袜子还是卖原料"。店铺没有这个字段，两个市场就分不开。
>
> 商品**不加业务品类字段**：原料商品 = 原料店铺的在售商品（按店铺反查）；外采自带的商品分类只用于**超范围校验**。

## 0.3 市场区分机制

```
后台一套数据
   ├─ 02 场所：大唐袜业城 / 原料市场 / 行政服务中心   ← 物理位置
   ├─ 04 商户档案：categories[] 主营品类（引用品类字典）
   ├─ 10 店铺：店铺类型（普通/品牌/自营）+ 所属商户
   └─ 外采商品库：商品（挂在店铺下）
        ↓ 按「主营品类是否属原料大类」分流
买家端：袜子市场（market-socks / market-map） ｜ 原料市场（market-material 系列）
```

| 规则 | 内容 |
|---|---|
| F05-R1 | 原料大类集合 = 品类字典「**原料纱线**」大类下的全部品类项（含定案后补入的纱线/化纤长丝/染料助剂/辅料橡筋/包装物料/纺机配件 6 项，Y-11）；集合由**运营端字典**决定，端上不写死 |
| F05-R2 | 市场归属按品类大类推导，**可多归属**：主营品类含原料大类 → 进原料市场；含袜品大类 → 进袜子市场；混营（两类都有）→ **两边都展示**（2026-11-03 业务确认）；品类为空 → 两边都不展示（运营端可筛「未归类」） |
| F05-R3 | 商户状态非「正常经营」（暂停/冻结/清退）→ 不出现在原料商户与商品列表 |
| F05-R4 | 店铺未开线上店（仅线下）→ 出现在「原料商户」，但**没有商品**，商铺详情只展示资料与联系 |
| F05-R5 | 品牌馆仅收「品牌店铺 + 品牌资质通过」的原料店铺（与 F03 品牌馆同规则，只多一层品类过滤） |

## 0.10 落地要求（2026-11-03 业务已定）

### 0.10.1 决策一句话

**「主营品类」升级为店铺的必备属性：04 商户档案已有、开店申请已在收，外采店铺表也要加这个字段。** 袜子市场与原料市场都靠它分流，不许再出现"没有字段可区分"的情况。

### 0.10.2 字段规格（三处同名同义）

| 位置 | 字段 | 必填 | 来源 | 说明 |
|---|---|---|---|---|
| 04 商户档案 | categories[] | 是 | 线下建档 / 资料变更审核 | **已有**，字典取值 |
| 买家端 开店申请 | categories[] | 是（≥1） | 商户勾选，字典下发 | **已有**（#43 已改字典渲染、不预选） |
| **外采店铺属性** | categories[] | 是 | **审批通过写入**；此后变更走资料变更审核 | **新增（Y-12）**；外采为源码整合（商城运营模块下），后台原型由运营端补 |

- **取值**：一律引用品类字典（04 §8.5b），端上不写死
- **写入时机**：开店审核通过 → 申请单 categories[] 写入店铺记录；线下商户自动建档时由 04 档案带过来
- **变更**：只能走「资料变更审核」，店长不能自改（防止品类被拿来刷市场曝光）
- **空值处理**：店铺无品类 → 两个市场都不展示，运营端「未归类」可筛（Y-12 已含）

### 0.10.3 商品侧口径（依赖店铺字段，不需给商品加品类）

| 项 | 口径 |
|---|---|
| 原料商品 | 取**店铺品类含原料大类**的店铺 → **按店铺 ID 反查在售商品** |
| 商品分类 | 外采自带，只用于**超范围校验**，不复制成第二套业务品类 |
| 兜底 | 若外采暂不支持按店铺 ID 过滤 → 按 goods.shopId 在我方过滤；若连 shopId 都没有 → 临时用「商品分类→市场」映射顶，但**必须限期补店铺字段** |

**仍需向外采确认的 2 个实现细节**（不影响口径，只影响工期）：

| # | 问题 | 影响 |
|---|---|---|
| E1 | 商品查询能否按店铺 ID（集合）过滤 | 不能则先在我方过滤，性能有差异 |
| E2 | 商品分类是否有多级字典可导出 | 没有则超范围校验先不做，只保留店铺维度 |

### 0.10.4 治理规则

| 编号 | 规则 |
|---|---|
| F05-10-R1 | 店铺 categories[] 来源 = **开店申请单审批通过后写入**；变更走「资料变更审核」，店长不能自改 |
| F05-10-R2 | 商品上架/同步时校验：商品分类映射的品类 ⊂ 店铺 categories[]；不满足**不拦截上架**，但打标「超范围」，**原料市场不展示该商品** |
| F05-10-R3 | 店铺 categories[] 为空 → 不进任何市场，运营端可筛「未归类」并催补 |
| F05-10-R4 | 纯线上原料店铺不必有 04 档口档案，**以店铺品类为准**；有 04 档案时两者必须一致，不一致以**审核通过的那次变更**为准并留痕 |

## 2. 原料市场介绍 `material-intro.html`

### 2.1 页面说明

| 项 | 内容 |
|---|---|
| 目标 | 让采购商了解原料市场规模、品类与配套，产生信任 |
| 入口 | 首页市场介绍卡、`material-merchants.html` |
| 后置 | 查看商户 → `material-merchants.html`；供应链金融 → `finance-service.html` |

### 2.2 页面结构

| 区块 | 内容 |
|---|---|
| 市场概况 | 封面、简介、4 个指标（供应商 / 品类 / 年交易额 / 面积） |
| 六大品类 | 纱线 / 化纤长丝 / 染料助剂 / 辅料橡筋 / 包装物料 / 纺机配件 |
| 商户构成 | 生产企业直营 / 一级代理占比等 |
| 配套服务 | **供应链金融、检测中心**（打样中心 / 智能仓储已于 2026-11-03 下架） |
| 入驻引导 | 招商说明 → `merchant-join.html` |

### 2.3 规则与验收

| 编号 | 内容 |
|---|---|
| F05-2-R1 | 六大品类名称与品类字典逐字一致，字典改则页面改 |
| AC-04 | 页面无「打样中心 / 智能仓储」入口；金融与检测仍可点 |

## 3. 原料商户 `material-merchants.html`

### 3.1 页面说明

| 项 | 内容 |
|---|---|
| 目标 | 按品类找原料供应商，支持列表与地图两种找法 |
| 数据来源 | **04 商户档案（状态=正常经营）且主营品类含原料大类** |
| 入口 | 首页「查看全部」、介绍页 |
| 后置 | 商铺详情 `material-shop-detail.html?id=` |

### 3.2 结构

| 视图 | 内容 |
|---|---|
| 列表 | 商户卡：名称、主营品类多标签、档口/店面位置、评分、在售商品数 → 商铺详情 |
| 地图 | 市场平面 + 商户点位，点点位弹商户卡（与列表同一数据） |
| 筛选 | 品类 / 产地 / 供货方式 / 认证，结果页 `material-filter.html` |

### 3.3 规则与验收

| 编号 | 内容 |
|---|---|
| F05-3-R1 | 仅「正常经营」商户可见；暂停/冻结/清退不进列表 |
| F05-3-R2 | 仅线下商户也展示（不因无线上店被过滤），详情页无商品区 |
| AC-05 | 商户状态改暂停后，列表与地图同时消失 |

## 4. 筛选结果 `material-filter.html`

### 4.1 页面说明

| 项 | 内容 |
|---|---|
| 目标 | 承接首页筛选项，输出符合条件的商品/商户 |
| 数据来源 | 同首页三源；筛选项取字典 + 商品/店铺字段 |

### 4.2 规则与验收

| 编号 | 内容 |
|---|---|
| F05-4-R1 | 品类为多选 AND 语义：商品需**全部**命中已选品类 |
| F05-4-R2 | 重置 = 清空全部条件回到默认；结果为空给空态 + 引导放宽条件 |
| AC-06 | 选「纱线 + 染料助剂」→ 只出同时涉及两类的商品；无结果时空态可见 |

## 5. 商铺详情 `material-shop-detail.html`

### 5.1 页面说明

| 项 | 内容 |
|---|---|
| 目标 | 看单家原料商铺的资质、主营与在售商品 |
| 数据来源 | 04 商户档案 + 02 资源单元（位置）+ 店铺（品牌/评分）+ 商品 |
| 入口 | 商户列表、地图点位、集采详情 |

### 5.2 字段

| 区块 | 字段 |
|---|---|
| 头部 | 商铺名、横幅、评分、经营年限、距离、位置 |
| 商户信息 | 商户名称、经营地址、入驻时间、**主营品类（多标签）**、联系电话 |
| 在售商品 | 商品卡：图、名、价、单位、起批量、销量 |
| 服务承诺 | 假一赔十、支持打样、当日发货等（取店铺服务项） |

### 5.3 规则与验收

| 编号 | 内容 |
|---|---|
| F05-5-R1 | 主营品类为数组，多标签平铺；单品类时不显示 `+N` |
| F05-5-R2 | 无线上店或无商品时，商品区显示「该商户暂未开通线上商品」 |
| AC-07 | 多品类商户显示全部标签，无 `undefined` |
| AC-08 | 仅线下商户进详情 → 有资料与电话，商品区为空态 |
