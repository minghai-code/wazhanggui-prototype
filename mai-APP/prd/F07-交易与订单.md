## 0. 族通用说明（本族其他页面不再重复）

### 0.1 这个族解决什么问题

把「买什么」变成「钱付了、货到了、有问题能退」：进货单结算 → 支付 → 订单跟踪 → 收货 → 评价/售后，外加收货地址与投诉通道。

不做会怎样：下单链路断在支付，买家付了钱看不到订单状态，出问题只能打电话；平台也拿不到交易数据。

### 0.2 角色与权限

| 角色 | 能看 | 能操作 | 越权表现 |
|---|---|---|---|
| 游客 | 进货单（本机）、订单列表 | 浏览 | 下单/支付/评价 → 原型**不拦**（接口期需登录） |
| 登录买家 | 全部 | 全部 | — |
| 商户账号（同账号体系） | 同上 | 同上（买家视角） | — |

> 本族**所有写操作均未做登录校验**，属有意简化；接口期统一在提交时校验（附录 A-2）。

### 0.5 状态机

| 对象 | 状态 | 转换 | 出口 |
|---|---|---|---|
| 订单 | 待付款 | → 待发货（付款）/ → 已取消（取消或超时） | 去付款 / 取消 |
| 订单 | 待发货 | → 待收货（发货）/ → 退款 | 催发货 / 退款 |
| 订单 | 待收货 | → 已完成（确认收货） | 查看物流 / 确认收货 |
| 订单 | 已完成 | → 待评价 → 已评价 | 去评价 / 追加评价 |
| 订单 | 售后中 | → 售后完成 / 关闭 | 查看进度 |
| 定制单 `CZ`（v1.1） | **待付订金 → 待生产 → 生产中 → 待付尾款 → 待发货** | 付订金 / 商户排产 / 完工质检 / 付尾款；两个「待付」子状态映射主状态「待付款」，其余映射「待发货」 | 去支付订金 / 查看进度 / 支付尾款 / 查看物流 |
| 打样单 `SP` | 待制样 → 已寄样 → 样衣确认（/ 要求改样 round+1） | 商户制样寄出、买家确认；**只有样衣确认才解锁定制单** | 确认样衣 |
| 拼单 `GB` | 待成团 → 已成团（订单转待发货）/ 未成团全额退 | 挂活动状态，成团后逐笔生成订单 | 查看拼单进度 |
| 投诉 | 待受理 → 处理中 → 已回复 → 已关闭 | 后台推进 | 查看进度 |
| 地址 | 普通 / 默认 | 设为默认互斥 | 删除（默认不可删） |

### 0.6 名词与口径

| 名词 | 口径 |
|---|---|
| 起批量 | 商品最小下单量；加购时即强制不低于该值，进货单内手动减量到以下时**行内标黄**并在结算时拦截（✅ A-3） |
| 小计 | 该店铺已勾选商品金额之和（`Σ 单价 × 数量`） |
| 运费 | 按物流方式取值（第三方物流 ¥28） |
| 优惠 | 优惠券固定 `-¥20`；积分 `1,280 分抵 ¥12.80` |
| 实付 | `商品总额 + 运费 − 优惠券 − 积分抵扣` |
| 询价订单金额 | 以**成交报价快照**为准，含运费；样品费 ¥50 可抵货款 |
| 订单类型 | 采购订单（`DD` 开头）/ 询价订单（`QJ` 开头，关联 `XQ` 需求单）/ 拼单订单（`GB`，关联 `T` 团号）/ 打样订单（`SP`，关联 `CP` 需求号）/ 定制订单（`CZ`，关联 `CP` 需求号） |
| 订金（v1.1） | 定制单**订单金额 × 30%**（取整到元），选标成交后支付；未付订金时 `已付订金 = ¥0.00（待支付）` |
| 尾款（v1.1） | `单价 × 数量 − 订金 − 打样费抵扣`；付订金后在详情展示，**发货前支付** |
| 打样费抵扣（v1.1） | 打样单 `SP` 样品费「可抵」时在下单抵扣大货款，**同一笔只抵一次**，抵扣额在订单上留痕，尾款中不再重复收取 |
| 定制单运费（v1.1） | 按报价「是否含运费」落单：含运 → `¥0.00（含运费）`；到付 → 显示实收金额并计入订单总额 |
| 评价 | 总分 1-5 星 + 4 个分项（质量/性价比/物流/服务），内容必填 |

### 0.6.1 跨端字段差异

| 端 | 字段 | 差异 |
|---|---|---|
| 后台 | `orderType` | 五值：`normal / inquiry / group / sample / custom`（与 `M03` §9.3 一致；本页旧描述的两值已作废） |
| 买家端 | URL `type` | `purchase` 缺省；`inquiry` / `group` / `sample` / `custom` 渲染对应详情块（同一 `order-detail.html`） |
| 后台 | CZ 子状态 | 挂主状态，不另设状态表；端上子状态文案与本表五段一一对应 |
| 后台 | `status` | 6 态（含售后） |
| 买家端 | Tab | 6 个（全部/待付款/待发货/待收货/待评价/售后） |
| **术语映射**（2026-11-03 定） | 同状态的两种称谓 | 买家端「**待收货**」＝ 后台「**已发货**」＝ 状态码 `SHIPPED`。**买家端不改成"已发货"**（买方视角看"待我收货"更明确），后台不改（贴合操作视角）；两端按此映射，禁止再出现第三种叫法 |
| 后台 | `freight` | 数值 |
| 买家端 | 「含运费」 | 询价订单文案化，不显示金额（A-6） |
