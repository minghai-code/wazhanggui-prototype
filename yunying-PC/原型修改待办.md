### Y-1. 商城运营「新增商品」：阶梯价 + 是否支持拼单 〔已具备 + 口径已定 · 2026-10-23〕

> **核对结论**：`yunying-PC/mall-product-add.html` 已有 ①「是否支持拼单」开关（支持/不支持）②「阶梯价设置」（统一规格：起始数量 / 结束数量 / 单价，可增删档；多规格：每个规格独立弹层配置）③保存提示已声明"同步到买家端商品详情页"。
> **买家端已按此实现**，本条目不再是待开发，只剩 3 个口径要核。

- **功能模块**：商城运营 → 新增商品（菜单已存在，需核对字段与联动）
- **为什么**：买家端拼单的两个下限都取自这里——**团长与参团人下单均 ≥ 起批数量的 20%**（起批 1000 → 至少 200 双）；商品**未开启「可拼单」**时买家端不展示发起入口。运营端是这套配置的**唯一来源**，商户端没有配置线。
- **关联 PRD**：`开发PRD/买家端app分册PRD/M01-采购询价与拼单集采.md` §8 BR-2 / BR-2a / BR-2b / BR-4
- **精确位置**：`yunying-PC/` 商城运营「新增商品」页（现有菜单位置），具体 DOM 待运营端窗口落位
- **口径已确认（2026-10-23）**：
  1. 区间校验：起始数量必填、多档区间不重叠、高档单价 ≤ 低档
  2. 关掉拼单开关：**存量团继续走完**，只拦新发起
  3. 接口字段：`groupEnabled` / `tier.min`（起始数量）/ `tier.price`；买家端按 `起始数量 × 20%` 算下限
- **补充确认（2026-10-26）**：
  1. **配置主体是商户，不是运营**——后台商城模块与商户共用，商户有电商模块权限即可自行「新增商品 / 商品发布」；运营人员是**监管角色**（审核、下架、纠错）
  2. 阶梯价字段以原型弹窗为准：**起始数量（双）/ 结束数量（双）/ 阶梯单价（元/双）**，可「添加档位」，末档结束数量可为「以上」
  3. **「起批量」是商品独立字段**，与阶梯「起始数量」不是同一个（起始数量可低至 1）——买家端拼单下限取**起批量 × 20%**，请确认商品表单里起批量为必填
- **状态**：配置层与口径已通，只剩接口实现；端上 UI 无需改动
- **验收**：起批 1000 时买家端团长与参团下限均显示 200；关开关后买家端只剩「立即下单」
- **备注**：商户端原 #36 已作废（`shanghu-APP/移动端原型修改待办.md`），商户侧只做外采系统价格同步
