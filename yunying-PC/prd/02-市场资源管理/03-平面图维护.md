## 1. 平面图维护 `resource-floorplan.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 给每层楼挂一张平面图，把档口标到图上，发布后买家端可导览 |
| 使用角色 | 物业（上传/标注）、主管（发布/下线）、其他（只读） |
| 入口 | 菜单 → 市场资源管理 → 平面图维护；或 P2 详情「前往平面图定位」 |
| 前置 | 该楼层已有档口（否则只能标公共设施） |
| 后置 | 发布后买家端「市场导览」即时可见；下线回滚上一版本 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 物业上传图片 + 手工标注点位 |
| 本页操作的跨端影响 | **发布/下线**直接决定买家端楼层图有无；点位决定档口位置与着色 |
| 依赖的其他端页面 | `mai-APP/market-map.html`（楼层 Tab + 档口网格 + 图例） |
| 不涉及的端 | 商户端 |
| 一致性要求 | 发布 ≤5s 生效；下线后买家端回退上一已发布版本 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题 + **「上传 / 替换平面图」**（隐藏 `input[type=file]`，accept 图片）+ 「发布到买家端」 |
| 楼层选择 | 楼栋下拉（A/B/C）+ 楼层 Tab + 右侧当前状态文案 |
| 左（9 栅格） | 图区：工具栏（标注模式 / 清除本层点位 / 撤销）+ 提示条 + 画布（**原型为示意图占位，上传后替换**）+ 图例 5 色 + 坐标说明 |
| 右（3 栅格） | 「本层档口与点位」列表：已标注 / 未标注计数 + 逐条档口（可点定位） |
| 底部 | 版本管理表（7 列）+ 右侧说明「发布后买家端立即可见，可回滚；**历史版本不可删除（审计留痕），只能下线或回滚**」 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 楼层 Tab | 按楼层自然序；当前层高亮 |
| 版本表排序 | 上传时间倒序 |
| 版本表分页 | 不分页（每层版本一般 ≤5） |
| 空结果 | 「该楼层还没有上传平面图」+ 上传按钮 |

### 1.5 字段规格

#### 1.5.1 上传 / 替换

| 项 | 规则 |
|---|---|
| 入口 | 顶部「上传 / 替换平面图」，点击打开文件选择 |
| 格式 | PNG / JPG / SVG（`accept="image/*"`） |
| 上传后 | 生成**新草稿版本**（`vN+1`），不直接影响已发布版本 |
| 已发布版本 | 上传替换不改变买家端，需再次「发布」才生效 |
| 失败提示 | 见 §1.8 |

#### 1.5.2 版本表（7 列）

| 列 | 字段 | 说明 |
|---|---|---|
| 版本 | `ver` | `v1` / `v2`…，自增 |
| 楼层 | `floor` | 如 `1F` |
| 上传时间 | `uploadedAt` | — |
| 上传人 | `uploader` | — |
| 点位 | `pins` | 已标注档口数 / 本层档口数 |
| 状态 | `state` | 草稿 / 已发布 / 历史 |
| 操作 | — | 发布 / 下线 / 回滚 / 预览（按状态显隐）；**不提供删除**——历史版本需留痕可回溯 |

**点位（`pin`）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `unitNo` | 文本 | 关联档口编号；公共设施用类型标识 |
| `x` / `y` | 百分比 | 相对图区左上角，0–100 |
| `w` / `h` | 百分比 | 矩形宽高（框选模式） |

**上传校验**

| 场景 | 提示 | 阻断 |
|---|---|---|
| 非图片文件 | 「仅支持 PNG / JPG / SVG」 | 是 |
| 图片 >10MB | 「图片不能超过 10MB，建议先压缩」 | 是 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 上传 / 替换平面图 | 始终 | 物业 | 选文件 → 生成新草稿版本 | 非图片 → 拒绝 |
| 标注模式 | 始终 | 物业 | 进入标注态，光标十字，点图打点 | 未上传图 → 置灰 |
| 清除本层点位 | 有点位 | 物业 | 二次确认 → 清空当前草稿 | 无点位 → 置灰 |
| 撤销 | 有操作记录 | 物业 | 撤销上一步 | 无可撤销 → 置灰 |
| 发布到买家端 | 有草稿且 ≥1 点位 | 物业/主管 | 二次确认 → 已发布，上一版转历史 | 0 点位 → 「请先标注至少 1 个点位」 |
| 下线 | 状态=已发布 | 物业/主管 | 确认 → 买家端回上一版 | 无历史 → 「下线后买家端将不显示该层」 |
| 回滚 | 有历史版本 | 物业 | 以历史版生成新草稿 | — |
| 点图打点 | 标注模式开启 | — | 弹窗选档口 → 生成点位 | 该档口已标注 → 「该档口已标注，是否移动」 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 | 例外 |
|---|---|---|---|---|---|
| R-15 | 已发布版本不可直接改 | 标注 | 作用于草稿；发布后定版 | 买家端 | — |
| R-16 | 坐标存百分比 | 打点 | 存 x/y/w/h（0–100） | 买家端 | 不随分辨率漂移 |
| R-17 | 同层一个档口只允许 1 个点位 | 打点 | 已存在 → 询问是否移动 | 买家端 | — |
| R-18 | 发布需 ≥1 点位 | 发布 | 拦截 | 买家端 | — |
| R-19 | 下线保留历史可回滚 | 下线 | 买家端回上一已发布版 | 买家端 | 无历史 → 该层不展示 |
| R-21 | 历史版本不可删除 | 任意 | 只可「下线」或「回滚」，无删除入口 | — | 审计要求：平面图是对外展示凭证 |
| R-20 | 点位按 Unit 状态着色 | 渲染 | 空闲/在租/装修中/停用/公共设施 5 色 | 买家端 | 公共设施固定紫色 |

### 1.8 异常与边界

> 完整提示语规格（含未实现项）见分册 **§8.6 提示语规格表**（M-31~M-41）；本表只记录原型实际行为。

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 未上传图就点标注 | 拦截 | 【已实现】「请先上传该楼层平面图」 |
| 数据 | 标注时未选档口 | 提示 | 【已实现】「请先在右侧列表点击「标注」选择档口编号，再点击图上位置」 |
| 数据 | 楼层无档口 | 只可标公共设施 | 【待实现】原型未做该限制 |
| 数据 | 上传非图片 | 拒绝并清空选择 | 【已实现】「仅支持 PNG / JPG / SVG」 |
| 数据 | 图片超 10MB | 拒绝并清空选择 | 【已实现】「图片不能超过 10MB，建议先压缩」 |
| 数据 | 无点位就发布 | 拦截 | 【已实现】「请先标注至少 1 个点位再发布」 |
| 数据 | 有档口未标注就发布 | 二次确认（可继续） | 【已实现】「本层还有 {n} 个档口未标注，未标注档口不会出现在买家端导航中。仍要发布吗？」 |
| 并发 | 两人同时改同层点位 | 后保存者覆盖前提示 | 【待实现】原型无并发校验 |
| 依赖 | 发布后买家端未更新 | 重试 3 次 | 【待实现】原型无同步重试 |
| 边界 | 点位超出图区（x>100） | 自动收敛到边界 | 【待实现】原型未处理越界 |
