1. 平面图维护 resource-floorplan.html

1.1 页面说明

项内容
页面目标给每层楼挂一张平面图，把档口标到图上，发布后买家端可导览
使用角色物业（上传/标注）、主管（发布/下线）、其他（只读）
入口菜单 → 市场资源管理 → 平面图维护；或 P2 详情「前往平面图定位」
前置该楼层已有档口（否则只能标公共设施）
后置发布后买家端「市场导览」即时可见；下线回滚上一版本

1.2 本页端间关系

项内容
本页数据来源物业上传图片 + 手工标注点位
本页操作的跨端影响发布/下线直接决定买家端楼层图有无；点位决定档口位置与着色
依赖的其他端页面mai-APP/market-map.html（楼层 Tab + 档口网格 + 图例）
不涉及的端商户端
一致性要求发布 ≤5s 生效；下线后买家端回退上一已发布版本

1.3 页面结构

区块内容
顶部标题 + 「上传 / 替换平面图」（隐藏 input[type=file]，accept 图片）+ 「发布到买家端」
楼层选择楼栋下拉（A/B/C）+ 楼层 Tab + 右侧当前状态文案
左（9 栅格）图区：工具栏（标注模式 / 清除本层点位 / 撤销）+ 提示条 + 画布（原型为示意图占位，上传后替换）+ 图例 5 色 + 坐标说明
右（3 栅格）「本层档口与点位」列表：已标注 / 未标注计数 + 逐条档口（可点定位）
底部版本管理表（7 列）+ 右侧说明「发布后买家端立即可见，可回滚」

1.4 列表、筛选与排序

项目规则
楼层 Tab按楼层自然序；当前层高亮
版本表排序上传时间倒序
版本表分页不分页（每层版本一般 ≤5）
空结果「该楼层还没有上传平面图」+ 上传按钮

1.5 字段规格

1.5.1 上传 / 替换

项规则
入口顶部「上传 / 替换平面图」，点击打开文件选择
格式PNG / JPG / SVG（accept="image/*"）
上传后生成新草稿版本（vN+1），不直接影响已发布版本
已发布版本上传替换不改变买家端，需再次「发布」才生效
失败提示见 §1.8

1.5.2 版本表（7 列）

列字段说明
版本verv1 / v2…，自增
楼层floor如 1F

上传人uploader—

上传校验

场景提示阻断

1.6 交互规则

元素显示条件可点条件点击后禁止表现
上传 / 替换平面图始终物业选文件 → 生成新草稿版本非图片 → 拒绝
标注模式始终物业进入标注态，光标十字，点图打点未上传图 → 置灰
清除本层点位有点位物业二次确认 → 清空当前草稿无点位 → 置灰
撤销有操作记录物业撤销上一步无可撤销 → 置灰
发布到买家端有草稿且 ≥1 点位物业/主管二次确认 → 已发布，上一版转历史0 点位 → 「请先标注至少 1 个点位」
下线状态=已发布物业/主管确认 → 买家端回上一版无历史 → 「下线后买家端将不显示该层」
回滚有历史版本物业以历史版生成新草稿—
点图打点标注模式开启—弹窗选档口 → 生成点位该档口已标注 → 「该档口已标注，是否移动」

1.7 业务规则与计算口径

编号规则触发处理影响端例外
R-15已发布版本不可直接改标注作用于草稿；发布后定版买家端—
R-16坐标存百分比打点存 x/y/w/h（0–100）买家端不随分辨率漂移
R-17同层一个档口只允许 1 个点位打点已存在 → 询问是否移动买家端—
R-18发布需 ≥1 点位发布拦截买家端—
R-19下线保留历史可回滚下线买家端回上一已发布版买家端无历史 → 该层不展示
R-20点位按 Unit 状态着色渲染空闲/在租/装修中/停用/公共设施 5 色买家端公共设施固定紫色
