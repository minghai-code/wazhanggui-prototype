1.1 页面说明

项内容
页面目标资源单元总台账；合同同步匹配的结果在这里落成"当前租户 + 租期"；异常在这里人工处理
使用角色物业（全操作）、运营（标记/同步/异常）、财务（只读）、合同专员（只读）

1.2 本页端间关系

项内容
本页数据来源物业录入（属性）+ 05 合同事件/兜底同步（状态与租户）+ 物业登记（竞拍）
本页操作的跨端影响装修/停用 → 买家端隐藏该档口、商户端「我的档口」显示装修中；批量导入 → 买家端点位可选
依赖的其他端页面mai-APP/market-map.html（档口着色）、shanghu-APP/property.html（我的档口，待接）
不涉及的端买家端不可见承租人姓名、身份证、空置原因
一致性要求编号全端唯一；状态变更 ≤5s 同步买家端；身份证脱敏不可绕过
