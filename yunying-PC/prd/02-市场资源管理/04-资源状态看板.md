## 1. 资源状态看板 `resource-dashboard.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 一屏回答"还有多少可租、空置多久、合同匹配有没有问题" |
| 使用角色 | 全部角色（只读） |
| 入口 | 菜单 → 市场资源管理 → 资源状态看板 |
| 前置 | 已有档口与合同数据 |
| 后置 | 空置清单可下钻 P2；匹配异常跳 P2 异常 Tab |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | P1/P2/P3 的汇总，**本页不产生新数据** |
| 本页操作的跨端影响 | 无（纯只读） |
| 依赖的其他端页面 | 无直接依赖；统计口径供驾驶舱复用 |
| 不涉及的端 | 商户端、买家端 |
| 一致性要求 | 与 P2 台账同源，数字必须能对上（点进去条数一致） |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 页头 | 标题 + **「数据截至 2026-09-24 02:00」标签** + 说明行（出租率由合同判定，每日同步后刷新）+ 右侧 **「导出报表」** |
| **统计卡（6）** | 出租率（较上月 ±pt）· 可租档口（总数 − 停用）· 空置档口（含空置率）· 平均空置天数（较上月 ±天）· 装修中 · **待处理匹配异常**（红底卡，可点「去处理」） |
| 图表（3） | 出租率趋势（近 12 月折线）· 档口状态分布（环形 + 图例 4 项）· 按楼层出租率对比（条形，可下钻） |
| 图表（1） | 合同同步情况（近 30 日双色柱：同步条数 / 异常条数 + 累计文案 + 口径说明块） |
| 表格（1） | 空置资源清单（8 列，表内滚动 330px，30/60/90 天分级标色） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 空置清单排序 | 空置天数倒序（最久在最上） |
| 筛选 | 无独立筛选条（靠统计卡/楼层条下钻） |
| 分页 | 表内滚动（max-height 330px），不分页 |
| 空结果 | 「当前无空置资源」 |
| 分级标色 | 空置 >30 天黄、>60 天橙、>90 天红 |

### 1.5 字段规格

#### 1.5.1 统计卡（6 个，每个都有口径）

| 卡片 | 数值示例 | 口径 / 副文案 |
|---|---|---|
| 出租率 | 86.3% | 在租 ÷ 可租；副文案「较上月 +0.2pt」 |
| 可租档口 | 1,202 | 总数 − 停用；副文案「总数 1,286 − 停用 84」 |
| 空置档口 | 127 | 状态=空闲；副文案「空置率 10.6%」 |
| 平均空置天数 | 42 | Σ空置天数 ÷ 空闲数，向上取整；副文案「较上月 −6 天」 |
| 装修中 | 38 | 状态=装修中；副文案「物业标记」 |
| **待处理匹配异常** | 3 | 异常状态=待处理；**红底红字**，副文案 `去处理 ›` 跳 P2 异常 Tab |

#### 1.5.2 空置清单（8 列）

| 列 | 字段 | 说明 |
|---|---|---|
| 档口编号 | `no` | 跳 P2 详情 |
| 楼栋楼层 | `b` + `floor` | — |
| 面积(㎡) | `area` | — |
| 原租户 | `lastTenant` | 上一任承租人；从未出租 `—` |
| 空置开始日期 | `vacantFrom` | 合同到期/终止日 |
| 空置天数 | 计算 | 今天 − vacantFrom |
| 跟进状态 | `follow` | 未跟进 / 已联系 / 已带看 / 暂不出租 |
| 操作 | — | 查看详情 / 更新跟进 |

**统计卡口径**

| 卡片 | 公式 | 空值处理 |
|---|---|---|
| 可租档口 | 总数 − 停用 − 公共设施 | — |
| 空置档口 | 状态=空闲 | 空置率 = 空闲 ÷ 可租 |
| 平均空置天数 | Σ空置天数 ÷ 空闲数，向上取整 | 空闲=0 → `—` |
| 装修中 | 状态=装修中 | — |
| 待处理匹配异常 | 异常状态=待处理 | 0 → 隐藏「去处理」 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 导出报表 | 始终 | 物业/主管/财务 | 下载 Excel（资源状态报表） | 无权限 → 置灰 |
| 待处理匹配异常卡 | 始终 | 异常数 >0 | 跳 P2 `?tab=e` | 0 → 不显示「去处理」 |
| 楼层条形 | 始终 | 始终 | 跳 P2 带该楼层筛选 | — |
| 空置行「查看详情」 | 始终 | 始终 | 跳 P2 详情 | — |
| 更新跟进 | 状态≠暂不出租 | 物业/运营 | 下拉 + 备注 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-21 | 看板数字与 P2 同源 | 渲染 | 复用同一统计函数，不重复计算 | 无 |
| R-22 | 空置天数 = 今天 − 空置开始日 | 渲染 | 自然日；当日为 0 | 无 |
| R-23 | 平均空置天数向上取整 | 渲染 | 空置=0 显示 `—` | 无 |
| R-24 | 停用与公共设施不进可租 | 渲染 | 可租 = 总数 − 停用 − 公共设施 | 无 |
| R-25 | 趋势图取近 12 个自然月 | 渲染 | 无数据月份补 0 | 无 |
