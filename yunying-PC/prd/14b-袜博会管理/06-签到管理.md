## 1. 签到管理 `expo-checkin.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 现场入场核销（扫码）+ 手工补录 + **参展商签到台账与后台手工核销** + 未到场标记 |
| 使用角色 | **现场核销**（专职）、运营主管 |
| 入口 | 菜单 → 文商旅管理 → 袜博会 → 签到管理 |
| 前置 | 观众登记已通过（有入场码）；参展商展位申请已通过（已发码） |
| 后置 | 核销记录归档；到场率更新；未核销标记未到场 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 观众：P3 已通过登记的入场码；参展商：P2 审核通过时签发的参展证号 + 签到码 |
| 本页操作的跨端影响 | 观众：核销 → 端上显示"已入场"；参展商：后台核销 → 买家端参展商中心显示"已签到"，重复核销返回首次时间 |
| 依赖的其他端页面 | 买家端入场码 / 参展证（含二维码与签到码）；买家端扫码核销页 `expo-checkin-scan.html` |
| 不涉及的端 | 商户端 |
| 一致性要求 | **核销幂等**（两个 Tab 都是）；核销窗口 = 每日开馆前 1h 至闭馆；参展商**一企业一证**，到场按企业计 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「签到管理」+ 扫码入口 + 导出核销表 + 标记未到场 |
| **Tab 条** | ① 观众签到　② **参展商签到**（2026-10-28 新增）+ 右侧「核销员与核销点」 |
| **统计卡（4）** | 今日核销 / 累计核销 / 登记总数 / 到场率 |
| 筛选区 | 关键词 / 身份类型 / 参观日期 / 核销方式 + 查询 |
| 列表 | **10 列** + 分页 |
| 弹窗 | 手工补签（原因必填） |

#### 1.3.1 参展商签到 Tab（2026-10-28 新增，Y-5）

| 区块 | 内容 |
|---|---|
| 筛选区 | 展位号 / 企业名 / 签到码 · 签到状态 · 导出到场名单 |
| **后台手工核销区** | 三合一输入框（展位号 / 企业名 / 5 位签到码），边输边出候选 → 点选确认 |
| 台账列表 | **8 列**：参展证号 · 签到码 · 企业名称 · 展位号 · 签到时间 · 签到方式 · 核销人 · 操作 |

| 要点 | 说明 |
|---|---|
| 台账口径 | 一行 = **一家企业**（一企业一证）；A01-A02 两个展位共用一行 |
| 输入优先级 | **展位号 > 企业名 > 签到码** —— 展位牌上就有 A01，比让人掏证念码快 |
| 签到码纠错 | 输满 5 位先校验**校验位**，错则提示「格式不对（不含 0/1/I/O）」，不会误报「查无此证」 |
| 核销方式三档 | `扫码核销`（端上扫码）/ `手工补录`（端上手输）/ **`后台手工核销`**（本页） |
| 幂等 | 重复核销返回首次签到时间，不产生第二条记录 |
| 边界 | 后台**只做精确核销 + 台账**：不做扫码枪、不做批量核销、不做连续扫 |

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
