## 1. 资料管理 `expo-material.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 管理展会**官方资料**（可设访问策略）与**展商资料**（需审核） |
| 使用角色 | 文商旅运营专员、运营主管 |
| 入口 | 菜单 → 文商旅管理 → 袜博会 → 资料管理 |
| 前置 | 无 |
| 后置 | 端上可下载（受访问策略约束） |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 专员上传（官方）+ 展商上传（展商资料） |
| 本页操作的跨端影响 | 上架 → 端上可下载；「需登记解锁」→ 端上需已通过参观登记 |
| 依赖的其他端页面 | 买家端资料下载页 |
| 不涉及的端 | 商户端 |
| 一致性要求 | **需登记解锁策略由端上校验**（本模块只设策略） |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「资料管理」+ 分类维护 + 上传资料 |
| **统计卡（4）** | 官方资料 / 展商资料待审 / 累计下载 / 需登记解锁 |
| **Tab 条（2）** | 官方资料 / 展商资料 |
| Tab 官方资料 | 表（**8 列**） |
| Tab 展商资料 | 表（**8 列**） |
| 抽屉 | 上传 / 编辑（名称 / 描述 / 格式 / 访问策略 / 分类） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 上传时间倒序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 访问策略 | 公开 / 需登记解锁 |
| 空结果 | **无空态提示**（待补） |

### 1.5 字段规格

**官方资料（8 列）**：资料名称 · 描述 · 格式 · 大小 · 访问策略 · 下载次数 · 状态 · 操作

**展商资料（8 列）**：资料名称 · 所属展商 · 类型（厂家介绍 / 商品名录 / **展位效果图**）· 版本 · 格式 · 更新时间 · 状态 · 操作

> **本页是展商资料的唯一审核台**：P4「参展商管理」不做审核，只按展商汇总状态并跳转到这里（`?tab=m&exh={展商名}` 自动切 Tab + 按展商筛选，顶部显示筛选条）。
> **展位效果图纳入本页（原缺口补齐）**：此前效果图只在 P4 详情里显示「待审核」，但不属于本页资料类型，导致该文件长期悬空无人可审。现与厂家介绍、商品名录同队列。
> 审核要点：效果图不得含二维码、联系方式、未授权品牌标识。

| 关键字段 | 说明 |
|---|---|
| `access` | 公开 / 需登记解锁 |
| `state` | 草稿 / 已发布 / 已下架 |
| `downloads` | 累计下载次数（端上报） |
| `version` | 展商资料版本（展商可重传） |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 上传资料 | 始终 | 专员/主管 | 抽屉（含大小/格式校验） | 超限 → 拦截 |
| 上架 / 下架 | 始终 | 专员/主管 | 端上可下载 / 不可下载 | — |
| 预览 | 有文件 | 同上 | 在线预览 | — |
| 分类维护 | 始终 | 同上 | 增删分类 | — |
| 展商资料审核 | 状态=待审核 | 同上 | 通过后对外；**驳回原因必填（≥ 2 字）** | 空原因驳回 → 拦截 |
| 按展商筛选 | 带 `?exh=` 参数进入 | 同上 | 只显示该展商资料 + 顶部筛选条 + 清除筛选 | 筛选态下计数按可见行统计 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-34 | 需登记解锁 = 端上校验登记状态 | 下载 | 本模块只设策略 | 端上 |
| R-35 | 展商资料需审核才对外 | 上传 | 待审核 → 通过；**驳回必填原因** | 端上 |
| R-38 | 审核写入方唯一 | 任何审核动作 | **只在 P7 发生**；P4 参展商管理只读 + 跳转 | 端上 |
| R-39 | 三类资料同队列 | 上传 | 厂家介绍 / 商品名录 / 展位效果图 走同一审核链路与同一 `资料状态` 字段 | 端上 |
| R-40 | 待审数三处同源 | 审核通过 / 驳回 | 统计卡 + Tab 徽标 + 列表标题同步递减 | — |
| R-36 | 下架不删文件 | 下架 | 保留历史与下载数 | — |
| R-37 | 下载次数端上报 | 下载 | 累加 | 本模块统计 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 未登记下载受限资料 | 端上拦截（运营端只设策略，**不在本页校验**；端上改造见 mai-APP 待办 #23） | — |
| 数据 | 文件超大小限制 | 拦截 | 【待实现】应提示上限 |
| 数据 | 展商资料未审核 | 端上不展示 | — |
| 交互 | 驳回未填原因 | 拦截，抽屉不关闭 | 驳回需填写原因（不少于 2 个字） |
| 数据 | 展位效果图 | 归入展商资料第三类，与其余两类同队列 | — |
