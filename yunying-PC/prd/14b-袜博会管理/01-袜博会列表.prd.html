0. 模块通用说明（本模块其他页面不再重复）

0.1 这个模块解决什么问题

展会筹备靠 Excel 划展位、缴费靠财务对账、观众靠纸质登记：展位重复卖、钱收没收到说不清、来了多少人不知道。 本模块把「届次配置 → 展位申请 → 缴费确认 → 参观登记 → 现场核销 → 存档回顾」串成一条线，以届次隔离数据。

不做：展位靠白板贴纸条；观众到场靠门口点数；往届数据散落各处无法复盘。

0.5 状态机

① 展位申请单（7 态）：待审核 → 已通过（待缴费）→ 已缴费（待确认）→ 已确认；另有 候补 / 已驳回 / 已取消

② 参观登记单（6 态）：待审核 → 已通过（生成入场码）→ 已核销；另有 已驳回 / 未到场 / 已取消

③ 展位（3 态）：可选 / 已售 / 锁定（"临时预占"为逻辑态，不落库）

④ 届次（5 态）：筹备中 / 报名中 / 进行中 / 已结束 / 已归档

stateDiagram-v2
    [*] --> 待审核: 展商提交（预占展位）
    待审核 --> 已通过待缴费: 主管终审通过
    待审核 --> 候补: 库存不足
    待审核 --> 已驳回: 资质不符（释放预占）
    候补 --> 待审核: 有展位释放
    已通过待缴费 --> 已缴费待确认: 展商缴费
    已通过待缴费 --> 已取消: 逾期 7 天自动取消（释放展位）
    已缴费待确认 --> 已确认: 财务确认收款（锁定展位）
    已确认 --> 已取消: 退展（主管，按退款规则）
