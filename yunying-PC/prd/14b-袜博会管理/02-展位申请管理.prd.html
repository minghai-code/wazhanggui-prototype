1. 展位申请管理 expo-booth.html

1.1 页面说明

项内容
页面目标处理展商展位申请：初核 → 终审 → 缴费 → 确认锁定
使用角色专员（初核）、主管（终审）、财务（缴费确认）
入口菜单 → 文商旅管理 → 袜博会 → 展位申请管理
前置本届已配置展位（P1）
后置确认后生成参展商（P4），展位锁定为「已售」

1.2 本页端间关系

项内容
本页数据来源展商在买家端提交（展位号由展商自选，随申请单携带）
本页操作的跨端影响终审通过 → 端上进入"缴纳费用"；确认收款 → 端上"确认展位"完成
依赖的其他端页面买家端展位申请页 / 展位图
不涉及的端商户端（展商申请走买家端口径）
一致性要求提交即预占展位，驳回/逾期释放

1.3 页面结构

区块内容
顶部标题「展位申请管理」+ 批量通过 + 导出
统计卡（4）待审核 / 待缴费 / 已确认展位 / 展位销售率
Tab 条（3）待审批 / 已通过 / 已驳回（各带数量角标）
筛选区关键词 / 展位类型 / 状态 / 提交时间 + 查询
列表11 列 + 分页
抽屉申请详情（企业资质 / 展位 / 金额 / 审核记录 / 缴费记录）

1.6 交互规则

元素显示条件可点条件点击后禁止表现

终审通过待审核（已初核）主管待缴费 + 通知缴费专员 → 隐藏
驳回待审核专员/主管必填原因 + 释放预占—
转候补待审核 + 库存不足主管进候补队列—
确认收款待缴费财务已确认 + 锁定展位 + 推参展须知非财务 → 隐藏
批量通过有勾选主管（终审）/专员（初核）逐条校验含库存不足 → 转候补

类型场景系统行为提示文案
