项内容
页面目标维护展会日程与议程（时间 / 标题 / 地点 / 嘉宾 / 亮点），发布后同步端上
使用角色文商旅运营专员、运营主管

前置届次已创建

1.2 本页端间关系

项内容
本页数据来源专员录入
本页操作的跨端影响发布 → 端上日程可见；变更 → 可向已登记观众推通知
依赖的其他端页面买家端展会日程 / 议程详情
不涉及的端商户端
一致性要求议程时间不得重叠冲突（同地点）
