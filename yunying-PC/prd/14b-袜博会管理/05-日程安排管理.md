## 1. 日程安排管理 `expo-schedule-manage.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 维护展会日程与议程（时间 / 标题 / 地点 / 嘉宾 / 亮点），发布后同步端上 |
| 使用角色 | 文商旅运营专员、运营主管 |
| 入口 | 菜单 → 文商旅管理 → 袜博会 → 日程安排管理 |
| 前置 | 届次已创建 |
| 后置 | 发布后买家端即时可见；变更可推送通知 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 专员录入 |
| 本页操作的跨端影响 | 发布 → 端上日程可见；变更 → 可向已登记观众推通知 |
| 依赖的其他端页面 | 买家端展会日程 / 议程详情 |
| 不涉及的端 | 商户端 |
| 一致性要求 | 议程时间不得重叠冲突（同地点） |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「日程安排管理」+ 新增议程 + 发布 |
| **统计卡** | **无**（议程编辑页，指标无意义） |
| 列表 | **8 列**（排序 / 时间 / 议程标题 / 地点 / 类型 / 嘉宾说明 / 状态 / 操作） |
| 抽屉 | 议程编辑（时间 / 标题 / 地点 / 类型 / 嘉宾 / 亮点） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 排序号升序，其次时间 |
| 分页 | 不分页 |
| 类型 | 开幕式 / 论坛 / 对接会 / 发布秀 / 其他 |
| 空结果 | **无空态提示**（待补） |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 排序 | `sort` | 手动序号 |
| 时间 | `startTime`~`endTime` | — |
| 议程标题 | `title` | — |
| 地点 | `venue` | 场馆内具体位置 |
| 类型 | `type` | 五类 |
| 嘉宾/说明 | `speaker` / `desc` | — |
| 状态 | `state` | 草稿 / 已发布 / 已取消 |
| 操作 | — | 编辑 / 发布 / 删除 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新增/编辑议程 | 始终 | 专员/主管 | 抽屉 | 时间重叠（同地点）→ 拦截 |
| 保存 | 抽屉 | 同上 | 存草稿 | — |
| **发布** | 草稿 | 同上 | 端上即时更新 | — |
| 添加亮点 / 嘉宾 | 编辑态 | 同上 | 追加条目 | — |
| 删除 | 草稿 | 同上 | 删除议程 | 已发布 → 只能取消 |
| 发送变更通知 | 已发布且已改 | 同上 | 向已登记观众推送 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-24 | 同地点时间不可重叠 | 保存 | 拦截 | — |
| R-25 | 发布即时同步端上 | 发布 | 无需二次审核 | 端上 |
| R-26 | 已发布议程变更可推通知 | 变更 | 向已登记观众发送 | 端上 |
| R-27 | 已发布不可删只可取消 | 删除 | 状态置已取消 | 端上 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 时间重叠 | 拦截 | 【待实现】应提示冲突议程 |
| 数据 | 已发布删议程 | 拦截 | 【待实现】应提示改为取消 |
| 数据 | 无议程 | **无空态提示**（待补） | — |

### 1.9 通知与消息

| 事件 | 接收人 | 渠道 | 抑制条件 |
|---|---|---|---|
| 日程发布 | 已登记观众（可选） | 站内 + 短信 | 一次 |
| 议程变更 | 已登记观众 | 站内 + 短信 | 每议程一次 |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-23 | 草稿议程 | 点发布 | 端上日程即时出现 | P0 |
| AC-24 | 已发布议程改时间 | 点发送变更通知 | 已登记观众收到通知 | P0 |
| AC-25 | 已发布议程 | 点删除 | 【待实现】应拦截或转取消 | P1 |
| AC-26 | 同地点时间重叠 | 保存 | 【待实现】应拦截 | P1 |
