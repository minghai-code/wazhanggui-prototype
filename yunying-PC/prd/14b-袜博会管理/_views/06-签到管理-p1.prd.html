1. 签到管理 expo-checkin.html

1.1 页面说明

项内容
页面目标现场入场核销（扫码）+ 手工补录 + 未到场标记
使用角色现场核销（专职）、运营主管
入口菜单 → 文商旅管理 → 袜博会 → 签到管理
前置观众登记已通过（有入场码）
后置核销记录归档；到场率更新；未核销标记未到场

1.2 本页端间关系

项内容
本页数据来源P3 已通过登记的入场码
本页操作的跨端影响核销 → 观众端显示"已入场"；重复扫码 → 端上提示已核销时间
依赖的其他端页面买家端入场码（含二维码）
不涉及的端商户端
一致性要求核销幂等；核销窗口 = 每日开馆前 1h 至闭馆

顶部标题「签到管理」+ 扫码入口 + 导出核销表 + 标记未到场
