1. 资料管理 expo-material.html

1.1 页面说明

项内容
页面目标管理展会官方资料（可设访问策略）与展商资料（需审核）
使用角色文商旅运营专员、运营主管
入口菜单 → 文商旅管理 → 袜博会 → 资料管理
前置无
后置端上可下载（受访问策略约束）

1.2 本页端间关系

项内容
本页数据来源专员上传（官方）+ 展商上传（展商资料）
本页操作的跨端影响上架 → 端上可下载；「需登记解锁」→ 端上需已通过参观登记
依赖的其他端页面买家端资料下载页
不涉及的端商户端
一致性要求需登记解锁策略由端上校验（本模块只设策略）

1.3 页面结构

区块内容
顶部标题「资料管理」+ 分类维护 + 上传资料
统计卡（4）官方资料 / 展商资料待审 / 累计下载 / 需登记解锁
Tab 条（2）官方资料 / 展商资料
Tab 官方资料表（8 列）
Tab 展商资料表（8 列）
抽屉上传 / 编辑（名称 / 描述 / 格式 / 访问策略 / 分类）

1.4 列表、筛选与排序

项目规则
默认排序上传时间倒序
分页不分页
筛选组合条件之间 且
访问策略公开 / 需登记解锁
空结果无空态提示（待补）

1.5 字段规格

官方资料（8 列）：资料名称 · 描述 · 格式 · 大小 · 访问策略 · 下载次数 · 状态 · 操作

展商资料（8 列）：资料名称 · 所属展商 · 类型 · 版本 · 格式 · 更新时间 · 状态 · 操作

关键字段说明
access公开 / 需登记解锁
state草稿 / 已发布 / 已下架
downloads累计下载次数（端上报）
version展商资料版本（展商可重传）

1.6 交互规则

元素显示条件可点条件点击后禁止表现
上传资料始终专员/主管抽屉（含大小/格式校验）超限 → 拦截
上架 / 下架始终专员/主管端上可下载 / 不可下载—
预览有文件同上在线预览—
分类维护始终同上增删分类—
展商资料审核展商资料待审核同上通过后对外—

1.7 业务规则与计算口径

编号规则触发处理影响端
R-34需登记解锁 = 端上校验登记状态下载本模块只设策略端上
R-35展商资料需审核才对外上传待审核 → 通过端上
R-36下架不删文件下架保留历史与下载数—
R-37下载次数端上报下载累加本模块统计

1.8 异常与边界

类型场景系统行为提示文案

数据文件超大小限制拦截【待实现】应提示上限
