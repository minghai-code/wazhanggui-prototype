1. 参观申请管理 expo-visitor.html

1.1 页面说明

项内容
页面目标审核观众参观登记，通过后生成入场码并短信下发
使用角色文商旅运营专员、运营主管
入口菜单 → 文商旅管理 → 袜博会 → 参观申请管理
前置观众在买家端登记
后置入场码可用于现场核销（P6）；资料下载解锁
与端上现状的差异：买家端原型为"提交即出证"（无审核），本模块要求「提交 = 待审核，通过后再发码」。端上需改造（见 §0.6.1）。

1.2 本页端间关系

项内容
本页数据来源买家端观众登记
本页操作的跨端影响通过 → 端上收到入场码短信；驳回 → 端上显示驳回原因
依赖的其他端页面买家端登记页 / 入场码
不涉及的端商户端
一致性要求入场编号 V+年+届次+4位流水；通过状态是资料解锁的前置

1.3 页面结构

区块内容
顶部标题「参观申请管理」+ 导出观众名单 + 批量通过
统计卡（5）登记总数 / 待审核 / 已通过 / 已核销 / 到场率
Tab 条（3）待审批 / 已通过 / 已驳回（各带数量角标）
筛选区关键词 / 身份类型 / 关注品类 / 参观日期 / 状态 + 查询
列表10 列 + 分页
抽屉登记详情（身份 / 企业 / 关注品类 / 审核记录）
