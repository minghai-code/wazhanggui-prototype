## 1. 往期存档回顾 `expo-archive.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 历届展会**存档报告**的生成、导出与复用（复制为下届模板） |
| 使用角色 | 文商旅运营主管（**仅主管可生成**） |
| 入口 | 菜单 → 文商旅管理 → 袜博会 → 往期存档回顾；也从 P1「生成存档」跳入 |
| 前置 | 对应届次已结束 |
| 后置 | 存档报告可导出 PDF；可复制为新届模板 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 已结束届次的统计数据（展位 / 展商 / 观众 / 到场） |
| 本页操作的跨端影响 | 存档报告可同步买家端「往届回顾」页展示 |
| 依赖的其他端页面 | 买家端往届回顾页 |
| 不涉及的端 | 商户端 |
| 一致性要求 | **展会结束才可生成完整存档** |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「往期存档回顾」 |
| **统计卡（4）** | 已归档届次 / 累计展商 / 累计观众 / 平均到场率 |
| 列表 | **11 列** |
| 抽屉 | 存档报告（数据摘要 / 人工补充编辑 / 导出 PDF） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 年份倒序 |
| 分页 | 不分页 |
| 存档状态 | 未生成 / 已生成 / 已归档 |
| 空结果 | **无空态提示**（待补） |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 届次 | `edition` | 第 N 届 |
| 年份 | `year` | — |
| 展会名称 | `name` | — |
| 起止日期 | `start`~`end` | — |
| 展位售出率 | `soldRate` | 已售 ÷ 总数 |
| 展商数 | `exhibitors` | — |
| 观众登记 | `visitors` | — |
| 实际到场 | `attended` | 已核销数 |
| 资料下载 | `downloads` | — |
| 存档状态 | `archiveState` | 未生成 / 已生成 / 已归档 |
| 操作 | — | 生成 / 导出 / 复制为模板 / 补充编辑 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 生成存档 | 届次已结束 | **主管** | 生成报告（含统计快照） | 未结束 → E-42 |
| 人工补充编辑 | 已生成 | 主管 | 进入编辑模式补文字 | — |
| 导出报告 | 已生成 | 主管 | 导出 PDF / Excel | — |
| 复制为下届模板 | 已归档 | 主管 | 生成新届草稿 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-38 | 未结束不可生成 | 生成 | 拦截 | — |
| R-39 | 报告含统计快照 | 生成 | 固化当届数据，不随后续变更 | — |
| R-40 | 补充编辑只改文字 | 编辑 | 不改统计数字 | — |
| R-41 | 复制模板不复制展商 | 复制 | 只复制配置（类型/区域/栏目） | — |
| R-42 | 平均到场率 | 渲染 | Σ到场 ÷ Σ登记 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 展会未结束生成 | 拦截 | 【已实现】展会结束后可生成完整存档 |
| 数据 | 未生成就导出 | 按钮置灰 | — |
| 数据 | 无历史届次 | **无空态提示**（待补） | — |

### 1.9 通知与消息

本页不发通知（归档类）。

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-37 | 展会进行中 | 点生成存档 | 拦截提示展会结束后可生成 | P0 |
| AC-38 | 已结束届次 | 点生成存档 | 生成报告，含当届统计快照 | P0 |
| AC-39 | 已归档届次 | 点复制为下届模板 | 生成新届草稿，**不含展商与申请** | P0 |
| AC-40 | 生成报告后代观众数据变化 | 查看报告 | 数字不变（快照固化） | P1 |
| AC-41 | 已生成报告 | 点人工补充编辑 | 仅可改文字，不可改统计 | P1 |
