## 1. 展位申请管理 `expo-booth.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 处理展商展位申请：初核 → 终审 → 缴费 → 确认锁定 |
| 使用角色 | 专员（初核）、主管（**终审**）、财务（**缴费确认**） |
| 入口 | 菜单 → 文商旅管理 → 袜博会 → 展位申请管理 |
| 前置 | 本届已配置展位（P1） |
| 后置 | 确认后生成参展商（P4），展位锁定为「已售」 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 展商在买家端提交（**展位号由展商自选，随申请单携带**） |
| 本页操作的跨端影响 | 终审通过 → 端上进入"缴纳费用"；确认收款 → 端上"确认展位"完成 |
| 依赖的其他端页面 | 买家端展位申请页 / 展位图 |
| 不涉及的端 | 商户端（展商申请走买家端口径） |
| 一致性要求 | 提交即**预占**展位，驳回/逾期释放 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「展位申请管理」+ 批量通过 + 导出 |
| **统计卡（4）** | 待审核 / 待缴费 / 已确认展位 / 展位销售率 |
| **Tab 条（3）** | 待审批 / 已通过 / 已驳回（各带数量角标） |
| 筛选区 | 关键词 / 展位类型 / 状态 / 提交时间 + 查询 |
| 列表 | **11 列** + 分页 |
| 抽屉 | 申请详情（企业资质 / 展位 / 金额 / 审核记录 / 缴费记录） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 提交时间正序 |
| 分页 | 页码 |
| 筛选组合 | 条件之间 **且** |
| 状态 | 待审核 / 候补 / 待缴费 / 待确认 / 已确认 / 已驳回 / 已取消 |
| 空结果 | **无空态提示**（待补） |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 初核通过 | 待审核 | 专员/主管 | 标记初核 | — |
| **终审通过** | 待审核（已初核） | **主管** | 待缴费 + 通知缴费 | 专员 → 隐藏 |
| 驳回 | 待审核 | 专员/主管 | 必填原因 + **释放预占** | — |
| 转候补 | 待审核 + 库存不足 | 主管 | 进候补队列 | — |
| **确认收款** | 待缴费 | **财务** | 已确认 + **锁定展位** + 推参展须知 | 非财务 → 隐藏 |
| 批量通过 | 有勾选 | 主管（终审）/专员（初核） | 逐条校验 | 含库存不足 → 转候补 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-07 | 提交即预占展位 | 申请 | 临时预占（逻辑态），他人不可选 | 端上展位图 |
| R-08 | 终审通过才可缴费 | 终审 | 通知缴费 | 端上 |
| R-09 | **7 天未缴自动取消** | 定时 | 释放展位 + 通知候补 | 端上 |
| R-10 | 缴费需财务确认 | 确认 | 展位锁定「已售」 | 端上 |
| R-11 | 驳回释放预占 | 驳回 | 展位回「可选」 | 端上 |
| R-12 | 已确认只能退展 | 回退 | 走退展流程 | — |
| R-13 | 金额 = 类型单价 × 数量 | 渲染 | 不手工改 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 终审通过未确认展位号 | 拦截（读申请单「展位号（展商自选）」） | 【已实现】「请先确认展位号（买家端自选，随申请单携带）」 |
| 数据 | 逾期未缴 | 「检测逾期未缴」扫描后自动取消并释放 | 【已实现】「检测到 {n} 条逾期未缴（>7 天），已自动取消并释放展位…」 |
| 数据 | 库存不足 | 转候补 | — |
| 权限 | 专员点终审 | 按钮隐藏 | — |

### 1.9 通知与消息

| 事件 | 接收人 | 渠道 | 抑制条件 |
|---|---|---|---|
| 申请提交 | 专员 | 短信 + 站内 | 合并 |
| 终审通过 | 展商 | 短信（含缴费指引与时限） | 一次 |
| 缴费到期前 3 天 / 1 天 | 展商 | 短信 | 每档一次 |
| 逾期取消 | 展商 + 候补队列 | 短信 | 一次 |
| 确认收款 | 展商 | 短信（含参展须知） | 一次 |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-07 | 待审核申请 | 专员账号终审 | 无终审按钮 | P0 |
| AC-08 | 待审核（已初核） | 主管终审通过 | 状态待缴费，展商收到缴费短信 | P0 |
| AC-09 | 待缴费 | 财务确认收款 | 状态已确认，展位锁定，生成参展商 | P0 |
| AC-10 | 待缴费超 7 天 | 系统扫描 | 【待实现】应自动取消并释放 | P0 |
| AC-11 | 驳回申请 | 查看展位 | 展位回「可选」，他人可选 | P1 |
| AC-12 | 同一展位两人同时申请 | 第二人提交 | 预占冲突，提示已被占用 | P1 |
