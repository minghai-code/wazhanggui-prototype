## 1. 参展商管理 `expo-exhibitor.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 管理已确认展商：资料审核、缴费确认、精选推荐、名录维护 |
| 使用角色 | 文商旅运营专员、运营主管 |
| 入口 | 菜单 → 文商旅管理 → 袜博会 → 参展商管理 |
| 前置 | P2 展位申请已确认收款 |
| 后置 | 展商名录同步买家端；资料审核通过后可见 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | P2 确认后自动生成 + 展商在端上补充资料 |
| 本页操作的跨端影响 | 精选 → 端上名录置顶；资料通过 → 端上展商详情可见资料 |
| 依赖的其他端页面 | 买家端展商名录 / 展商详情 |
| 不涉及的端 | 商户端 |
| 一致性要求 | 展位号唯一；资料审核通过才对外展示 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「参展商管理」+ 导出名录 + 新增展商 |
| **统计卡（4）** | 展商总数 / 资料待审核 / 精选展商 / 已缴费确认 |
| 筛选区 | 关键词 / 类目 / 展位 / 缴费状态 / 资料状态 + 查询 |
| 列表 | **11 列** + 分页 |
| 抽屉 | 展商详情（企业信息 / 展位 / 缴费 / 资料 / 操作留痕） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 精选优先 + 展位号升序 |
| 分页 | 页码 |
| 筛选组合 | 条件之间 **且** |
| 状态 | 启用 / 停用 |
| 空结果 | **无空态提示**（待补） |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 展商名称 | `name` | — |
| 类目标签 | `tags[]` | 多选 |
| 展位号 | `boothNo` | **唯一** |
| 主营品类 | `products` | — |
| 联系人 / 电话 | `contact` / `phone` | 脱敏 |
| **缴费状态** | `payState` | 未缴 / 已缴 / 已确认 |
| **资料状态** | `docState` | 草稿 / 待审核 / 已发布 / 已驳回 |
| 精选 | `featured` | 端上置顶 |
| 状态 | `state` | 启用 / 停用 |
| 操作 | — | 编辑 / 资料审核 / 缴费提醒 / 精选 / 确认收款 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 编辑 | 始终 | 专员/主管 | 抽屉 | 展位号重复 → 拦截 |
| 资料审核通过 | 资料=待审核 | 专员/主管 | 端上展示展商资料 | — |
| 缴费提醒 | 未缴/已缴未确认 | 专员/主管 | 短信提醒 | — |
| 确认收款 | 已缴待确认 | **财务** | 缴费状态已确认 | 非财务 → 隐藏 |
| 精选 / 取消 | 已确认 | 专员/主管 | 端上置顶 / 取消 | — |
| 启用 / 停用 | 始终 | 专员/主管 | 名录显示控制 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-19 | 展位号唯一 | 保存 | 重复拦截 | — |
| R-20 | 资料通过才对外 | 审核 | 端上展商详情可见 | 端上 |
| R-21 | 精选置顶 | 精选 | 端上排序优先 | 端上 |
| R-22 | 停用不出现在名录 | 停用 | 端上隐藏，数据保留 | 端上 |
| R-23 | 缴费状态与申请单强一致 | 任何来源 | 以 P2 为准 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 展位号重复 | 拦截 | 【待实现】应提示展位号已被占用 |
| 数据 | 资料未审核 | 端上不展示 | — |
| 依赖 | 展商未提交资料 | 名录仅显示基础信息 | — |
