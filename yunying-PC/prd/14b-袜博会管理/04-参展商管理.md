## 1. 参展商管理 `expo-exhibitor.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 管理已确认展商：**资料状态汇总（审核在 P7 资料管理）**、缴费确认、名录维护 |
| 使用角色 | 文商旅运营专员、运营主管 |
| 入口 | 菜单 → 文商旅管理 → 袜博会 → 参展商管理 |
| 前置 | P2 展位申请已确认收款 |
| 后置 | 展商名录同步买家端；资料状态取自 P7，本页只读展示 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | P2 确认后自动生成 + 展商在端上补充资料 |
| 本页操作的跨端影响 | **上首页由 P1 展示管理决定，本页只读**；资料审核结果由 P7 产出，本页只做跳转 |
| 依赖的其他端页面 | 买家端展商名录 / 展商详情 |
| 不涉及的端 | 商户端 |
| 一致性要求 | 展位号唯一；资料审核通过才对外展示，**写入方唯一 = P7 资料管理** |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「参展商管理」+ 导出名录 + 新增展商 |
| **统计卡（4）** | 展商总数 / **资料待审核**（与 P7 同源，卡内「去审核」跳 P7）/ **上首页**（只读，来自 P1 展示管理）/ **已缴费（线下登记）** |
| 筛选区 | 关键词 / 类目 / 展位 / 缴费状态 / 资料状态 + 查询 |
| 列表 | **11 列** + 分页 |
| 抽屉 | 展商详情（企业信息 / 展位 / 缴费 / 资料 / 操作留痕） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 上首页优先 + 展位号升序 |
| 分页 | 页码 |
| 筛选组合 | 条件之间 **且** |
| 状态 | 启用 / 停用 |
| 空结果 | **无空态提示**（待补） |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 展商名称 | `name` | — |
| 类目标签 | `tags[]` | 多选 |
| 展位号 | `boothNo` | **唯一** |
| 主营品类 | `products` | — |
| 联系人 / 电话 | `contact` / `phone` | 脱敏 |
| **缴费状态** | `payState` | 未缴 / 已缴 / 已确认 |
| **资料状态** | `docState` | 草稿 / 待审核 / 已发布 / 已驳回 |
| **上首页** | `featured` | 只读；来自 P1「展示管理」，本页不可勾选 |
| 状态 | `state` | 启用 / 停用 |
| 操作 | — | 编辑 / **去审核**（跳 P7，已按该展商筛选）/ 缴费提醒 / 确认收款 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 编辑 | 始终 | 专员/主管 | 抽屉 | 展位号重复 → 拦截 |
| **去审核** | 资料状态=待审核 | 专员/主管 | 跳转 `资料管理?tab=m&exh={展商名}`，本页不弹审核界面 | 不得在本页直接改资料状态 |
| 缴费提醒 | 未缴/已缴未确认 | 专员/主管 | 短信提醒 | — |
| 确认收款 | 已缴待确认 | **财务** | 缴费状态已确认 | 非财务 → 隐藏 |
| ~~精选 / 取消~~ | — | — | **已移除**：改由 P1「展示管理」勾选与排序 | 本页不得出现该操作 |
| 启用 / 停用 | 始终 | 专员/主管 | 名录显示控制 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-19 | 展位号唯一 | 保存 | 重复拦截 | — |
| R-20 | 资料通过才对外 | 审核 | 端上展商详情可见 | 端上 |
| R-21 | 上首页由 P1「展示管理」**唯一决定** | 展示管理保存 | 端上排序优先；本页只读同步 | 端上 |
| R-22 | 停用不出现在名录 | 停用 | 端上隐藏，数据保留 | 端上 |
| R-23 | 缴费状态与申请单强一致 | 任何来源 | 以 P2 为准 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 展位号重复 | 拦截 | 【待实现】应提示展位号已被占用 |
| 数据 | 资料未审核 | 端上不展示 | — |
| 依赖 | 展商未提交资料 | 名录仅显示基础信息 | — |
