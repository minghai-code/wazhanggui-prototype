1. 公告通知 content-notice.html

1.1 页面说明

项内容
页面目标平台公告的定向发布与多端触达（可同步生成推送任务）
使用角色内容运营专员、运营主管、物业（仅物业类公告）
入口菜单 → 内容管理 → 公告通知
前置已配置公告类投放位
后置发布后 → 买家端消息中心、商户端通知公告 + 工作台；勾选同步推送则生成推送任务

1.2 本页端间关系

项内容
本页数据来源运营 / 物业手工录入
本页操作的跨端影响发布 → 买家端 messages.html + 商户端 notice-detail.html 与工作台最新 3 条；置顶 → 端上显著位置
依赖的其他端页面mai-APP/messages.html、shanghu-APP/notice-detail.html、shanghu-APP/index-app-shanghu.html
不涉及的端—
一致性要求通知对象过滤在端上生效（仅商户 / 仅买家 / 全平台）；历史公告长期可查

1.3 页面结构

区块内容
顶部标题「公告通知」+ 「导出」「新增公告」
统计卡生效中 / 待发布（定时未到）/ 待审核 / 置顶使用（上限 3）/ 联动消息推送
筛选区关键词 + 通知对象（全平台 / 仅买家 / 仅商户）+ 类别 + 状态 + 生效期 + 是否置顶 + 查询 + 重置
列表8 列 + 分页
投放位表6 列（公告专用位，自动带出）
抽屉标题 / 正文 / 通知对象 / 置顶 / 有效期 / ☑ 同步推送消息

1.4 列表、筛选与排序

项目规则
默认排序置顶优先，其次最近更新倒序
分页页码（原型演示 2 页）
筛选组合条件之间 且
通知对象筛选全平台 / 仅买家 / 仅商户
空结果端上"暂无公告"
导出含通知对象、置顶、有效期、推送记录、已读率

公告列表（8 列）

列字段说明

1.6 交互规则

元素显示条件可点条件点击后禁止表现

1.7 业务规则与计算口径

编号规则触发处理影响端
R-09投放位随通知对象自动带出切换对象不用手选，避免错投两端
R-10置顶上限默认 3 条置顶超限拦截端上排序

R-13历史公告长期可查过期后不物理删除，只下线两端
