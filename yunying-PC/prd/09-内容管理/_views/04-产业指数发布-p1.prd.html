1. 产业指数发布 content-index.html

1.1 页面说明

项内容
页面目标录入 / 导入客户线下每年发布的产业指数（本期不做自动计算与图表）
使用角色内容运营专员（主力）、运营主管
入口菜单 → 内容管理 → 产业指数发布
前置无（一年一期，手工录入）
后置发布后供端上消费（消费位待确认，见分册 §10-2）

1.2 本页端间关系

项内容
本页数据来源客户线下发布稿（PDF / Excel）+ 运营手工录入
本页操作的跨端影响当前无端上消费位（买家端"行情参考"与驾驶舱均待确认）
依赖的其他端页面无
依赖的运营端模块11 原料市场（价格指数的口径来源）
一致性要求数值与客户发布稿一致；口径说明必填（否则下游无法解释数据）

1.3 页面结构

区块内容
顶部标题「产业指数发布」+ 「导入模板」「导出」「新增年度期次」
统计卡已发布期次 / 待发布 / 草稿或未完成 / 附件总数（客户发布稿）
筛选区指数类型（原料价格 / 景气 / 创新 / 趋势）+ 年度 + 状态 + 发布人 + 查询 + 重置
列表10 列
抽屉年度期次 / 四类指数数值 + 单位 / 口径说明（必填） / 附件（可多件） / 发布与生效时间

1.4 列表、筛选与排序

项目规则
默认排序年度倒序（新年度在前）
分页不分页（一年一期，量少）
筛选组合条件之间 且
空结果「还没有指数期次，先新增一期」
导出按年度，含数值、口径说明、附件清单

1.5 字段规格

指数台账（10 列）

列字段说明
年度期次period如「2027 年度」，一年一期
原料价格rawPrice + 单位可只填客户实际发布的类型
景气指数prosperity同上
创新指数innovation同上
趋势指数trend同上
口径说明caliber必填：数据来源 + 统计范围
附件files[]PDF / 图片 / Excel，可多件
发布人 / 时间publisher / publishedAt—
状态state草稿 / 待发布 / 已发布 / 已下线
操作—查看 / 编辑 / 发布 / 下线

录入抽屉

字段必填校验
年度 / 期次是默认「2026 年度」，一年一期
四类指数数值至少一类可只填客户实际发布的类型
单位条件填了数值则必填
口径说明是来源与统计范围
附件否PDF / 图片 / Excel，可多件
发布时间否可定时

1.6 交互规则

元素显示条件可点条件点击后禁止表现
导入模板始终专员下载 Excel 模板—
新增年度期次始终专员抽屉—
发布状态=草稿/待发布专员/主管校验口径 + 至少一类数值 → 生效缺项 → C-32/C-33

下线状态=已发布专员/主管置已下线—

1.7 业务规则与计算口径

编号规则触发处理影响端
R-20一年一期新增年度不可重复—
R-21至少一类指数数值发布全空 → 拦截—
R-22口径说明必填发布空 → 拦截下游消费方
R-23不自动算环比同比—如需对比人工写进口径说明—
R-24附件保留原稿上传不压缩、不修改—
