## 1. 消息推送 `content-push.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 统一消息触达：模板化、规则化、可统计 |
| 使用角色 | 内容运营专员（配置模板 / 补发）、主管（策略确认） |
| 入口 | 菜单 → 内容管理 → 消息推送；公告发布勾选「同步推送」也会在此生成任务 |
| 前置 | 渠道已绑定（站内默认可用；微信依赖公众号绑定） |
| 后置 | 推送记录可查送达 / 失败 / 已读 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 业务事件触发（订单 / 缴费 / 物业 / 政策 / 活动 / 公告）+ 人工补发 |
| 本页操作的跨端影响 | 发送 → 买家端 / 商户端消息中心出现站内推送；勾微信则走公众号模板消息 |
| 依赖的其他端页面 | `mai-APP/messages.html`、商户端消息（站内推送） |
| 不涉及的端 | — |
| 一致性要求 | 频次限制防打扰；失败可重发但**不重复计已读** |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「消息推送」+ **「渠道配置」****「导出记录」****「人工补发」** |
| **Tab** | 消息模板 / 推送记录（原型 1 个 Tab 容器） |
| **统计卡** | 启用中的模板 / 推送记录条数 / 累计送达或失败 / 平均已读率 / 可用渠道 |
| 模板表 | **8 列** |
| 记录表 | **8 列** |
| 弹窗 | 模板编辑 / 人工补发 / 渠道配置（原型略） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 模板按状态（启用在前）+ 更新倒序；记录按发送时间倒序 |
| 分页 | 不分页 |
| 筛选 | 记录可按时间与模板筛选 |
| 空结果 | 「暂无推送记录」 |
| 导出 | 记录可导出明细（**脱敏，仅号码尾号**） |

### 1.5 字段规格

**消息模板（8 列）**

| 列 | 字段 | 说明 |
|---|---|---|
| 模板 | `name` / `code` | — |
| 触发条件 | `trigger` | 业务事件驱动（订单支付 / 发货 / 缴费到期 / 物业告警 / 政策到期 / 活动开始 / 公告发布） |
| 目标人群 | `audience` | 买家 / 商户 / 指定对象 |
| 渠道 | `channels[]` | **站内推送 + 微信消息推送**（短信暂不做） |
| 频次限制 | `frequency` | 防打扰（如每用户每日 ≤2 条） |
| 近 30 天推送 / 已读率 | 派生 | — |
| 状态 | `state` | 启用 / 停用 |
| 操作 | — | 编辑 / 配置 / 停用 |

**推送记录（8 列）**：推送单号 · 模板/来源 · 目标人群 · 渠道 · 送达/失败 · 已读（率）· 发送时间 · 操作

**模板内容可变字段**

`{{订单号}} {{金额}} {{到期日}} {{笔数}} {{政策名称}} {{截止日}} {{处理人}} {{预计时间}}`

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新建/编辑模板 | 始终 | 专员 | 弹窗（名称/触发/人群/渠道/内容） | 缺触发 → C-42 |
| 人工补发 | 始终 | 专员 | 选模板 + 选人群 + 预览 + 发送 | 未选渠道 → C-43 |
| 渠道配置 | 始终 | 专员 | 弹窗（AppID / 模板 ID 映射 / 回执地址） | — |
| 查看来源公告 | 记录来自公告 | 始终 | 跳 P2 | — |
| 导出明细 | 有记录 | 专员 | 脱敏导出 | — |
| 了解开启成本 | 短信渠道 | 专员 | 说明（2026-10-09 暂缓） | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-25 | 模板必须有触发条件 | 保存 | 空触发 → 拦截 | — |
| R-26 | 至少一个渠道 | 保存/发送 | 空 → 拦截 | — |
| R-27 | 短信渠道暂缓 | 配置 | 只展示说明，不可启用 | — |
| R-28 | 公告同步推送生成任务 | 公告发布 | 记录来源公告 ID，可反查 | 两端 |
| R-29 | 导出脱敏 | 导出 | 仅号码尾号 | — |
| R-30 | 频次限制 | 发送 | 超限不发，记跳过 | 两端 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 模板名未填 | 行内拦截 | 【已实现】「请填写模板名称」 |
| 数据 | 触发条件未填 | 行内拦截 | 【已实现】「请填写触发条件（业务事件驱动，模板不能空触发）」 |
| 数据 | 未选渠道 | 行内拦截 | 【已实现】「请至少选择一个渠道（站内推送 / 微信消息推送）」 |
| 数据 | 消息内容为空 | 行内拦截 | 【已实现】「请填写消息内容」 |
| 依赖 | 微信未绑定公众号 | 渠道不可选 | 【待实现】应提示"需先完成公众号绑定" |
