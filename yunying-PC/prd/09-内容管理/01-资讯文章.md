## 0. 模块通用说明（本模块其他页面不再重复）

### 0.1 这个模块解决什么问题

资讯、公告、Banner、指数、推送原本散在各自后台甚至直接改代码，**发出去收不回、发错了改不了、哪个端显示了什么没人说得清**。
本模块把五类内容的**生产 → 审核 → 定时 → 多端投放 → 下线归档**收到一处。

> **投放粒度分两类（v1.1 明确，2026-10-26）**：
> - **Banner 类（P3）按「投放位」**：端 × 页面 × 具体位置，有位次与条数上限，同时段同位次唯一；
> - **资讯 / 公告 / 推送按「投放端」**：买家端 / 商户端各自只有**一个固定的对应模块**（资讯 → 「资讯」模块、行业资讯 → 「行业资讯」模块），**没有投放位，也没有位次与条数上限**。
>
> 早期版本把资讯也按投放位设计（含"位次上限 / 投放位已满"），**与端上实际形态不符，已于 2026-10-26 撤销**。

不做：内容只能靠改代码上线，出错无法回滚，多端展示不一致没人发现。

### 0.5 状态机

**① 内容状态（9 态）**

| 状态 | 含义（等谁做什么） | 驱动方 |
|---|---|---|
| 草稿 | 已录入未提交 | 运营专员 |
| 待审核 | 已提交，等主管 | 运营专员 → 主管 |
| 已驳回 | 审核未过，等改后重提 | 主管 |
| 待发布 | 已通过，未到生效时间 | 系统（定时） |
| 生效中 | 已下发各端并展示 | 系统 |
| 部分发布 | 部分端成功、部分失败，等重推 | 系统 + 专员 |
| 已下线 | 人工下线（终态，可回滚） | 专员 / 主管 |
| 已过期 | 超过结束时间（终态） | 系统 |
| 发布异常 | 全部端下发失败，等重推 | 系统 + 专员 |

**② 投放位占用（4 态 · 仅 Banner 类）**：待生效 / 生效中（**同位次同时段唯一**）/ 已结束 / 冲突待处理
> **资讯 / 公告不适用**——按端下发，不存在位次占用，两条资讯同时生效是正常的。

```mermaid
stateDiagram-v2
    [*] --> 草稿: 新建（规格校验 + 投放位必填）
    草稿 --> 待审核: 提交审核
    草稿 --> 待发布: 直接发布（审核流关闭）
    待审核 --> 待发布: 通过
    待审核 --> 已驳回: 驳回（原因必填）
    已驳回 --> 待审核: 修改重提
    待发布 --> 生效中: 到生效时间
    待发布 --> 部分发布: 部分端失败
    待发布 --> 发布异常: 全部端失败
    部分发布 --> 生效中: 重推成功
    发布异常 --> 生效中: 重推成功
    生效中 --> 已下线: 手动下线
    生效中 --> 已过期: 到失效时间
    已下线 --> 生效中: 回滚上一版本
```

**禁止路径**

| 场景 | 系统行为 | 提示文案 | 日志 |
|---|---|---|---|
| 同位次同时段已有内容 | 拦截保存 | 见 C-29 | 是 |
| 非主管强制替换位次 | 按钮隐藏 | — | 否 |
| 删除已发布内容 | 拦截 | 见 C-12 / C-24 | 是 |
| 发布未绑定投放位 | 拦截 | 见 C-03 | 否 |
| 任一端下发失败 | **不静默**，进异常清单可重推 | 见 C-11 | 是 |

### 0.6 名词与口径

| 名词 | 定义 | 备注 |
|---|---|---|
| **按端曝光 / 点击** | 按「投放端」维度统计 | 一条资讯投 2 个端 → 2 组数据（Banner 才按投放位统计） |
