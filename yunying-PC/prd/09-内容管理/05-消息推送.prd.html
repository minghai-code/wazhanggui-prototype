1. 消息推送 content-push.html

1.1 页面说明

项内容
页面目标统一消息触达：模板化、规则化、可统计
使用角色内容运营专员（配置模板 / 补发）、主管（策略确认）
入口菜单 → 内容管理 → 消息推送；公告发布勾选「同步推送」也会在此生成任务
前置渠道已绑定（站内默认可用；微信依赖公众号绑定）
后置推送记录可查送达 / 失败 / 已读

1.2 本页端间关系

项内容
本页数据来源业务事件触发（订单 / 缴费 / 物业 / 政策 / 活动 / 公告）+ 人工补发
本页操作的跨端影响发送 → 买家端 / 商户端消息中心出现站内推送；勾微信则走公众号模板消息
依赖的其他端页面mai-APP/messages.html、商户端消息（站内推送）
不涉及的端—
一致性要求频次限制防打扰；失败可重发但不重复计已读

1.3 页面结构

区块内容
顶部标题「消息推送」+ 「渠道配置」「导出记录」「人工补发」
Tab消息模板 / 推送记录（原型 1 个 Tab 容器）
统计卡启用中的模板 / 推送记录条数 / 累计送达或失败 / 平均已读率 / 可用渠道
模板表8 列
记录表8 列
弹窗模板编辑 / 人工补发 / 渠道配置（原型略）

1.4 列表、筛选与排序

项目规则
默认排序模板按状态（启用在前）+ 更新倒序；记录按发送时间倒序
分页不分页
筛选记录可按时间与模板筛选
空结果「暂无推送记录」
导出记录可导出明细（脱敏，仅号码尾号）

1.5 字段规格

列字段说明

1.8 异常与边界

类型场景系统行为提示文案

依赖微信未绑定公众号渠道不可选【待实现】应提示"需先完成公众号绑定"
