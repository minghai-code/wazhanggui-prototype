## 1. Banner 管理 `content-banner.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 各端页面轮播 / 广告位的图片、跳转与**排期**管理 |
| 使用角色 | 内容运营专员、运营主管 |
| 入口 | 菜单 → 内容管理 → Banner 管理 |
| 前置 | 已配置投放位（端 × 页面 × 位次） |
| 后置 | 生效后按位次在端上轮播；位次冲突需调序或等下线 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 运营手工上传；**08 活动审批通过 → 自动生成曝光位草稿** |
| 本页操作的跨端影响 | 生效 → 买家端 `home.html` 轮播 / `market-socks.html` / `chamber.html` 出现；下线 → 立即撤下 |
| 依赖的其他端页面 | `mai-APP/home.html`、`mai-APP/market-socks.html`、`mai-APP/chamber.html`、`shanghu-APP/home.html`（**商户端顶部轮播需新建**） |
| 不涉及的端 | — |
| 一致性要求 | 位次同时段唯一；多端下发失败进异常清单 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「Banner管理」+ **「导出」**「新增 Banner」 |
| **活动曝光位草稿提示区** | 08 活动审批通过后生成的草稿，带「确认投放」「忽略」 |
| **统计卡（5）** | 上架中 / 待发布（定时未到）/ 待审核 / 已过期 / 启用中的投放位 |
| 筛选区 | 关键词 + **投放端**（买家端 / 商户端）+ 页面 + 投放位 + 状态 + 生效期 + 查询 + 重置 |
| 列表 | **9 列** + 分页 |
| 投放位表 | **7 列** |
| 抽屉 | 图片（规格校验）/ 标题 / **投放位多选** / **位次与排序** / **点击行为** / 生效起止 / 各端预览 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 位次升序，同位次按生效时间 |
| 分页 | 页码（原型演示 2 页） |
| 筛选组合 | 条件之间 **且** |
| 投放端筛选 | 买家端 / 商户端 |
| 空结果 | 「该投放位暂无 Banner」 |
| 导出 | 含投放位、生效期、按位曝光/点击 |

### 1.5 字段规格

**Banner 列表（9 列）**

| 列 | 字段 | 说明 |
|---|---|---|
| 素材 | `image` | 缩略图 |
| 标题 | `title` | — |
| **副标题** | `sub` | **头图位必填**；端上显示在标题下方 |
| 底图 | `img` | 头图位使用；普通轮播位用渐变色块占位 |
| 投放位（端 · 页面 · 位置） | `slots[]` | 多选，标签组展示 |
| 位次 / 排序 | `position` | **同投放位同时段唯一** |
| 点击行为 | `action` | 跳商品 / 店铺 / 活动 / 外链 / 无 |
| 生效期（定时） | `startAt`~`endAt` | — |
| 按位曝光 / 点击 | 派生 | 按位维度，不是总数 |
| 状态 | `state` | 同模块 6 态 |
| 操作 | — | 审核 / 下线 / 编辑 / 忽略（草稿） |

**投放位表（7 列）**：投放位 ID · 端 · 页面 · 位置 · 位次上限 · 素材规格 · 状态 · 操作

> **共 7 个投放位**（2026-10-28 新增 `B-CHAMBER-HEAD`）：`B-HOME-TOP`（首页轮播 5）· `B-MARKET-ON`（市场线上 3）· `B-MARKET-OFF`（市场线下 3）· `B-CHAMBER`（协会轮播 2）· **`B-CHAMBER-HEAD`（协会页头部头图，全页唯一 1）** · `B-SH-HOME`（商户端首页 3）· `B-SH-WORK`（商户端工作台 2，停用）。

**编辑抽屉**

| 字段 | 必填 | 校验 / 说明 |
|---|---|---|
| 图片 | 是 | **规格随投放位自动校验**（如 1080×540 / 480KB / JPG） |
| 标题 | 是 | — |
| **副标题** | **头图位必填** | 端上显示在标题下方；勾了 `B-CHAMBER-HEAD` 而副标题为空 → 拦截 |
| 投放位 | 是 | 至少 1 个 |
| 位次 | 是 | 同投放位不重复；冲突拦截；**编辑时排除自身占用** |
| 点击行为 | 否 | 目标类型 + 目标 ID |
| 生效起止 | 是 | 精度到分钟 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新增 Banner | 始终 | 专员/主管 | 抽屉 | — |
| 确认投放（草稿） | 有活动曝光位草稿 | 专员/主管 | 转为待发布 Banner，按时间自动上线 | — |
| 忽略（草稿） | 同上 | 同上 | 填原因后忽略 | — |
| 审核 | 状态=待审核 | 主管 | 通过 / 驳回 | 驳回原因必填 |
| 下线 | 状态=生效中 | 专员/主管 | 立即撤下 | — |
| 提交审核 | 草稿 | 专员 | 置待审核 | 未绑投放位 → C-03 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-15 | 同位次同时段唯一 | 保存 | 冲突拦截；主管可强制替换 | 两端 |
| R-16 | 素材规格随投放位校验 | 选图 | 不符合 → 拦截 | — |
| R-17 | 活动曝光位草稿可一键确认 | 打开页面 | 转待发布，按活动时间上线 | 两端 |
| R-18 | 点击行为必带参 | 保存 | 目标类型 + ID，不留死链 | 两端 |
| R-19 | 空位不渲染 | 端上 | 生效期内无内容则不占位 | 两端 |
| R-20 | 头图位（`B-CHAMBER-HEAD`）副标题必填 | 保存 | 勾了头图位但副标题为空 → 拦截 | 买家端 |
| R-21 | 头图位全页唯一（上限 1） | 新增 / 审核 | 新增时满位拦截；**编辑排除自身**；**审核通过前再校验**（避免多条待审核同时上线） | 买家端 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 图片规格不符 | 拦截 | 【已实现】「已选择图片；校验：1080×540 / 480KB / JPG → 通过（规格随投放位自动校验）」 |
| 数据 | 位次冲突 | 拦截 | 【待实现】C-29 |
| 数据 | 投放位已满 | 拦截 | 【已实现】「投放位已满：{位名}（上限 {n} 条），请先下线其他内容」 |
| 数据 | 头图位缺副标题 | 拦截 | 【已实现】协会头图位的副标题必填（端上展示在标题下方） |
| 数据 | 审核通过时位次已满 | 拦截，不置待发布 | 该投放位已满：{位名}（在用 {n}/{m}），请先下线或替换现有内容再通过 |
| 依赖 | 商户端顶部轮播未建 | 生效但无展示 | — |
