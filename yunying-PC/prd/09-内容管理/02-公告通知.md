## 1. 公告通知 `content-notice.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 平台公告的**定向发布**与多端触达（可同步生成推送任务） |
| 使用角色 | 内容运营专员、运营主管、物业（仅物业类公告） |
| 入口 | 菜单 → 内容管理 → 公告通知 |
| 前置 | 已配置公告类投放位 |
| 后置 | 发布后 → 买家端消息中心、商户端通知公告 + 工作台；勾选同步推送则生成推送任务 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 运营 / 物业手工录入 |
| 本页操作的跨端影响 | 发布 → 买家端 `messages.html` + 商户端 `notice-detail.html` 与工作台最新 3 条；置顶 → 端上显著位置 |
| 依赖的其他端页面 | `mai-APP/messages.html`、`shanghu-APP/notice-detail.html`、`shanghu-APP/index-app-shanghu.html` |
| 不涉及的端 | — |
| 一致性要求 | 通知对象过滤在端上生效（仅商户 / 仅买家 / 全平台）；历史公告长期可查 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「公告通知」+ **「导出」**「新增公告」 |
| **统计卡** | 生效中 / 待发布（定时未到）/ 待审核 / 置顶使用（上限 3）/ 联动消息推送 |
| 筛选区 | 关键词 + **通知对象**（全平台 / 仅买家 / 仅商户）+ 类别 + 状态 + 生效期 + 是否置顶 + 查询 + 重置 |
| 列表 | **8 列** + 分页 |
| 投放位表 | **6 列**（公告专用位，自动带出） |
| 抽屉 | 标题 / 正文 / **通知对象** / **置顶** / 有效期 / **☑ 同步推送消息** |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 置顶优先，其次最近更新倒序 |
| 分页 | 页码（原型演示 2 页） |
| 筛选组合 | 条件之间 **且** |
| 通知对象筛选 | 全平台 / 仅买家 / 仅商户 |
| 空结果 | 端上"暂无公告" |
| 导出 | 含通知对象、置顶、有效期、推送记录、已读率 |

### 1.5 字段规格

**公告列表（8 列）**

| 列 | 字段 | 说明 |
|---|---|---|
| 标题 / 类别 | `title` / `category` | 类别：公告 / 政策 / 活动 |
| 通知对象 | `noticeType` | 全平台 / 仅买家 / 仅商户 |
| 投放位（自动带出） | `slots[]` | 按通知对象自动匹配，**不用手选** |
| 有效期（定时） | `startAt`~`endAt` | 置顶不影响有效期判定 |
| 置顶 | `top` | 置顶 / 取消置顶；**上限默认 3 条** |
| 消息推送 | `pushTaskId` | 有则显示跳转入口 |
| 状态 | `state` | 同模块 6 态 |
| 操作 | — | 审核 / 置顶 / 编辑 / 下线 / 删除（仅草稿） |

**投放位表（6 列）**：投放位 ID · 端 · 页面 · 位置 · 上限 · 素材规格 · 状态

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 通知对象 | 编辑态 | 专员/主管；物业仅物业类 | 切换后**投放位自动重算** | — |
| 置顶 | 状态=生效中/待发布 | 专员 | 置顶（上限 3） | 达上限 → C-18 |
| 取消置顶 | 已置顶 | 同上 | 取消 | — |
| 同步推送消息 | 编辑态 | 同上 | 勾选后显示渠道选择（站内 / 微信） | 勾选未选渠道 → C-22 |
| 查看推送任务 | 有 `pushTaskId` | 始终 | 跳 P5 | — |
| 删除 | 仅草稿 | 专员 | 物理删除 | 非草稿 → C-24 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-09 | 投放位随通知对象自动带出 | 切换对象 | 不用手选，避免错投 | 两端 |
| R-10 | 置顶上限默认 3 条 | 置顶 | 超限拦截 | 端上排序 |
| R-11 | 置顶不影响有效期 | 到期 | 照常过期 | 两端 |
| R-12 | 勾选同步推送 → 生成推送任务 | 发布 | 在 P5 可见该任务 | 两端消息 |
| R-13 | 历史公告长期可查 | 过期后 | 不物理删除，只下线 | 两端 |
| R-14 | 物业仅能发物业类公告 | 新建 | 类别锁定 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 置顶已 3 条 | 拦截 | 【已实现】「置顶已达上限 {n} 条，请先取消其他置顶」 |
| 数据 | 勾选推送未选渠道 | 拦截 | 【已实现】「已勾选「同步推送消息」，请至少选择一个渠道（站内推送 / 微信消息推送）」 |
| 数据 | 删除非草稿 | 拦截 | 【已实现】「仅「草稿」可删除；已发布公告请用「下线」（历史需长期可查）」 |
| 数据 | 端上未接公告位 | 发布后无展示 | — |

### 1.9 通知与消息

| 事件 | 接收人 | 渠道 | 抑制条件 |
|---|---|---|---|
| 公告发布 | 按通知对象：全部 / 仅买家 / 仅商户 | 站内（勾选则加微信） | 同公告不重复 |
| 公告置顶 | 同上 | 站内 | — |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-07 | 已有 3 条置顶 | 再置顶一条 | 拦截并提示上限 | P0 |
| AC-08 | 通知对象选「仅商户」 | 发布 | 买家端消息中心**看不到**，商户端可见 | P0 |
| AC-09 | 勾选同步推送未选渠道 | 保存 | 拦截并提示选渠道 | P1 |
| AC-10 | 已发布公告 | 点删除 | 拦截，提示用「下线」 | P1 |
| AC-11 | 勾选同步推送并选站内 | 发布 | P5 出现对应推送任务，可点「查看来源公告」跳回 | P1 |
