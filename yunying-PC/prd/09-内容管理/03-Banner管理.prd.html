编辑抽屉

字段必填校验 / 说明
图片是规格随投放位自动校验（如 1080×540 / 480KB / JPG）
标题是—
副标题头图位必填端上显示在标题下方；勾了 B-CHAMBER-HEAD 而副标题为空 → 拦截
投放位是至少 1 个
位次是同投放位不重复；冲突拦截；编辑时排除自身占用
点击行为否目标类型 + 目标 ID
生效起止是精度到分钟

1.6 交互规则

元素显示条件可点条件点击后禁止表现
新增 Banner始终专员/主管抽屉—
确认投放（草稿）有活动曝光位草稿专员/主管转为待发布 Banner，按时间自动上线—
忽略（草稿）同上同上填原因后忽略—
审核状态=待审核主管通过 / 驳回驳回原因必填
下线状态=生效中专员/主管立即撤下—
提交审核草稿专员置待审核未绑投放位 → C-03

1.7 业务规则与计算口径

编号规则触发处理影响端
R-15同位次同时段唯一保存冲突拦截；主管可强制替换两端
R-16素材规格随投放位校验选图不符合 → 拦截—
R-17活动曝光位草稿可一键确认打开页面转待发布，按活动时间上线两端
R-18点击行为必带参保存目标类型 + ID，不留死链两端
R-19空位不渲染端上生效期内无内容则不占位两端
R-20头图位（B-CHAMBER-HEAD）副标题必填保存勾了头图位但副标题为空 → 拦截买家端
R-21头图位全页唯一（上限 1）新增 / 审核新增时满位拦截；编辑排除自身；审核通过前再校验（避免多条待审核同时上线）买家端
