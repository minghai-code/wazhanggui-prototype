## 1. 产业指数发布 `content-index.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 录入 / 导入客户**线下每年发布**的产业指数（本期不做自动计算与图表） |
| 使用角色 | 内容运营专员（主力）、运营主管 |
| 入口 | 菜单 → 内容管理 → 产业指数发布 |
| 前置 | 无（一年一期，手工录入） |
| 后置 | 发布后供端上消费（**消费位待确认**，见分册 §10-2） |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 客户线下发布稿（PDF / Excel）+ 运营手工录入 |
| 本页操作的跨端影响 | **当前无端上消费位**（买家端"行情参考"与驾驶舱均待确认） |
| 依赖的其他端页面 | 无 |
| 依赖的运营端模块 | 11 原料市场（价格指数的口径来源） |
| 一致性要求 | 数值与客户发布稿一致；口径说明必填（否则下游无法解释数据） |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「产业指数发布」+ **「导入模板」****「导出」****「新增年度期次」** |
| **统计卡** | 已发布期次 / 待发布 / 草稿或未完成 / 附件总数（客户发布稿） |
| 筛选区 | 指数类型（原料价格 / 景气 / 创新 / 趋势）+ 年度 + 状态 + 发布人 + 查询 + 重置 |
| 列表 | **10 列** |
| 抽屉 | 年度期次 / 四类指数数值 + 单位 / **口径说明（必填）** / **附件（可多件）** / 发布与生效时间 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 年度倒序（新年度在前） |
| 分页 | 不分页（一年一期，量少） |
| 筛选组合 | 条件之间 **且** |
| 空结果 | 「还没有指数期次，先新增一期」 |
| 导出 | 按年度，含数值、口径说明、附件清单 |

### 1.5 字段规格

**指数台账（10 列）**

| 列 | 字段 | 说明 |
|---|---|---|
| 年度期次 | `period` | 如「2027 年度」，**一年一期** |
| 原料价格 | `rawPrice` + 单位 | 可只填客户实际发布的类型 |
| 景气指数 | `prosperity` | 同上 |
| 创新指数 | `innovation` | 同上 |
| 趋势指数 | `trend` | 同上 |
| 口径说明 | `caliber` | **必填**：数据来源 + 统计范围 |
| 附件 | `files[]` | PDF / 图片 / Excel，可多件 |
| 发布人 / 时间 | `publisher` / `publishedAt` | — |
| 状态 | `state` | 草稿 / 待发布 / 已发布 / 已下线 |
| 操作 | — | 查看 / 编辑 / 发布 / 下线 |

**录入抽屉**

| 字段 | 必填 | 校验 |
|---|---|---|
| 年度 / 期次 | 是 | 默认「2026 年度」，一年一期 |
| 四类指数数值 | **至少一类** | 可只填客户实际发布的类型 |
| 单位 | 条件 | 填了数值则必填 |
| **口径说明** | **是** | 来源与统计范围 |
| 附件 | 否 | PDF / 图片 / Excel，可多件 |
| 发布时间 | 否 | 可定时 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 导入模板 | 始终 | 专员 | 下载 Excel 模板 | — |
| 新增年度期次 | 始终 | 专员 | 抽屉 | — |
| 发布 | 状态=草稿/待发布 | 专员/主管 | 校验口径 + 至少一类数值 → 生效 | 缺项 → C-32/C-33 |
| 立即发布 | 同上 | 同上 | 跳过定时立即生效 | — |
| 下线 | 状态=已发布 | 专员/主管 | 置已下线 | — |
| 附件上传 / 移除 / 预览 | 编辑态 | 专员 | 即时反馈 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-20 | 一年一期 | 新增 | 年度不可重复 | — |
| R-21 | 至少一类指数数值 | 发布 | 全空 → 拦截 | — |
| R-22 | 口径说明必填 | 发布 | 空 → 拦截 | 下游消费方 |
| R-23 | 不自动算环比同比 | — | 如需对比人工写进口径说明 | — |
| R-24 | 附件保留原稿 | 上传 | 不压缩、不修改 | — |
