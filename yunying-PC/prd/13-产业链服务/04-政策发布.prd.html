1. 政策发布 chain-policy.html

1.1 页面说明

项内容
页面目标维护端上「政策兑现」的政策卡片，只发四件事：发布标题 / 发布正文 / 附件 / 申请网址
使用角色产业服务专员（发布、下线、编辑）
入口菜单 → 产业链服务 → 政策兑现 → 政策发布
前置政策原文（PDF / Word / 图片）与官方申报入口网址已取得
后置端上政策兑现列表出现该政策卡片；详情展示正文 + 附件 + 申请网址，点击申请网址新窗口打开政务平台
发布即生效（§1.6 免审口径），无待审核、无驳回、无过期状态。

1.2 本页端间关系

项内容
本页数据来源专员录入（四字段），无需任何端上提交
本页操作的跨端影响发布 → 两端 policy-service.html 列表 + 详情可见；下线 → 两端撤下（历史留档）
依赖的其他端页面mai-APP/policy-service.html（买家端）、shanghu-APP/industry-service.html（商户端政策兑现入口）
不涉及的端无申报、无材料上传、无审批回写 → 不存在状态回写链路
一致性要求四字段两端同一展示口径：列表（标题 + 正文摘要 + 附件数 + 更新时间）→ 详情（正文 + 附件 + 申请网址）

1.3 页面结构

区块内容
顶部标题「政策发布」+ 导出 + 端上预览 + 新增政策
口径提示条「平台只发布政策原文与官方申请入口：不代收材料、不代办申报、不跟踪审批结果；本期已移除申报受理」
统计卡（3）已发布 / 已下线 / 草稿　—　与列表同源派生
筛选区关键词（发布标题 / 正文）+ 状态（已发布 / 草稿 / 已下线）+ 查询 / 重置
列表政策台账（5 列），按更新时间倒序
抽屉政策编辑（四字段）+ 端上卡片示意
弹窗端上预览（手机示意：列表卡片 → 详情）
单 Tab，无「申报受理」Tab。

1.4 列表、筛选与排序

项目规则
默认排序更新时间倒序（最新在前）
分页不分页
筛选组合条件之间 且
关键词匹配 发布标题 / 发布正文（不搜附件名）
状态已发布 / 草稿 / 已下线（无「已过期」）
空结果「暂无匹配的政策」

1.5 字段规格

政策表（5 列）：发布标题（副行 = 政策编号 + 正文摘要）· 附件（个数）· 更新时间 · 状态 · 操作

编辑抽屉（4 项）

字段类型必填校验 / 默认端上展示位置
发布标题 title文本是≤60 字，实时字数提示列表卡片标题 + 详情标题
发布正文 content多行文本是纯文本换行；不结构化拆申报条件 / 材料 / 流程详情「发布正文」；列表取前 30 字左右作摘要
附件 files[]文件（多个）否PDF / Word / Excel / 图片，单个 ≤20MB；原型内最多 8 个详情「附件」（文件名 + 大小，可预览 / 下载）
申请网址 applyUrlURL否填了须以 http:// / https:// 开头详情底部「前往申请网址」（新窗口打开政务平台）；空则提示「该政策未配置申请网址」

不在本页的字段（v2.0 明确删除）：分类、发布机构、文号、年度、适用对象、扶持方式、补贴标准、申报条件、申报材料、兑现流程、申报起止、受理方式、咨询电话、投放端、置顶、AI 稿 / 人工终稿。

1.6 交互规则

元素显示条件可点条件点击后禁止表现

1.7 业务规则与计算口径

编号规则触发处理影响端
R-18发布即生效发布无审核流、无驳回两端
R-19平台不代办申报任何时候无申报受理、无兑现登记、无状态回写；申报条件与时限以原文及政务平台为准两端
R-20标题 ≤60 字保存 / 发布超长拦截（端上卡片单行）端上卡片
R-21申请网址协议校验保存 / 发布非 http(s):// 拦截；空值允许端上按钮

R-23已发布不可删除删除仅草稿可删；其余引导「下线」—
