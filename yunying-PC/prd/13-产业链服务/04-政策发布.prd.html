1. 政策发布 chain-policy.html

1.1 页面说明

项内容
页面目标政策发布（含结构化字段与 AI 图文解读）+ 申报受理（受理 / 退回补正 / 登记兑现 / 未通过）
使用角色产业服务专员（受理）、产业服务主管（兑现登记）
入口菜单 → 产业链服务 → 政策兑现 → 政策发布
前置政策原文与结构化字段齐备
后置端上可见政策详情与申报入口；申报状态回写并推送
v1.2 订正：发布审核本期不做（发布即生效），但 AI 图文解读必须人工复核后才可发布；投放端 mo='sh' 的政策不得出现在买家端。

1.2 本页端间关系

项内容
本页数据来源专员录入政策；商户/买家在端上提交申报
本页操作的跨端影响发布 → 买家端 policy-service.html 详情 + 申报日历；申报状态 → 端上进度 + 09 推送
依赖的其他端页面mai-APP/policy-service.html、shanghu-APP/industry-service.html
不涉及的端—
一致性要求申报起止驱动端上倒计时；申报资格限已绑定商户主体

1.3 页面结构

区块内容
顶部标题「政策兑现 · 政策发布」+ 导出 + 新建政策
统计卡申报中政策 / T-7 内即将截止 / 草稿（未发布）/ 待受理申报 / 已兑现（累计）
筛选区（Tab1）关键词 + 分类 + 申报期 + 状态 + 查询 + 重置
Tab1 政策政策表（9 列）
Tab2 申报受理申报单表（7 列）+ 筛选（单号 / 政策 / 状态）
抽屉政策（分类 / 结构化字段 / 申报起止 / 附件 / AI 解读 / 投放端）；申报（受理 / 退回 / 兑现 / 未通过）

1.4 列表、筛选与排序

项目规则
默认排序置顶优先 + 申报截止升序
分页不分页
筛选组合条件之间 且
分类资金补贴 / 人才政策 / 创新支持（与端上 Tab 一致）
置顶上限3 条
Tab2 排序退回补正 + 已提交按提交时间正序（超 3 工作日未受理红标）
空结果「暂无政策」/「暂无申报」

1.5 字段规格

政策表（9 列）：政策名称 · 分类 · 发布机构/文号 · 申报期（剩余）· 补贴标准 · AI 图文解读 · 申报数 · 状态 · 操作

申报单表（7 列）：申报单号 · 申报商户 · 政策 · 提交时间 · 材料完整性 · 状态/进度 · 操作

结构化字段必填说明
申报条件是端上详情必展示
申报材料是端上详情必展示
兑现流程是端上详情必展示
申报起止是端上日历与倒计时依赖
补贴标准是AI 解读生成的前置输入
AI 图文解读是（发布前）AI 稿留档 + 人工终稿复核

1.6 交互规则

元素显示条件可点条件点击后禁止表现

1.7 业务规则与计算口径

编号规则触发处理影响端
