## 1. 招聘 · 招聘指南 `chain-recruit-guide.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 维护端上「招聘指南」**单篇富文本**（保存即生效） |
| 使用角色 | 产业服务专员、产业服务主管 |
| 入口 | 菜单 → 产业链服务 → 人才招聘 → 招聘指南 |
| 前置 | 无 |
| 后置 | 保存后再次保存即发布，端上「招聘指南」同步更新时间 |

> **本期不做**：多篇文章、版本历史。只有一个编辑区 + 手机壳预览。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 专员编辑 |
| 本页操作的跨端影响 | 发布 → 端上「招聘指南」内容与更新时间同步 |
| 依赖的其他端页面 | 端上招聘指南页 |
| 不涉及的端 | 商户端 |
| 一致性要求 | **「平台不向求职者收取任何费用」为发布必填项**（防骗） |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「人才招聘 · 招聘指南」+ 保存并发布 |
| **统计卡** | **无**（单篇编辑页，无指标需求） |
| 工具栏 | 加粗 / 列表 / 链接 / 图片占位 / 清除格式 |
| 编辑区 | 标题 + 正文（预置四分区） |
| 右侧预览 | 手机壳端上预览 |

### 1.4 内容规则

| 项目 | 规则 |
|---|---|
| 预置分区 | 平台规则 / 如何写简历 / 面试注意 / **防骗提示** |
| 标题 | 必填 |
| 正文长度 | 过短拦截（建议四个分区都写） |
| 防骗要点 | **必须包含「平台不向求职者收取任何费用」** |
| 保存 | 保存即发布，无需审核 |

### 1.5 字段规格

| 字段 | 必填 | 校验 |
|---|---|---|
| 指南标题 | 是 | 非空 |
| 正文 | 是 | 长度足够（四分区） |
| 防骗提示 | 是 | 含指定文案 |
| 更新时间 | 系统 | 发布时自动写 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 工具栏格式 | 始终 | 专员/主管 | 应用/取消格式 | 不支持格式 → J-39 |
| 插入链接 | 始终 | 同上 | 插入超链接 | — |
| 插入图片 | 始终 | 同上 | 插入占位块（**本期不做图床**） | — |
| 保存并发布 | 始终 | 同上 | 校验三项 → 保存 + 端上同步 | 缺标题/过短/缺防骗 → J-42~J-44 |
| 预览 | 始终 | 始终 | 手机壳预览 | — |

### 1.7 业务规则与计算口径

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 标题未填 | 拦截 | 【已实现】请填写指南标题 |
| 数据 | 内容过短 | 拦截 | 【已实现】内容过短，请补充完整（建议四个分区都写） |
| 数据 | 缺防骗提示 | 拦截发布 | 【已实现】发布前请补充「平台不向求职者收取任何费用」的提示（防骗要点为必填） |
| 数据 | 不支持的格式 | 忽略 | 【已实现】该格式在原型中不可用 |
