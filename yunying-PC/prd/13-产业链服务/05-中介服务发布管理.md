## 1. 中介服务发布管理 `chain-agency.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | **服务商台账（本模块服务商主数据产生方）** + 服务项目上下架 + 评价与委托登记 |
| 使用角色 | 产业服务专员、产业服务主管 |
| 入口 | 菜单 → 产业链服务 → 中介服务 → 服务发布管理 |
| 前置 | 服务商资质证照已收 |
| 后置 | 端上 `agency-service.html` 分类 Tab 可见；委托金额进入撮合指标 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 专员录入（线下签约服务商） |
| 本页操作的跨端影响 | 上架 → 买家端中介页可见；下架 → 端上撤下 |
| 依赖的其他端页面 | `mai-APP/agency-service.html`、`shanghu-APP/industry-service.html`（检测认证类） |
| 不涉及的端 | — |
| 一致性要求 | 类型字典（财务/法律/管理/认证检测/知识产权）**与端上分类一致**；服务商主数据被 P1/技术共享引用 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「中介服务发布管理」+ 导出 + 新增服务商 |
| **统计卡** | 在架服务商 / 服务项目 / 平均评分（在架）/ 优质服务商占比 / 累计委托金额 |
| 筛选区（服务商） | 关键词 + 类型 + 状态 + 评分 + 查询 + 重置 |
| **Tab 服务商** | 服务商表（**8 列**） |
| **Tab 服务项目** | 服务项目表（**9 列**） |
| 抽屉 | 服务商（名称/类型/范围/资质附件/评分/联系方式）；项目（名称/内容/计费/价格/周期/跳转） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 在架优先 + 评分降序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 类型 | 财务服务 / 法律咨询 / 管理咨询 / 认证检测 / 知识产权 |
| 空结果 | 「暂无服务商，请先录入」 |

### 1.5 字段规格

**服务商表（8 列）**：服务商 · 类型 · 服务范围 · 资质 · 评分 · 对接/委托 · 状态/排序 · 操作

**服务项目表（9 列）**：项目名称 · 所属服务商 · 服务内容 · 计费方式 · 价格 · 服务周期 · 跳转 · 状态 · 操作

| 关键字段 | 说明 |
|---|---|
| `qualFiles` | 资质证照（**上架前置**） |
| `rating` | 评分（评价聚合，端上展示） |
| `chargeType` | 计费方式：按次 / 按项目 / 面议 |
| `dealAmount` | 委托金额（**累计委托金额**指标来源） |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新增服务商 | 始终 | 专员/主管 | 抽屉 | 名称空 → H-07 |
| 上架服务商 | 已下架 | 专员/主管 | 端上可见 | **无资质 → H-03** |
| 下架 | 在架 | 专员/主管 | 端上撤下 | — |
| 删除服务商 | 始终 | 专员 | 软删留痕 | **有项目 → H-05** |
| 新增/编辑项目 | 始终 | 专员/主管 | 抽屉 | 名称空 → H-08 |
| 项目单独上下架 | 始终 | 专员/主管 | 独立于服务商 | — |
| 登记委托 | 已有对接 | 专员/主管 | 填金额 → 累计 | 金额非法 → H-10 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-26 | 无资质不可上架 | 上架 | 硬门槛 | 端上 |
| R-27 | 有服务项目不可删服务商 | 删除 | 先转移或删除项目 | — |
| R-28 | 项目可独立上下架 | 项目级 | 不影响服务商状态 | 端上 |
| R-29 | 评分来自评价聚合 | 评价提交 | 端上展示 | 端上 |
| R-30 | 累计委托金额只算已登记 | 委托登记 | 未登记不计入 | 驾驶舱 |
| R-31 | 类型字典与端上一致 | 新增类型 | 需同步端上改造 | 端上 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 无资质上架 | 拦截 | 【已实现】上架前请先上传资质证照（营业执照/许可证等） |
| 数据 | 有项目删服务商 | 拦截 | 【已实现】该服务商下还有服务项目，不可删除；请先删除或转移服务项目 |
| 数据 | 服务商名未填 | 拦截 | 【已实现】请填写服务商名称 |
| 数据 | 项目名未填 | 拦截 | 【已实现】请填写项目名称 |
| 数据 | 委托金额非法 | 拦截 | 【已实现】请填写正确的委托金额 |

### 1.10 验收标准
