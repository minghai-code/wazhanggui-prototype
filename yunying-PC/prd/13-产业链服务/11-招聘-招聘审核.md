## 1. 招聘 · 招聘审核 `chain-recruit-audit.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 审核企业端发布的岗位（**运营代发免审，不在此列**） |
| 使用角色 | 产业服务主管（审核）、产业服务专员（查看） |
| 入口 | 菜单 → 产业链服务 → 人才招聘 → 招聘审核 |
| 前置 | 企业端发布了岗位 |
| 后置 | 通过 → 招聘中并通知发布方；驳回 → 原因回传可改后重提 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 企业端发布岗位（`source=企业发布`） |
| 本页操作的跨端影响 | 通过 → 端上岗位可见 + 发布方收到通知；驳回 → 发布方收到原因 |
| 依赖的其他端页面 | 端上岗位发布页 / 我的岗位 |
| 不涉及的端 | 买家端 |
| 一致性要求 | **超 24h 未审只红标升级，不自动通过** |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「人才招聘 · 招聘审核」+ 导出 |
| **统计卡** | 待审核 / 超 24h 未审 / 今日已通过 / 今日已驳回 / 平均等待 |
| 筛选区 | 工种 / 岗位 / 单位 / 联系人（模糊）+ 查询 + 重置 |
| 列表 | **8 列** |
| 审核抽屉 | 只读岗位详情 + **历史驳回原因** + 提交次数 + 通过 / 驳回 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 提交时间正序（先到先审） |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 超时 | **超 24h 红标**（仅提示，不自动处置） |
| 空结果 | 「暂无待审核岗位」 |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 工种名称 | `trade` | 21 项字典 |
| 岗位名称 | `title` | — |
| 招聘单位 | `company` | — |
| 联系人 | `contact` | — |
| 联系方式 | `phone` | 脱敏展示 |
| 发布时间 / 等待 | `createdAt` / 派生 | 超 24h 红标 |
| 状态 | `state` | 待审核 / 已通过 / 已驳回 |
| 操作 | — | 审核 / 详情 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 审核 | 状态=待审核 | **主管** | 抽屉（只读 + 历史驳回） | 非主管 → 隐藏 |
| 通过 | 待审核 | 主管 | 招聘中 + 通知发布方 | — |
| 驳回 | 待审核 | 主管 | 必选原因枚举 + 说明（≥5 字） | 未选 → J-35；过短 → J-36 |
| **撤回审核** | 已通过 | 主管 | **2 小时内且无投递**可撤回 | 超时/有投递 → 隐藏 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-59 | 超 24h 只红标不自动通过 | 定时 | 提醒，不改变状态 | — |
| R-60 | 驳回原因必选 + 说明 ≥5 字 | 驳回 | 发布方要能照着改 | 端上 |
| R-61 | 撤回审核限 2h 且无投递 | 撤回 | 通过后回待审核 | — |
| R-62 | 审核依据四条 | 审核 | 信息真实 / 薪资可核实 / **不得收取任何费用** / 联系方式有效 | 合规 |
| R-63 | 历史驳回原因可见 | 重复提交 | 抽屉展示历史，避免反复同错 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 驳回未选原因 | 拦截 | 【已实现】请选择驳回原因 |
| 数据 | 说明过短 | 拦截 | 【已实现】请填写具体说明（至少 5 个字，发布方要能照着改） |
| 数据 | 超时未审 | 红标 | — |
| 权限 | 非主管审核 | 按钮隐藏 | — |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-54 | 待审核岗位 | 点驳回但不选原因 | 拦截提示选原因 | P0 |
| AC-55 | 选了原因但说明 3 个字 | 提交驳回 | 拦截提示至少 5 个字 | P0 |
| AC-56 | 待审核岗位 | 点通过 | 状态招聘中，发布方收到通知 | P0 |
| AC-57 | 岗位待审 25 小时 | 查看列表 | 红标提示，**状态仍为待审核** | P1 |
| AC-58 | 已通过且无投递、1 小时内 | 点撤回审核 | 回到待审核 | P2 |
