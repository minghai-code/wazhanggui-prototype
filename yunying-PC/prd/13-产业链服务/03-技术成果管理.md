## 1. 技术成果管理 `chain-tech-achv.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 维护高校/研究所的新技术新成果（入库 → 发布 → **被对接**跟进），并维护**技术专家库** |
| 使用角色 | 产业服务专员、产业服务主管 |
| 入口 | 菜单 → 产业链服务 → 技术共享 → 技术成果管理 |
| 前置 | 成果资料由业务方线下收集 |
| 后置 | 端上 `tech-service.html` 成果 Tab / 技术专家区块可见 |

> **v1.2 订正**：**审核发布环节本期不做**，原型为 `草稿 → 已发布 → 已下线`。与 P2 **共用同一张「对接记录」模型**（双向撮合）。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 专员录入（首批建议 8–12 条真实成果） |
| 本页操作的跨端影响 | 发布 → 买家端成果 Tab 可见；专家发布 → 端上「技术专家」区块 |
| 依赖的其他端页面 | `mai-APP/tech-service.html`（成果 Tab + 专家区块） |
| 不涉及的端 | 商户端（本页成果只投买家端） |
| 一致性要求 | 成果被对接次数 = 对接记录数；专家参与对接数同源 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「技术成果管理」+ 导出 + 新增成果 |
| **统计卡** | 已发布成果 / 草稿（未发布）/ 对接中 / 被对接次数 Top / 平均匹配时长·成功率 |
| 筛选区 | 关键词 + 所属领域 + 提供方类型 + 成熟度 + 状态 + 查询 + 重置 |
| **Tab 成果** | 成果表（**9 列**） |
| **Tab 专家** | 专家表（**8 列**） |
| 抽屉 | 成果（名称/提供方/领域/简介/技术指标/成熟度/应用场景/合作方式/联系方式/附件/投放端） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 已发布优先，其次对接次数降序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 提供方类型 | 高校 / 研究所 / 企业 / 其他 |
| 成熟度 | 实验室 / 中试 / 量产 |
| 空结果 | 「暂无成果，可由业务方线下收集后录入」 |

### 1.5 字段规格

**成果表（9 列）**：成果 · 提供方 · 所属领域 · 成熟度 · 应用场景 · 合作方式 · 对接次数/结果 · 状态 · 操作

**专家表（8 列）**：专家 · 所属单位 · 职称/头衔 · 研究方向 · 可服务领域 · 参与对接 · 状态 · 操作

| 关键字段 | 说明 |
|---|---|
| `coopType` | 合作方式（技术转让 / 合作开发 / 委托研发 / 技术服务），**至少选一种** |
| `maturity` | 实验室 / 中试 / 量产 |
| `files` | 说明书 / 专利（附件） |
| `matchCount` | 对接次数（同源对接记录） |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新增成果 | 始终 | 专员/主管 | 抽屉 | 缺必填 → A-08~A-10 |
| 发布 | 草稿 | 专员/主管 | 端上立即可见 | 缺简介/指标 → A-02 |
| 下线 | 已发布 | 专员/主管 | 端上撤下 | — |
| 发起对接（成果→需求方） | 已发布 | 专员/主管 | 生成对接记录 | 缺企业 → A-13 |
| 登记结果 | 对接中 | 专员/主管 | 成功/失败 | — |
| 专家 Tab 新增 | Tab=专家 | 专员/主管 | 抽屉 | 缺必填 → A-11 |
| 删除 | **仅草稿** | 专员 | 物理删除 | 非草稿 → A-06 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-13 | 成果与需求共用对接模型 | 发起 | 同一张 Match 表，双向可发起 | — |
| R-14 | 被对接次数 = 对接记录数 | 每次对接 | 列表 Top 排名依据 | 驾驶舱 |
| R-15 | 合作方式至少一种 | 发布 | 空 → 拦截 | 端上 |
| R-16 | 专家不新增菜单 | — | 成果页内 Tab | — |
| R-17 | 附件不压缩 | 上传 | 说明书/专利原样保存 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 缺简介/指标 | 拦截发布 | 【已实现】发布前请补全「成果简介」与「技术指标」（端上详情必展示） |
| 数据 | 未选合作方式 | 拦截 | 【已实现】请至少选择一种合作方式 |
| 数据 | 专家缺必填 | 拦截 | 【已实现】姓名与所属单位必填 |
| 数据 | 删除非草稿 | 拦截 | 【已实现】仅「草稿」可删除；已发布成果请用「下线」 |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-12 | 新成果未填简介 | 点发布 | 拦截提示补全简介与指标 | P0 |
| AC-13 | 已发布成果 | 发起对接给某企业 | 生成对接记录，被对接次数 +1 | P0 |
| AC-14 | 专家 Tab | 新增专家（缺所属单位） | 拦截提示必填 | P0 |

| AC-16 | 同一成果两次对接成功 | 查看名单 | 以最先成功为准，另一条保留记录 | P1 |
