## 1. 招聘 · 投递管理 `chain-recruit-delivery.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 跟进投递：查看简历快照 → 回复（约面试 / 不合适） |
| 使用角色 | 产业服务专员、产业服务主管 |
| 入口 | 菜单 → 产业链服务 → 人才招聘 → 投递管理；也从岗位管理、简历管理跳入（带筛选） |
| 前置 | 求职者已在端上投递 |
| 后置 | 回复后通知求职者；状态推进 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 端上投递 |
| 本页操作的跨端影响 | 回复 → 求职者收到通知（站内/微信） |
| 依赖的其他端页面 | 端上「我的投递」 |
| 不涉及的端 | 买家端 |
| 一致性要求 | **首次打开即置「已查看」**并留痕；48h 未查看红标 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「人才招聘 · 投递管理」+ 导出 |
| **统计卡** | 投递总数 / 待查看 / 已查看待回复 / 已回复（约面试）/ 已拒绝 / 今日新增 |
| 筛选区 | 岗位 / 单位 / 求职者 / 状态 / 时间 + 查询 + 重置 |
| 列表 | **9 列** |
| 详情抽屉 | 岗位摘要 + **简历快照（投递时点）** + 回复时间线 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 待查看 → 已查看待回复 → 已回复；同期按投递时间 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 状态 | 待查看 / 已查看待回复 / 已回复（约面试）/ 已拒绝 |
| 红标 | **超 48h 未查看** |
| 空结果 | 「暂无投递」 |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 岗位名称 | `job` | 可跳岗位详情 |
| 招聘单位 | `company` | — |
| 求职者 | `name` | 可跳简历管理 |
| 电话 | `phone` | **脱敏** |
| 工作年限 | `years` | — |
| 投递时间 | `createdAt` | — |
| 状态 | `state` | 四态 |
| 最近回复 | `lastReply` | 约面试 / 不合适 + 时间 |
| 操作 | — | 详情 / 回复 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 详情 | 始终 | 始终 | 抽屉（**首次打开自动置「已查看」**） | — |
| 约面试 | 待查看/已查看 | 专员/主管 | 必填面试时间 + 地点 → 通知求职者 | 缺项 → J-29 |
| 不合适 | 同上 | 专员/主管 | 选原因枚举 → 通知求职者 | 未选原因 → 拦截 |
| 跳简历 | 求职者名 | 始终 | 跳 P3 并筛选 | — |
| 跳岗位 | 岗位名 | 始终 | 跳 P2 岗位详情 | — |
| 导出 | 始终 | 专员/主管 | 联系方式脱敏 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-54 | 首次打开即已查看 | 打开详情 | 自动置状态 + 留痕（人 + 时间） | 端上 |
| R-55 | 48h 未查看红标 | 定时 | 列表红标提醒 | — |
| R-56 | 回复必须二选一 | 回复 | 约面试（含时间地点）/ 不合适（含原因） | 端上 |
| R-57 | 简历快照不随后续修改 | 投递时 | 详情展示投递时点快照 | — |
| R-58 | 回复可多次 | 已回复 | 允许补充回复，时间线保留 | 端上 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 约面试缺时间/地点 | 拦截 | 【已实现】约面试需填写面试时间与地点 |
| 数据 | 不合适未选原因 | 拦截 | 【待实现】应提示选原因 |
| 数据 | 岗位已关闭后新投递 | 端上不可投（本页只读历史） | — |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
