## 1. 招聘 · 简历管理 `chain-recruit-resume.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 求职者简历台账（**只读查询 + 脱敏查看 + 导出**），不在此编辑简历内容 |
| 使用角色 | 产业服务专员、产业服务主管 |
| 入口 | 菜单 → 产业链服务 → 人才招聘 → 简历管理 |
| 前置 | 求职者在端上投递 |
| 后置 | 无（本页不产生写操作，除导出与查看留痕） |

> **本页是纯查询页**：只有 1 条业务提示语（跳转投递管理），其余为脱敏与留痕规则。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 端上求职者投递（简历快照） |
| 本页操作的跨端影响 | 无写入；查看完整身份证/手机号只影响审计留痕 |
| 依赖的其他端页面 | 端上简历填写页（求职者视角） |
| 不涉及的端 | 商户端 |
| 一致性要求 | **身份证与手机号默认脱敏**；查看完整需填原因并留痕 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「人才招聘 · 简历管理」+ 导出 |
| **统计卡** | 简历总数 / 本月新增 / 有投递记录 / 已获回复 / 暂无投递 |
| 筛选区 | 姓名 / 电话 / 身份证后 4 位 / 婚姻 / 年限 / 投递状态 + 查询 + 重置 |
| 列表 | **12 列** |
| 详情抽屉 | 基本信息 + 简历详情 + 投递记录 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 投递时间倒序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 投递状态 | 有投递 / 已获回复 / 暂无投递 |
| 空结果 | ⬜ **未实现空态**（列表无数据时表格为空） |
| 导出 | **脱敏 Excel**，二次确认 + 留痕 |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 姓名 | `name` | — |
| 电话 | `phone` | **默认脱敏** |
| 身份证 | `idcard` | **默认脱敏**，仅显示后 4 位以外的掩码 |
| 婚姻状况 | `marriage` | — |
| 现住地址 | `addr` | — |
| 邮箱 | `email` | — |
| 工作年限 | `years` | — |
| 专业 | `major` | — |
| 外语及等级 | `lang` | — |
| 职业资格 | `cert` | — |
| 投递/状态 | `deliveryState` | 有投递 / 已获回复 / 暂无投递 |
| 操作 | — | 详情 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 详情 | 始终 | 始终 | 只读抽屉（基本信息 + 简历 + 投递记录） | — |
| 查看完整手机号/身份证 | 详情内 | 专员/主管 | **必须填写查看原因** → 显示 + 留痕 | 未填原因 → 拦截 |
| 导出 | 始终 | 专员/主管 | 脱敏 Excel + 二次确认 + 留痕 | — |
| 跳投递 | 有投递记录 | 始终 | 跳 P4 并筛选该求职者 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-49 | 默认脱敏 | 列表/详情 | 手机号中间 4 位、身份证中间掩码 | — |
| R-50 | 查看完整需原因 | 点击查看 | 原因 + 人 + 时间 + IP 入审计 | — |
| R-51 | 导出必脱敏 | 导出 | 二次确认 + 留痕，不可导未脱敏 | — |
| R-52 | 简历只读 | 任何时候 | 运营不可改简历内容 | — |
| R-53 | 简历快照 | 投递时 | 后续修改简历不改历史投递快照 | 端上 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 权限 | 非专员查看完整信息 | 按钮隐藏 | — |
| 数据 | 无投递 | 状态显示「暂无投递」 | — |
| 数据 | 简历为空 | **无空态提示**（待补） | — |
