## 1. 金融服务 · 服务商管理 `chain-finance.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 管理金融**机构与产品**（16 字段）与**第三方申请入口**，只做「信息展示 + 入口跳转」 |
| 使用角色 | 产业服务专员、产业服务主管 |
| 入口 | 菜单 → 产业链服务 → 金融服务 → 服务商管理 |
| 前置 | 与合作机构签有展示协议 |
| 后置 | 端上金融服务页展示产品卡；点击跳第三方申请入口 |

> **明确不做（ND-01~05）**：**申请单 / 审批 / 放款 / 材料收集 / 风控**。本模块不接触企业身份与申请内容，只统计**入口点击**。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 专员录入（机构 + 产品 + 入口） |
| 本页操作的跨端影响 | 上架 → 端上金融服务页可见；紧急下架 → 端上立即消失 |
| 依赖的其他端页面 | 买家端金融服务页（`finance-service.html`，**改造项**） |
| 不涉及的端 | 商户端（本期不投） |
| 一致性要求 | 入口点击只统计点击动作，**不采集企业身份** |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「金融服务 · 服务商管理」+ 导出 + 新增产品 |
| **统计卡** | 已上架产品 / 合作机构 / 本月入口点击 / 入口异常 / 7 天内到期 |
| 筛选区 | 关键词 + 机构 + 产品类型 + 状态 + 查询 + 重置 |
| 产品表 | **8 列** |
| 入口抽检表 | **7 列**（产品 / 机构 / 入口形态 / 上次抽检 / 结果 / 备注 / 操作） |
| 抽屉 | 机构与产品 16 字段 + 第三方申请入口（可多条） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 排序号升序，其次上架时间倒序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 产品类型 | 信贷 / 担保 / 保险 / 其他 |
| 空结果 | 「暂无金融产品」 |
| 导出 | 机构 / 产品 / 入口形态 / 点击量 / 状态 |

### 1.5 字段规格

**产品表（8 列）**：产品名称 · 机构 · 产品类型 · 额度/利率/期限 · 申请入口 · 状态 · 点击 · 操作

**入口抽检表（7 列）**：产品 · 机构 · 入口形态 · 上次抽检 · 结果 · 备注 · 操作

| 16 字段要点 | 说明 |
|---|---|
| 机构 / 机构类型 | 银行 / 担保 / 保险 / 其他 |
| 产品名 / 产品类型 | — |
| 额度 / 利率 / 期限 | 区间值，**只展示不计算** |
| 标签 / 适用对象 / 生效期 / 排序 / 状态 | — |
| **免责声明** | 端上必展示 |
| **申请入口（≥1）** | H5 / 小程序 / 二维码 / 电话 / 线下网点，**可配多条** |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新增/编辑产品 | 始终 | 专员/主管 | 抽屉 | 缺必填 → F-06 |
| 上架 | 已下架 | 专员/主管 | 端上可见 | **入口 <1 → F-07** |
| **紧急下架** | 已上架 | 专员/主管 | 端上立即消失 + **原因留痕** | 缺原因 → F-14（⬜） |
| 测试打开入口 | 抽屉内 | 有入口 | 新窗打开 / 拨号 | 格式错 → F-08/F-09 |
| 登记抽检结果 | 抽检表 | 专员 | 记正常 / 异常 | — |
| 删除 | 始终 | 专员 | **软删留痕** | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-32 | 入口至少 1 条 | 上架 | 硬门槛 | 端上可点 |
| R-33 | 入口格式校验 | 保存 | H5 需 http(s)://；电话 7–20 位数字 | — |
| R-34 | 到期自动过期 | 生效期结束 | 端上撤下 | 端上 |
| R-35 | 点击只统入口 | 端上点击 | 不采集企业身份 / 申请内容 | 驾驶舱 |
| R-36 | 入口异常红标 | 抽检失败 | 超阈值红标，提醒专员 | — |
| R-37 | 紧急下架需原因 | 下架 | 留痕（**⬜ 未实现**） | — |
