1. 金融服务 · 服务商管理 chain-finance.html

1.1 页面说明

项内容
页面目标管理金融机构与产品（16 字段）与第三方申请入口，只做「信息展示 + 入口跳转」
使用角色产业服务专员、产业服务主管
入口菜单 → 产业链服务 → 金融服务 → 服务商管理
前置与合作机构签有展示协议
后置端上金融服务页展示产品卡；点击跳第三方申请入口
明确不做（ND-01~05）：申请单 / 审批 / 放款 / 材料收集 / 风控。本模块不接触企业身份与申请内容，只统计入口点击。

1.2 本页端间关系

项内容
本页数据来源专员录入（机构 + 产品 + 入口）
本页操作的跨端影响上架 → 端上金融服务页可见；紧急下架 → 端上立即消失
依赖的其他端页面买家端金融服务页（finance-service.html，改造项）
不涉及的端商户端（本期不投）
一致性要求入口点击只统计点击动作，不采集企业身份

1.3 页面结构

区块内容
顶部标题「金融服务 · 服务商管理」+ 导出 + 新增产品
统计卡已上架产品 / 合作机构 / 本月入口点击 / 入口异常 / 7 天内到期
