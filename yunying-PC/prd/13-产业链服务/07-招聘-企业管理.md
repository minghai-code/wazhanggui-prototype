## 1. 招聘 · 企业管理 `chain-recruit-company.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 管理招聘企业主体，并可**关联入驻商户**（只读引用 04，不写 04） |
| 使用角色 | 产业服务专员、产业服务主管 |
| 入口 | 菜单 → 产业链服务 → 人才招聘 → 企业管理 |
| 前置 | 企业资料线下收取 |
| 后置 | 岗位可挂在该企业下；停用后不可新建岗位 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 专员录入 + 关联 04 商户档案（搜索带入） |
| 本页操作的跨端影响 | 停用 → 端上该企业岗位不再展示（岗位需另行关闭） |
| 依赖的其他端页面 | 端上招聘页（企业信息展示） |
| 不涉及的端 | 买家端（求职者视角走 `industry-services.html` 聚合） |
| 一致性要求 | 关联商户**只读引用**，不反向写 04 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「人才招聘 · 企业管理」+ 导出 + 新增企业 |
| **统计卡** | 招聘企业总数 / 已关联入驻商户 / 在招企业 / 关联岗位总数 / 未关联商户 |
| 筛选区 | 关键词 + 企业类型 + 状态 + 是否关联商户 + 查询 + 重置 |
| 企业表 | **8 列** |
| 关联商户搜索表 | **4 列**（商户/档口 · 企业全称 · 联系人/电话 · 操作） |
| 抽屉 | 企业名 / 类型 / 信用代码 / 联系人 / 电话 / 地址 / 简介 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 新增时间倒序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 空结果 | 「暂无招聘企业，请先新增」 |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 企业名称 | `name` | **唯一**，重复拦截 |
| 企业类型 | `type` | 制造业 / 贸易 / 服务 / 其他 |
| 统一社会信用代码 | `creditCode` | 18 位 |
| 关联入驻商户 | `merchantId` | 可关联 04 档案；带出企业名/联系人/电话（只读） |
| 岗位数 | `jobCount` | 可跳岗位管理 |
| 招聘记录 | `recruitCount` | 累计招聘数 |
| 状态 | `state` | 启用 / 停用 |
| 操作 | — | 编辑 / 关联商户 / 停用 / 删除 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新增/编辑 | 始终 | 专员/主管 | 抽屉 | 缺必填 → J-04；重名 → J-05 |
| 关联商户 | 编辑态 | 专员/主管 | 搜索 04 → 带入只读字段 | — |
| 停用 | 启用中 | 专员/主管 | 停用后不可新建岗位 | — |
| 删除 | 始终 | 专员 | 软删留痕 | **有岗位 → J-02** |
| 跳岗位 | 岗位数 > 0 | 始终 | 跳 P2 并筛选该企业 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-38 | 企业名唯一 | 保存 | 重名拦截 | — |
| R-39 | 关联商户只读 | 关联 | 带入企业名/联系人/电话，不回写 04 | 04 |
| R-40 | 有岗位不可删 | 删除 | 先关闭或转移岗位 | — |
| R-41 | 停用后不可新建岗位 | 新建岗位 | 企业下拉不可选 | — |
| R-42 | 删除为软删 | 删除 | 留痕可在操作日志回溯 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 缺必填 | 拦截 | 【已实现】企业名称 / 联系人 / 联系电话 为必填 |
| 数据 | 企业名重复 | 拦截 | 【已实现】企业名称已存在：「{企业名}」 |
| 数据 | 有岗位删企业 | 拦截 | 【已实现】该企业仍有 {n} 个岗位，不可删除；请先关闭或转移岗位 |
| 依赖 | 关联的商户已清退 | 关联置灰 + 提示 | 【待实现】 |
