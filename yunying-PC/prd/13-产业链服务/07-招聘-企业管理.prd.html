1. 招聘 · 企业管理 chain-recruit-company.html

1.1 页面说明

项内容
页面目标管理招聘企业主体，并可关联入驻商户（只读引用 04，不写 04）
使用角色产业服务专员、产业服务主管
入口菜单 → 产业链服务 → 人才招聘 → 企业管理
前置企业资料线下收取
后置岗位可挂在该企业下；停用后不可新建岗位

1.2 本页端间关系

项内容
本页数据来源专员录入 + 关联 04 商户档案（搜索带入）
本页操作的跨端影响停用 → 端上该企业岗位不再展示（岗位需另行关闭）
依赖的其他端页面端上招聘页（企业信息展示）
不涉及的端买家端（求职者视角走 industry-services.html 聚合）
一致性要求关联商户只读引用，不反向写 04

1.3 页面结构

区块内容
顶部标题「人才招聘 · 企业管理」+ 导出 + 新增企业
统计卡招聘企业总数 / 已关联入驻商户 / 在招企业 / 关联岗位总数 / 未关联商户
筛选区关键词 + 企业类型 + 状态 + 是否关联商户 + 查询 + 重置
企业表8 列
关联商户搜索表4 列（商户/档口 · 企业全称 · 联系人/电话 · 操作）
抽屉企业名 / 类型 / 信用代码 / 联系人 / 电话 / 地址 / 简介

1.4 列表、筛选与排序

项目规则
默认排序新增时间倒序
分页不分页
筛选组合条件之间 且
空结果「暂无招聘企业，请先新增」

1.5 字段规格

列字段说明
企业名称name唯一，重复拦截
企业类型type制造业 / 贸易 / 服务 / 其他
统一社会信用代码creditCode18 位

状态state启用 / 停用
操作—编辑 / 关联商户 / 停用 / 删除

1.6 交互规则

元素显示条件可点条件点击后禁止表现
