## 1. 招聘 · 岗位管理 `chain-recruit-job.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 岗位全生命周期管理（新建 / 审核 / 上架 / 关闭 / 删除）+ 投递统计入口 |
| 使用角色 | 产业服务专员（代发）、产业服务主管 |
| 入口 | 菜单 → 产业链服务 → 人才招聘 → 岗位管理 |
| 前置 | 企业已建档且为启用状态 |
| 后置 | 审核通过后端上展示；投递进入 P4 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 企业端发布（需审核）+ 运营代发（**免审**） |
| 本页操作的跨端影响 | 审核通过 → 端上岗位可见并通知发布方；关闭 → 端上下架 |
| 依赖的其他端页面 | 端上招聘岗位列表 / 详情 |
| 不涉及的端 | 买家端（走聚合入口） |
| 一致性要求 | **端上发布必审、运营代发免审** |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「人才招聘 · 岗位管理」+ 导出 + 新建岗位 + 批量删除 |
| **统计卡** | 岗位总数 / 招聘中 / 待审核 / 已驳回 / 已关闭 / 本月新增 |
| 筛选区 | 发布时间 / 年度模式 / 工种 / 岗位 / 单位 / 状态 + 查询 + 重置 |
| 列表 | **11 列**（支持勾选批量删） |
| 抽屉 | 新建/编辑 **15 字段**；详情（基本信息 + 职位描述 + 审核记录 + 投递统计） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 发布时间倒序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 状态 | 待审核 / 招聘中 / 已驳回 / 已关闭 |
| 年度模式 | 可切换按年度筛选 |
| 空结果 | 「暂无岗位」 |

### 1.5 字段规格

**岗位表（11 列）**：工种 · 岗位名称 · 招聘单位 · 联系人/电话 · 薪资范围 · 人数 · 状态 · 发布方 · 发布时间 · 投递 · 操作

| 15 字段要点 | 说明 |
|---|---|
| 工种 | **21 项字典**（本期内置，见分册附录 A） |
| 单位 | 二选一（元/月 或 元/年） |
| 薪资范围 | 下限 ≤ 上限 |
| 联系方式 | 11 位手机号 |
| 发布方 | 企业发布 / 运营代发（决定是否需审核） |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新建岗位 | 始终 | 专员/主管 | 抽屉 | 缺必填 → J-18 |
| 审核通过 / 驳回 | 状态=待审核 | **主管** | 通过→招聘中；驳回原因必填 | — |
| 关闭 | 招聘中 | 专员/主管 | 原因必选 + 端上下架 | — |
| 重新上架 | 已关闭 | 专员/主管 | **重新进入待审核** | — |
| 批量删除 | 有勾选 | 专员 | 仅「已关闭且无投递」可删 | 未勾/不满足 → J-11/J-12 |
| 跳投递 | 投递 > 0 | 始终 | 跳 P4 并按该岗位筛选 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-43 | 端上发布必审 | 企业发布 | 置待审核 | 端上 |
| R-44 | 运营代发免审 | 代发 | 直接招聘中 | 端上 |
| R-45 | 重新上架要再审 | 重新上架 | 回待审核 | — |
| R-46 | 仅「已关闭且无投递」可删 | 删除 | 否则拦截 | — |
| R-47 | 薪资区间校验 | 保存 | 下限 ≤ 上限 | — |
| R-48 | 关闭不影响已有投递 | 关闭 | 投递记录保留 | 端上 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 缺必填 | 拦截 | 【已实现】工种 / 岗位名称 / 招聘单位 / 联系人 / 联系方式 / 人数 为必填 |
| 数据 | 薪资倒挂 | 拦截 | 【已实现】薪资下限不能大于上限（{下限} > {上限}） |
| 数据 | 电话格式错 | 拦截 | 【已实现】联系方式需为 11 位手机号（原型可填脱敏值，实际保存前校验） |
| 数据 | 批量删未勾选 | 拦截 | 【已实现】请先勾选要删除的岗位（仅「已关闭且无投递」可删） |
| 数据 | 部分不满足删除 | 部分执行 | 【已实现】有 {n} 个岗位不满足删除条件（非已关闭或已有投递） |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
