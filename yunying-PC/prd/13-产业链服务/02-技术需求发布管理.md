## 1. 技术需求发布管理 `chain-tech-demand.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 管理企业提出的技术需求，跟进**对接过程与结果** |
| 使用角色 | 产业服务专员、产业服务主管 |
| 入口 | 菜单 → 产业链服务 → 技术共享 → 需求发布管理 |
| 前置 | 需求由端上提交或运营代录 |
| 后置 | 对接结果回流驾驶舱（平均匹配时长 / 成功率） |

> **v1.2 订正**：**审核环节本期不做**（发布即生效）；来源端 = 商户端/买家端提交 + 运营代录，列表"提出方"下带**来源端标签**，编辑抽屉**只读展示来源端**。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 端上提交（商户端**入口缺**、买家端可提）+ 运营代录 |
| 本页操作的跨端影响 | 发布 → 买家端 `tech-service.html` 技术需求 Tab 可见；端上「联系对接」→ 生成对接记录 |
| 依赖的其他端页面 | `mai-APP/tech-service.html`；提出方 → `merchant-profile.html`（04） |
| 不涉及的端 | — |
| 一致性要求 | 投放端 `mo` 决定端上可见范围；联系方式**对接后**才揭示 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「技术需求发布管理」+ 导出 + 新增需求（代录） |
| **统计卡** | 待对接 / 对接中 / 已匹配 / 超期未对接（红）/ 平均匹配时长·成功率 |
| 筛选区 | 关键词 + 技术领域 + 对接状态 + 发布日期区间 + 仅看超期未对接 + 查询 + 重置 |
| 列表 | **9 列** |
| 抽屉 | 新增/编辑（标题 / 提出方 / 领域 / 描述 / 难点 / 投入 / 周期 / 对接方式 / 附件 / 投放端） |
| 对接抽屉 | 对接对象 + 联系方式 + 方式 + 进展 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 发布日期倒序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 对接状态 | 待对接 / 对接中 / 已匹配 / 已关闭 |
| 超期筛选 | 发布 15 天未对接 |
| 空结果 | 「暂无匹配的技术需求」 |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 需求编号 | `id` | — |
| 标题（+提出方） | `title` / `org` | 提出方可跳 04 档案；**来源端标签** |
| 技术领域 | `domain` | 字典 |
| 期望投入 / 周期 | `invest` / `period` | — |
| 发布日 / 已发布天数 | `publishAt` / 派生 | 超 15 天未对接红标 |
| 对接状态 | `matchState` | 待对接 / 对接中 / 已匹配 / 已关闭 |
| 对接次数 | `matchCount` | 可多条并行 |
| 结果 / 评价 | `result` / `rating` | 成功 / 失败 + 星级 |
| 操作 | — | 发起对接 / 登记结果 / 评价 / 关闭 / 编辑 / 删除 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新增需求（代录） | 始终 | 专员/主管 | 抽屉 | 缺必填 → D-07~D-09 |
| 发布 | 草稿 | 专员/主管 | 端上立即可见 | 缺描述 → D-02 |
| 发起对接 | 已发布 | 专员/主管 | 生成对接记录，状态→对接中 | 缺对象/进展 → D-11/D-12 |
| 登记结果 | 对接中 | 专员/主管 | 成功→已匹配（记匹配时间）；失败→已关闭 | 缺说明 → D-13 |
| 评价 | 已匹配 | 专员（代录）/主管 | 存星级与标签 | — |
| 关闭 | 已发布/对接中 | 专员/主管 | 必填原因；对接中需二次确认 | — |
| 删除 | **仅草稿** | 专员 | 物理删除 | 非草稿 → D-05 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-07 | 发布即生效 | 发布 | 无审核 | 买家端 |
| R-08 | 一需求可多路对接 | 发起 | 对接记录多条，**以最先成功为准** | — |
| R-09 | 匹配时长从发布起算 | 成功登记 | 记 `matchedAt`，参与平均值 | 驾驶舱 |
| R-10 | 60 天无更新自动关闭 | 系统 | 原因="超期未跟进"留痕 | — |
| R-11 | 来源端只读 | 编辑 | 代录/端上提交来源不可改 | — |
| R-12 | 联系方式对接后揭示 | 端上对接 | 揭示动作留痕 | 两端 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 描述未填 | 拦截 | 【已实现】发布前请填写「需求描述」（端上必展示） |
| 数据 | 删除非草稿 | 拦截 | 【已实现】仅「草稿」可删除；已发布需求请用「关闭」（历史需可查） |
| 数据 | 发起对接缺对象 | 拦截 | 【已实现】请填写对接对象 |
| 数据 | 结果缺说明 | 拦截 | 【已实现】结果说明必填 |
| 数据 | 列表为空 | 空态 | 【已实现】「暂无匹配的技术需求」 |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-06 | 新需求未填描述 | 点发布 | 拦截并提示补描述 | P0 |
| AC-07 | 已发布需求 | 发起对接 | 生成对接记录，状态变对接中 | P0 |
| AC-08 | 对接中 | 登记结果=成功 | 状态已匹配，记录匹配时间 | P0 |
| AC-09 | 同一需求两条对接记录 | 一条成功 | **以最先成功为准**，另一条不覆盖结果 | P0 |
| AC-10 | 需求发布 61 天无更新 | 系统扫描 | 自动关闭并留痕"超期未跟进" | P1 |
| AC-11 | 已发布需求 | 点删除 | 拦截提示用「关闭」 | P1 |
