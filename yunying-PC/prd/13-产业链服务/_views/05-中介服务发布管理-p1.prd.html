1. 中介服务发布管理 chain-agency.html

1.1 页面说明

项内容
页面目标服务商台账（本模块服务商主数据产生方） + 服务项目上下架 + 评价与委托登记
使用角色产业服务专员、产业服务主管
入口菜单 → 产业链服务 → 中介服务 → 服务发布管理
前置服务商资质证照已收
后置端上 agency-service.html 分类 Tab 可见；委托金额进入撮合指标

1.2 本页端间关系

项内容
本页数据来源专员录入（线下签约服务商）
本页操作的跨端影响上架 → 买家端中介页可见；下架 → 端上撤下
依赖的其他端页面mai-APP/agency-service.html、shanghu-APP/industry-service.html（检测认证类）
不涉及的端—
一致性要求类型字典（财务/法律/管理/认证检测/知识产权）与端上分类一致；服务商主数据被 P1/技术共享引用

1.3 页面结构

区块内容
顶部标题「中介服务发布管理」+ 导出 + 新增服务商
统计卡在架服务商 / 服务项目 / 平均评分（在架）/ 优质服务商占比 / 累计委托金额
筛选区（服务商）关键词 + 类型 + 状态 + 评分 + 查询 + 重置
Tab 服务商服务商表（8 列）
Tab 服务项目服务项目表（9 列）
抽屉服务商（名称/类型/范围/资质附件/评分/联系方式）；项目（名称/内容/计费/价格/周期/跳转）

1.4 列表、筛选与排序

项目规则
默认排序在架优先 + 评分降序
分页不分页
筛选组合条件之间 且
类型财务服务 / 法律咨询 / 管理咨询 / 认证检测 / 知识产权
空结果「暂无服务商，请先录入」

1.5 字段规格

服务商表（8 列）：服务商 · 类型 · 服务范围 · 资质 · 评分 · 对接/委托 · 状态/排序 · 操作

服务项目表（9 列）：项目名称 · 所属服务商 · 服务内容 · 计费方式 · 价格 · 服务周期 · 跳转 · 状态 · 操作

关键字段说明
qualFiles资质证照（上架前置）
rating评分（评价聚合，端上展示）
chargeType计费方式：按次 / 按项目 / 面议
dealAmount委托金额（累计委托金额指标来源）

1.6 交互规则

元素显示条件可点条件点击后禁止表现
新增服务商始终专员/主管抽屉名称空 → H-07
上架服务商已下架专员/主管端上可见无资质 → H-03
下架在架专员/主管端上撤下—
删除服务商始终专员软删留痕有项目 → H-05
新增/编辑项目始终专员/主管抽屉名称空 → H-08
项目单独上下架始终专员/主管独立于服务商—
登记委托已有对接专员/主管填金额 → 累计金额非法 → H-10

1.7 业务规则与计算口径

编号规则触发处理影响端
R-26无资质不可上架上架硬门槛端上
R-27有服务项目不可删服务商删除先转移或删除项目—
R-28项目可独立上下架项目级不影响服务商状态端上
R-29评分来自评价聚合评价提交端上展示端上
R-30累计委托金额只算已登记委托登记未登记不计入驾驶舱
R-31类型字典与端上一致新增类型需同步端上改造端上
