1. 招聘 · 招聘审核 chain-recruit-audit.html

1.1 页面说明

项内容
页面目标审核企业端发布的岗位（运营代发免审，不在此列）
使用角色产业服务主管（审核）、产业服务专员（查看）
入口菜单 → 产业链服务 → 人才招聘 → 招聘审核
前置企业端发布了岗位
后置通过 → 招聘中并通知发布方；驳回 → 原因回传可改后重提

1.2 本页端间关系

项内容
本页数据来源企业端发布岗位（source=企业发布）
本页操作的跨端影响通过 → 端上岗位可见 + 发布方收到通知；驳回 → 发布方收到原因
依赖的其他端页面端上岗位发布页 / 我的岗位
不涉及的端买家端
一致性要求超 24h 未审只红标升级，不自动通过

1.6 交互规则

元素显示条件可点条件点击后禁止表现
审核状态=待审核主管抽屉（只读 + 历史驳回）非主管 → 隐藏
通过待审核主管招聘中 + 通知发布方—
驳回待审核主管必选原因枚举 + 说明（≥5 字）未选 → J-35；过短 → J-36
撤回审核已通过主管2 小时内且无投递可撤回超时/有投递 → 隐藏

1.7 业务规则与计算口径

编号规则触发处理影响端
R-59超 24h 只红标不自动通过定时提醒，不改变状态—
R-60驳回原因必选 + 说明 ≥5 字驳回发布方要能照着改端上
R-61撤回审核限 2h 且无投递撤回通过后回待审核—
R-62审核依据四条审核信息真实 / 薪资可核实 / 不得收取任何费用 / 联系方式有效合规
R-63历史驳回原因可见重复提交抽屉展示历史，避免反复同错—
