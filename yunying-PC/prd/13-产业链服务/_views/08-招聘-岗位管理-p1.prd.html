1. 招聘 · 岗位管理 chain-recruit-job.html

1.1 页面说明

项内容
页面目标岗位全生命周期管理（新建 / 审核 / 上架 / 关闭 / 删除）+ 投递统计入口
使用角色产业服务专员（代发）、产业服务主管
入口菜单 → 产业链服务 → 人才招聘 → 岗位管理
前置企业已建档且为启用状态
后置审核通过后端上展示；投递进入 P4

1.2 本页端间关系

项内容
本页数据来源企业端发布（需审核）+ 运营代发（免审）
本页操作的跨端影响审核通过 → 端上岗位可见并通知发布方；关闭 → 端上下架
依赖的其他端页面端上招聘岗位列表 / 详情
不涉及的端买家端（走聚合入口）
一致性要求端上发布必审、运营代发免审

1.3 页面结构

区块内容
顶部标题「人才招聘 · 岗位管理」+ 导出 + 新建岗位 + 批量删除
统计卡岗位总数 / 招聘中 / 待审核 / 已驳回 / 已关闭 / 本月新增
筛选区发布时间 / 年度模式 / 工种 / 岗位 / 单位 / 状态 + 查询 + 重置
列表11 列（支持勾选批量删）
抽屉新建/编辑 15 字段；详情（基本信息 + 职位描述 + 审核记录 + 投递统计）

1.4 列表、筛选与排序

项目规则
默认排序发布时间倒序
分页不分页
筛选组合条件之间 且
状态待审核 / 招聘中 / 已驳回 / 已关闭
年度模式可切换按年度筛选
空结果「暂无岗位」

1.5 字段规格

岗位表（11 列）：工种 · 岗位名称 · 招聘单位 · 联系人/电话 · 薪资范围 · 人数 · 状态 · 发布方 · 发布时间 · 投递 · 操作

15 字段要点说明
工种21 项字典（本期内置，见分册附录 A）
单位二选一（元/月 或 元/年）
薪资范围下限 ≤ 上限
联系方式11 位手机号
发布方企业发布 / 运营代发（决定是否需审核）

1.6 交互规则

元素显示条件可点条件点击后禁止表现
新建岗位始终专员/主管抽屉缺必填 → J-18
审核通过 / 驳回状态=待审核主管通过→招聘中；驳回原因必填—
关闭招聘中专员/主管原因必选 + 端上下架—
重新上架已关闭专员/主管重新进入待审核—
批量删除有勾选专员仅「已关闭且无投递」可删未勾/不满足 → J-11/J-12
跳投递投递 > 0始终跳 P4 并按该岗位筛选—
