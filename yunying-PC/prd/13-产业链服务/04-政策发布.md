## 1. 政策发布 `chain-policy.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 维护端上「政策兑现」的政策卡片，**只发四件事**：发布标题 / 发布正文 / 附件 / 申请网址 |
| 使用角色 | 产业服务专员（发布、下线、编辑） |
| 入口 | 菜单 → 产业链服务 → 政策兑现 → 政策发布 |
| 前置 | 政策原文（PDF / Word / 图片）与官方申报入口网址已取得 |
| 后置 | 端上政策兑现列表出现该政策卡片；详情展示正文 + 附件 + 申请网址，点击申请网址新窗口打开政务平台 |

> **发布即生效**（§1.6 免审口径），无待审核、无驳回、无过期状态。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 专员录入（四字段），无需任何端上提交 |
| 本页操作的跨端影响 | 发布 → 两端 `policy-service.html` 列表 + 详情可见；下线 → 两端撤下（历史留档） |
| 依赖的其他端页面 | `mai-APP/policy-service.html`（买家端）、`shanghu-APP/industry-service.html`（商户端政策兑现入口） |
| 不涉及的端 | 无申报、无材料上传、无审批回写 → **不存在状态回写链路** |
| 一致性要求 | 四字段两端同一展示口径：列表（标题 + 正文摘要 + 附件数 + 更新时间）→ 详情（正文 + 附件 + 申请网址） |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「政策发布」+ 导出 + 端上预览 + 新增政策 |
| 口径提示条 | 「平台只发布政策原文与官方申请入口：不代收材料、不代办申报、不跟踪审批结果；本期已移除申报受理」 |
| **统计卡（3）** | 已发布 / 已下线 / 草稿　—　**与列表同源派生** |
| 筛选区 | 关键词（发布标题 / 正文）+ 状态（已发布 / 草稿 / 已下线）+ 查询 / 重置 |
| 列表 | 政策台账（**5 列**），按更新时间倒序 |
| 抽屉 | 政策编辑（四字段）+ 端上卡片示意 |
| 弹窗 | 端上预览（手机示意：列表卡片 → 详情） |

> 单 Tab，**无「申报受理」Tab**。

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | **更新时间倒序**（最新在前） |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 关键词 | 匹配 发布标题 / 发布正文（不搜附件名） |
| 状态 | 已发布 / 草稿 / 已下线（无「已过期」） |
| 空结果 | 「暂无匹配的政策」 |

### 1.5 字段规格

**政策表（5 列）**：发布标题（副行 = 政策编号 + 正文摘要）· 附件（个数）· 更新时间 · 状态 · 操作

**编辑抽屉（4 项）**

| 字段 | 类型 | 必填 | 校验 / 默认 | 端上展示位置 |
|---|---|---|---|---|
| 发布标题 `title` | 文本 | 是 | **≤60 字**，实时字数提示 | 列表卡片标题 + 详情标题 |
| 发布正文 `content` | 多行文本 | 是 | 纯文本换行；**不结构化拆申报条件 / 材料 / 流程** | 详情「发布正文」；列表取前 30 字左右作摘要 |
| 附件 `files[]` | 文件（多个） | 否 | PDF / Word / Excel / 图片，单个 ≤20MB；原型内最多 8 个 | 详情「附件」（文件名 + 大小，可预览 / 下载） |
| 申请网址 `applyUrl` | URL | 否 | 填了须以 `http://` / `https://` 开头 | 详情底部「前往申请网址」（新窗口打开政务平台）；空则提示「该政策未配置申请网址」 |

**不在本页的字段（v2.0 明确删除）**：分类、发布机构、文号、年度、适用对象、扶持方式、补贴标准、申报条件、申报材料、兑现流程、申报起止、受理方式、咨询电话、投放端、置顶、AI 稿 / 人工终稿。

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新增政策 | 始终 | 专员 | 抽屉（四字段） | 缺标题 / 正文 → P-02 / P-04 |
| 编辑 | 始终 | 专员 | 抽屉回填；保存后**即时生效** | — |
| 发布 | 草稿 / 已下线 | 专员 | 校验四字段 → 已发布（`up` 更新为当前时间） | 校验不过 → P-02~P-05 |
| 下线 | 已发布 | 专员 | 已下线（端上撤下，留档） | — |
| 删除 | **仅草稿** | 专员 | 直接删除 | 非草稿 → P-09 |
| 端上预览 | 始终 | 专员 | 手机示意（列表 + 详情） | 未发布时提示「端上不可见」 |
| 前往申请网址（预览内） | 有 `applyUrl` | 始终 | 提示新窗口打开；无则提示未配置 | — |
| 导出 | 始终 | 专员 | 台账（标题 / 附件数 / 更新时间 / 状态） | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-18 | 发布即生效 | 发布 | 无审核流、无驳回 | 两端 |
| R-19 | **平台不代办申报** | 任何时候 | 无申报受理、无兑现登记、无状态回写；申报条件与时限以原文及政务平台为准 | 两端 |
| R-20 | 标题 ≤60 字 | 保存 / 发布 | 超长拦截（端上卡片单行） | 端上卡片 |
| R-21 | 申请网址协议校验 | 保存 / 发布 | 非 `http(s)://` 拦截；空值允许 | 端上按钮 |
| R-22 | 仅已发布端上可见 | 发布 / 下线 | 草稿与已下线均不下发 | 两端 |
| R-23 | 已发布不可删除 | 删除 | 仅草稿可删；其余引导「下线」 | — |
| R-24 | 统计卡同源 | 渲染 | 3 张卡由列表现算，不写死 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 标题为空 / 超 60 字 | 拦截 | 【已实现】请填写发布标题 / 发布标题不能超过 60 字（端上卡片单行展示） |
| 数据 | 正文为空 | 拦截 | 【已实现】请填写发布正文 |
| 数据 | 网址格式错 | 拦截 | 【已实现】申请网址需以 http:// 或 https:// 开头 |
| 数据 | 附件超 8 个 | 拦截 | 【已实现】附件最多 8 个（超出请合并或压缩） |
| 数据 | 删除非草稿 | 拦截 | 【已实现】仅「草稿」可删除；已发布政策请用「下线」（历史需可查） |
| 边界 | 未配置申请网址 | 端上灰字提示 | 【已实现】该政策未配置申请网址 |
