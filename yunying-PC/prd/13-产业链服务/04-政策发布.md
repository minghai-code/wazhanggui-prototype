## 1. 政策发布 `chain-policy.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 政策发布（含结构化字段与 **AI 图文解读**）+ 申报受理（受理 / 退回补正 / 登记兑现 / 未通过） |
| 使用角色 | 产业服务专员（受理）、产业服务主管（**兑现登记**） |
| 入口 | 菜单 → 产业链服务 → 政策兑现 → 政策发布 |
| 前置 | 政策原文与结构化字段齐备 |
| 后置 | 端上可见政策详情与申报入口；申报状态回写并推送 |

> **v1.2 订正**：**发布审核本期不做**（发布即生效），但 **AI 图文解读必须人工复核后才可发布**；**投放端 `mo='sh'` 的政策不得出现在买家端**。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 专员录入政策；商户/买家在端上提交申报 |
| 本页操作的跨端影响 | 发布 → 买家端 `policy-service.html` 详情 + 申报日历；申报状态 → 端上进度 + 09 推送 |
| 依赖的其他端页面 | `mai-APP/policy-service.html`、`shanghu-APP/industry-service.html` |
| 不涉及的端 | — |
| 一致性要求 | 申报起止驱动端上倒计时；申报资格限已绑定商户主体 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「政策兑现 · 政策发布」+ 导出 + 新建政策 |
| **统计卡** | 申报中政策 / T-7 内即将截止 / 草稿（未发布）/ 待受理申报 / 已兑现（累计） |
| 筛选区（Tab1） | 关键词 + 分类 + 申报期 + 状态 + 查询 + 重置 |
| **Tab1 政策** | 政策表（**9 列**） |
| **Tab2 申报受理** | 申报单表（**7 列**）+ 筛选（单号 / 政策 / 状态） |
| 抽屉 | 政策（分类 / 结构化字段 / 申报起止 / 附件 / AI 解读 / 投放端）；申报（受理 / 退回 / 兑现 / 未通过） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 置顶优先 + 申报截止升序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 分类 | 资金补贴 / 人才政策 / 创新支持（**与端上 Tab 一致**） |
| 置顶上限 | **3 条** |
| Tab2 排序 | 退回补正 + 已提交按提交时间正序（**超 3 工作日未受理红标**） |
| 空结果 | 「暂无政策」/「暂无申报」 |

### 1.5 字段规格

**政策表（9 列）**：政策名称 · 分类 · 发布机构/文号 · 申报期（剩余）· 补贴标准 · AI 图文解读 · 申报数 · 状态 · 操作

**申报单表（7 列）**：申报单号 · 申报商户 · 政策 · 提交时间 · 材料完整性 · 状态/进度 · 操作

| 结构化字段 | 必填 | 说明 |
|---|---|---|
| 申报条件 | 是 | 端上详情必展示 |
| 申报材料 | 是 | 端上详情必展示 |
| 兑现流程 | 是 | 端上详情必展示 |
| 申报起止 | 是 | 端上日历与倒计时依赖 |
| 补贴标准 | 是 | AI 解读生成的前置输入 |
| **AI 图文解读** | 是（发布前） | AI 稿留档 + **人工终稿复核** |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新建政策 | 始终 | 专员/主管 | 抽屉 | 缺必填 → P-16~P-19 |
| **生成 AI 解读** | 已填补贴标准 + 申报条件 | 专员 | 生成 AI 稿 → 待人工复核 | 前置缺失 → P-14 |
| 发布 | 草稿 | 专员/主管 | 端上可见 | 缺字段/解读 → P-08~P-10 |
| 置顶 | 已发布 | 专员/主管 | 置顶（上限 3） | 超限 → P-05 |
| 下线 | 已发布 | 专员/主管 | 端上撤下 | — |
| 受理 | 申报=已提交 | 专员 | 校验材料 → 受理中 | — |
| 退回补正 | 申报=已提交 | 专员 | 缺件说明必填 | 空 → P-21 |
| **登记兑现** | 申报=受理中 | **主管** | 兑现说明 + 金额 | 缺 → P-23/P-24 |
| 未通过 | 申报=受理中 | 主管 | 原因必填 | 空 → P-26 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-18 | 发布即生效 | 发布 | 无审核流 | 两端 |
| R-19 | **AI 解读必须人工复核** | 发布 | AI 稿 + 终稿双留档；招标 #124 硬要求 | — |
| R-20 | 三项结构化字段必填 | 发布 | 缺一不可 | 端上详情 |
| R-21 | 置顶上限 3 条 | 置顶 | 超限拦截 | 端上排序 |

| R-24 | 已受理不可退回已提交 | 状态机 | 只能未通过 / 退回补正（受理前） | — |
| R-25 | 兑现只能主管登记 | 兑现 | 专员按钮隐藏 | 端上进度 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 缺申报起止 | 拦截发布 | 【已实现】发布前请填写「申报起止」（端上申报日历与倒计时依赖它） |

| 数据 | 缺 AI 解读 | 拦截发布 | 【已实现】发布前请先生成并复核「AI 图文解读」（招标 #124 要求政策带图文解读后发布） |
| 数据 | 置顶超限 | 拦截 | 【已实现】置顶上限 3 条：请先取消其他置顶 |
| 数据 | 截止早于开始 | 拦截 | 【已实现】申报截止不能早于申报开始 |
