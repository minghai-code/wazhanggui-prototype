## 1. 商户档案 `merchant-profile.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 商户主档的查询、维护与画像；**只含实体（档口）商户**（纯线上商户归 10 商城） |
| 使用角色 | 商户管理专员（主）、运营主管、运营专员（只读 + 标签）、财务（只读口径字段） |
| 入口 | 菜单 → 商户管理 → 商户档案；也从 P1 建档成功、P2 变更页跳入 |
| 前置 | 已由 05 合同「已存档」自动建档，或手工补档 |
| 后置 | 编辑留痕；关联账号变更即时生效 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 05 合同 + 02 档口（只读）；商户端提交的变更经 P2 回写 |
| 本页操作的跨端影响 | 添加员工 → 被关联账号**立刻可见档口信息 + 物业模块**；解除 → 即时收回 |
| 依赖的其他端页面 | `shanghu-APP/mine.html`、`property.html`、`contract.html`、`payment.html`（**均为写死档口号，需改读本页**） |
| 不涉及的端 | 买家端（仅 `shop-detail.html` 商位信息间接引用） |
| 一致性要求 | 关联/解除关联即时生效并留痕 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「商户档案」+ 导出 + 新增（补档） |
| **统计卡** | 商户总数（实体 / 档口）/ 线上兼档口 / 仅线下档口（未上线）/ 授权员工数（关联账号）/ 待推动上线 |
| 筛选区 | 关键词 + 商户类型 + 线上开通状态 + 是否关联档口 + 主营品类 + 状态 + 信用等级 + 来源 + 日期 + 查询 + 重置 |
| 列表 | **13 列** + 分页 |
| 详情抽屉 | **9 分区**（含 ⑧ 物业权限与关联账号、⑨ 历史租赁信息） |
| 历史租赁表 | **6 列**（在详情 ⑨ 内） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 建档时间倒序 |
| 分页 | 页码 |
| 筛选组合 | 条件之间 **且** |
| 商户类型 | 仅线上 / 线上兼档口 / 仅线下档口（未上线） |
| 线上开通状态 | 未申请 / 审核中 / 需补充材料 / 已通过 / 已驳回 |
| 空结果 | 「没有符合条件的商户」 |
| 导出 | 身份证、手机号**已脱敏** |

### 1.5 字段规格

**档案列表（13 列）**

| 列 | 字段 | 说明 |
|---|---|---|
| 商户编号 | `id` | — |
| 主体名称 | `name` | — |
| 主体类型 | `subjectType` | 个体工商户 / 企业 / 工厂制造商 |
| 商户类型 | `type` | 三值枚举，**变化留痕** |
| 线上开店状态 | `onlineState` | 五态 |
| 关联档口 | `units[]` | **只读**，来自 02，多个逗号分隔 |
| 授权员工数 | `staffCount` | 关联账号数 |
| 物业权限 | `propertyPerm` | 有/无 + 有效期（随合同期） |
| 主营品类 | `categories[]` | — |
| 建档时间 | `createdAt` | — |
| 信用等级 | `creditLevel` | 跳 P4 |
| 状态 | `state` | 待判定 / 正常经营 / 暂停 / 冻结 / 已清退 |
| 操作 | — | 详情 / 编辑 / 添加员工 |

**详情抽屉 9 分区**

| # | 分区 | 要点 |
|---|---|---|
| ① | 主体信息 | 编号 / 名称 / 类型 / 信用代码 / 法定代表人 / 电话 / 地址 |
| ② | 线上信息 | 店铺数（跳 10）、权限状态（电商 ✅ / 询价 ⛔） |
| ③ | 线下信息 | 关联档口表（编号/楼层/面积/租期/合同号/状态），**只读** |
| ④ | 信用评级 | 等级 / 总分 / 分项 / 周期，跳 P4 |
| ⑤ | 画像标签 | 实力标签 + 风险标签，可人工加标 |
| ⑥ | 变更与操作留痕 | 建档来源 / 类型升降 / 权限开收 / 状态变更（人+时间+前后值） |
| ⑦ | 关联数据入口 | 合同（05）/ 缴费（06）/ 店铺（10）/ 评价（买家端） |
| ⑧ | **物业权限与关联账号** | 授权员工数 / 权限有效期 / 关联台账（档口 × 使用人 × 操作人 × 时间）+ 添加员工 / 解除 |
| ⑨ | **历史租赁信息** | 已结束的租赁：历史档口 + 历史合同（含结束原因）+ 当时的店铺信息 |

**历史租赁（6 列）**：历史档口 · 历史合同 · 租期 · 年租金 · 结束原因 · 当时的店铺信息
> **同一档口可多条**（每份合同一条，以合同号区分）；空态「暂无历史租赁记录」（首次租赁，未换过档口）。

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 查看完整身份证 | 始终 | 专员/主管 | 二次校验 → 显示完整 + **记留痕**（人/时间/IP） | 非授权 → 隐藏 |
| 添加员工 | 详情 ⑧ | 专员/主管 | 输入手机号（须已注册商户端）→ 关联档口 | 格式错 → M-26 |
| 解除关联 | 已关联行 | 专员/主管 | 即时收回物业权限 + 留痕 | — |
| 加标签 | 详情 ⑤ | 专员/主管/运营专员 | 输入新标签 | 重复 → M-29 |
| 编辑 | 始终 | 专员/主管 | 改联系方式 / 品类 / 联系人 / 备注 / 标签 | 身份证/编号/类型/档口**置灰只读** |
| 补档 | 右上 | 专员 | 新建档案（必填原因） | 缺必填 → M-32/M-33；身份证重复 → M-34 |
| 暂停 / 冻结 | 始终 | **主管** | 二次确认 + 原因 | 非主管 → 隐藏 |
| 跳档口 | 关联档口 | 始终 | 跳 02 `resource-unit.html` | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-12 | 档口数据只读 | 任何时候 | 主权在 02，本页不提供编辑 | — |
| R-13 | 权限随合同期 | 建档 / 续签 | 有生效合同即有物业权限 | 商户端 |
| R-14 | 关联即时生效 | 添加/解除 | 被关联账号立即获得/失去档口可见 | 商户端 |
| R-15 | 身份证不可改 | 编辑 | 只读，错误走关联关系变更留痕 | — |
| R-16 | 历史租赁只读 | 详情 ⑨ | 由 05 合同终态归档（+ 每日兜底） | — |
| R-17 | 导出默认脱敏 | 导出 | 身份证 / 手机号打码 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 手机号格式错 / 未注册 | 拦截 | 【已实现】「请输入正确的 11 位手机号（对方须已注册商户端账号）」 |
| 数据 | 标签重复 | 拦截 | 【已实现】「该标签已存在」 |
| 数据 | 补档缺必填 | 拦截 | 【已实现】「主体名称与经营者姓名为必填」 |
| 数据 | 补档未填原因 | 拦截 | 【已实现】「补档原因必填（用于留痕与审核）」 |
| 数据 | 身份证重复建档 | 拦截 | 【已实现】「该身份证已存在档案「{商户名}」」 |
| 数据 | 无历史租赁 | 空态，并提示首次租赁未换过档口 | 暂无历史租赁记录 |
