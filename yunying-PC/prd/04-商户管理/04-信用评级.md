## 1. 信用评级 `merchant-rating.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 按信用指标体系给商户自动定级，并支持人工校准 |
| 使用角色 | 商户管理专员（规则配置）、运营主管（**人工调整唯一角色**） |
| 入口 | 菜单 → 商户管理 → 信用评级；也从档案详情 ④ 跳入 |
| 前置 | 交易/评价数据可用；缴费数据当前**无源** |
| 后置 | 等级输出到档案与端上「实力商家」标识 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 交易（10 商城/外采）、评价（买家端）、缴费（**06 无字段 → 标"数据缺失"**） |
| 本页操作的跨端影响 | 等级变化 → 买家端店铺/商品页「实力商家」标识；商户端等级展示（**端上均未接**） |
| 依赖的其他端页面 | `mai-APP/shop-detail.html`（标识位）、`shanghu-APP/mine.html`（等级展示） |
| 不涉及的端 | — |
| 一致性要求 | 规则改版**不回溯历史周期** |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「信用评级」+ 重新评分 |
| **统计卡** | AAA / AA / A / B / C / D / 待评级 / 数据缺失（等级分布 8 张） |
| 筛选区 | 关键词 + 信用等级 + 商户类型 + 评估周期 + 状态 + 查询 + 重置 |
| 列表 | **10 列** + 分页 |
| 评级详情抽屉 | 分项得分表（**5 列**：指标 / 权重 / 得分 / 数据来源 / 取数区间）+ 人工调整区 |
| 规则配置抽屉 | **5 列**（指标 / 权重 / 评分算法 / 数据源 / 状态） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 信用总分降序 |
| 分页 | 页码 |
| 筛选组合 | 条件之间 **且** |
| 等级筛选 | AAA–D + 待评级 + 数据缺失 |
| 空结果 | 「暂无评级数据」 |

### 1.5 字段规格

**评级列表（10 列）**

| 列 | 字段 | 说明 |
|---|---|---|
| 商户名称 | `name` | 跳档案详情 |
| 商户类型 | `type` | — |
| 信用总分 | `score` | 加权合计 − 违规扣分 |
| 交易 45% | `tradeScore` | 权重可配 |
| 评价 25% | `reviewScore` | — |
| 缴费 20% | `payScore` | **无数据显示「数据缺失」，不算 0 分** |
| 违规扣分 | `penalty` | 负向 |
| 等级 | `level` | AAA / AA / A / B / C / D |
| 评估周期 | `period` | 月度 |
| 操作 | — | 详情 / 调整 |

**分项得分（5 列）**：指标 / 权重 / 得分 / 数据来源 / 取数区间

**规则配置（5 列）**：指标 / 权重 / 评分算法（区间打分 / 线性映射）/ 数据源 / 状态

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 重新评分（单/批量） | 始终 | 专员/主管 | 按当前规则重算，数据缺失项不参与 | — |
| 规则配置 | 始终 | 专员/主管 | 抽屉（权重 + 算法 + 生效日） | 权重和≠100% → M-45 |
| 详情 | 始终 | 始终 | 分项得分 + 取数来源 | — |
| **人工调整** | 始终 | **主管** | 选新等级 + 原因 + 说明（对商户可见） | 非主管 → 隐藏；缺项 → M-41~M-43 |
| 跳档案 | 商户名 | 始终 | 跳 `merchant-profile.html` | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-18 | 总分 = 交易×45% + 评价×25% + 缴费×20% − 违规扣分 | 评算 | 权重可配、版本化 | 两端 |
| R-19 | **数据缺失不算 0 分** | 缴费无源 | 单独标记，不参与等级判定 | 两端 |
| R-20 | 规则改版不回溯 | 保存规则 | 历史周期评级保持原值 | — |
| R-21 | 人工调整必填原因 + 说明 | 调整 | 说明**对商户可见** | 商户端 |
| R-22 | 权重和必须 100% | 保存规则 | 校验通过才可存 | — |
| R-23 | 等级映射实力商家 | 等级输出 | AAA/AA → 实力商家标识 | 买家端（待接） |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 未选调整等级 | 拦截 | 【已实现】「请选择调整后等级」 |
| 数据 | 未选调整原因 | 拦截 | 【已实现】「调整原因必选」 |
| 数据 | 未填说明 | 拦截 | 【已实现】「请填写调整说明（必填，需对商户可见）」 |
| 数据 | 权重非数字 / 和≠100 | 拦截 | 【已实现】「权重必须是数字」「三项权重之和必须为 100%（当前 …%）」 |
| 数据 | 缴费无数据源 | 标"数据缺失" | 【已实现】「已按规则 v2.3 重新计算 … 其中 … 家"数据缺失"（无缴费数据源）不参与等级判定」 |
