### 1.1 原料市场六品类（Y-11，2026-11-03 增补）

买家端原料市场（F05）上线后，品类字典补入 6 个原料细类（与买家端对外叫法**逐字一致**）：

| 编号 | 品类 | 大类 | 说明 |
|---|---|---|---|
| CT-015 | 纱线 | 原料纱线 | 由原「棉纱 CT-009」「氨纶包覆纱 CT-010」合并而来（两项已停用，历史数据保留） |
| CT-016 | 化纤长丝 | 原料纱线 | |
| CT-017 | 染料助剂 | 原料纱线 | |
| CT-018 | 辅料橡筋 | 原料纱线 | |
| CT-019 | 包装物料 | 原料纱线 | 物料类，区别于「设计包装」大类的服务 |
| CT-020 | 纺机配件 | 原料纱线 | |

**市场分流支点（F05-R2）**：店铺 / 商户的「主营品类」是否包含「原料纱线」大类，决定其在买家端的可见市场——
- 含原料大类 → **原料市场**；仅袜品等其他大类 → **袜子市场**；两者都有（混营）→ **两个市场都展示**
- 品类为空 → **未归类**，两个市场都不展示，运营催补
- 因此本字典是市场分流的**唯一数据支点**，品类项的增删停用直接影响市场归属

**不做什么**：不做品类层级树（大类是固定 5 类，不是可维护的树）；不做品类与商品的绑定（商品品类归 10 商城运营，本期只统一"商户经营品类"口径）。

## 2. 分区结构

| 区块 | 内容 |
|---|---|
| 统计卡（4） | 启用品类 / 已停用 / 有商户在用 / **零使用品类** |
| 筛选 | 关键词（名称 / 编号）+ 所属大类 + 状态 + 查询 + 重置 |
| 列表（7 列） | 品类编号 / 品类名称 / 所属大类 / 排序 / **关联商户** / 状态 / 操作 |
| 抽屉 | 新增 / 编辑（名称、大类、排序、状态、备注） |
| 弹层 | 合并到…（目标品类 + 原因）/ 关联商户清单 |

> 「关联商户」= 商户档案「主营品类」包含该品类的商户数（去重），点数字可看清单。「零使用品类」用来发现该下线的品类。

## 3. 字段

| 字段 | 必填 | 规则 |
|---|---|---|
| 品类编号 | 系统 | `CT-xxx` |
| 品类名称 | 是 | **全局唯一**（去空格）；这是端上展示给商户看的名字 |
| 所属大类 | 是 | 袜品 / 原料纱线 / 袜机设备 / 设计包装 / 其他（固定 5 类，只用于筛选与排序分组） |
| 排序 | 是 | 同大类内越小越靠前 |
| 状态 | 是 | 启用 / 停用 |
| 备注 | 否 | 如"2026-08 起无商户使用，暂时停用" |

## 4. 操作与规则

| 操作 | 条件 | 效果 |
|---|---|---|
| 新增 | — | 立即进入商户档案 / 端上认证 / 变更审核的选择项（发布即生效） |
| 编辑 | — | 改名会**同步改写所有已引用商户**的品类名；改大类/排序只影响展示与筛选 |
| 停用 / 启用 | 除「其他」 | 停用后不进**新的**选择项；已选该品类的商户数据保留，档案仍显示（灰标） |
| **合并到…** | 除「其他」 | 选目标品类 + 填原因 → 源品类的关联商户**自动改挂**目标品类 → 源品类置停用并标注"已并入 X"（不删除，可追溯） |
| 导出 | — | 含大类、关联商户数、使用状态 |
| 查看关联商户 | 关联数 > 0 | 列出商户名称与编号，可跳档案 |

**规则**

| 编号 | 规则 |
|---|---|
| CT-1 | 品类名称**全局唯一**，重复即阻断（并提示用合并） |
| CT-2 | **只停用不删除**，保证历史商户档案可追溯 |
| CT-3 | 停用不影响历史数据，仅从新选择项消失；已选该品类的商户在**档案列表与编辑抽屉仍显示**（灰标 · 删除线 · 标「已停用」，不可再新增，可移除） |
| CT-4 | 合并 = 改挂 + 源停用 + 写入商户档案变更留痕，**不做物理删除** |
| CT-5 | 只是写法不同（男式袜 / 男袜）→ 用**合并**，不要改名或新增 |
| CT-6 | 「其他」为兜底项，不可停用、不可合并 |

## 7. 验收要点

| 编号 | 场景 | 期望 |
|---|---|---|
| AC-C01 | 新增同名品类 | 阻断并提示已存在、建议合并 |
| AC-C02 | 停用一个有商户在用的品类 | 提示在用的商户数；停用后仍在商户档案**列表与编辑抽屉以灰标+「已停用」显示**，新选择项不出现 |
| AC-C03 | 合并 A → B | A 的商户全部改挂 B，A 置停用并标注"已并入 B"，B 的关联数增加 |
| AC-C04 | 商户档案补档不选品类 | 阻断，提示去字典维护 |
| AC-C05 | 商户档案按品类筛选 | 只出该品类商户（多选匹配任一即中） |
| AC-C06 | 字典新增品类后打开商户档案编辑 | 新品类立即出现（无需刷新配置） |
