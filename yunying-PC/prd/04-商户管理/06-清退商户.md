## 1. 清退商户 `merchant-exit.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 被终止合同商户的**存档台账（只读）**，可追溯"为什么被终止" |
| 使用角色 | 商户管理专员、运营主管（均只读） |
| 入口 | 菜单 → 商户管理 → 清退商户 |
| 前置 | 05 合同台账已发起「终止」并由主管确认 |
| 后置 | 无（本页**不发起清退**，只归档展示） |

> **定位（v2.4）**：**不再发起清退**——发起在 **05 合同台账**。本页只收**提前终止**记录；**正常到期不进本页**（到期由系统自动置「已到期」，无审批、无原因）。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 05 合同终止（终止生效日 + 原因 + 主管确认） |
| 本页操作的跨端影响 | 无（只读）；终止发生时已联动：02 档口回空闲、商户端物业权限与关联账号回收 |
| 依赖的其他端页面 | `shanghu-APP/property.html`（权限已回收） |
| 不涉及的端 | 买家端 |
| 一致性要求 | **到期 ≠ 终止**：到期不进本页 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「清退商户（存档台账）」+ 导出 |
| **统计卡** | 存档总数（提前终止合同商户）/ 违约终止（欠租）/ 违规或资质清退 / 协商解除·经营调整·转让退出 |
| 筛选区 | 关键词 + 终止类型 + 状态 + 日期区间 + 查询 + 重置 |
| 列表 | **11 列** + 分页 |
| 详情抽屉 | 合同侧终止时间轴（只读） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 终止生效日倒序 |
| 分页 | 页码 |
| 筛选组合 | 条件之间 **且** |
| 终止类型 | 违约终止（欠租）/ 违规或资质清退 / 协商解除 / 经营调整 / 转让退出 |
| 空结果 | 「暂无匹配的存档记录」 |
| 导出 | 含终止类型、生效日、联动结果 |

### 1.5 字段规格

**存档台账（11 列）**

| 列 | 字段 | 说明 |
|---|---|---|
| 清退单号 | `id` | — |
| 商户名称 | `merchantName` | 跳 P3 档案 |
| 商户类型 | `merchantType` | — |
| 关联档口 | `unit` | 来自 02（快照） |
| 合同号 | `contractNo` | 来自 05 |
| **终止类型** | `termType` | 五类枚举 |
| **终止生效日** | `effectiveAt` | — |
| 终止原因 | `reason` | 合同侧填写，**只读** |
| 操作人（合同侧） | `operator` | 合同专员 |
| 状态 | `state` | 已生效（本页只收已生效） |
| 操作 | — | 详情 |

**详情时间轴（只读）**

`提交终止 → 主管确认 → 05 合同置「已终止」→ 02 档口「当前租户」清空并回「空闲（待竞拍）」→ 04 商户状态按原因置「违约终止 / 已终止」→ 物业权限与关联账号回收`

> 商户状态映射：**违约类原因 → 违约终止**；**非违约原因 → 已终止**。

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 详情 | 始终 | 始终 | 只读时间轴抽屉 | — |
| 导出 | 始终 | 专员/主管 | 导出当前筛选 | — |
| ~~发起清退~~ | — | — | **本页不提供**（在 05 合同台账发起） | — |
| 跳档案 | 商户名 | 始终 | 跳 `merchant-profile.html`（状态=已清退/已终止） | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-29 | 只收提前终止 | 归档 | 正常到期不进本页 | — |
| R-30 | 只读 | 任何时候 | 无编辑、无发起、无删除 | — |
| R-31 | 状态按原因落定 | 终止生效 | 违约→违约终止；非违约→已终止 | 商户端 |
| R-32 | 不含线上店铺 | 归档 | 店铺归 10 商城，不在本页处理 | — |
| R-33 | 不含保证金 | 归档 | 保证金线下必缴已收 | — |
