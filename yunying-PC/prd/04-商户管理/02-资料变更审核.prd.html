1. 资料变更审核 merchant-change.html

1.1 页面说明

项内容
页面目标审核商户提交的经营信息 / 资质变更，通过后回写主档并留痕
使用角色商户管理专员、运营主管
入口菜单 → 商户管理 → 资料变更审核
前置商户已在商户端提交变更申请
后置主档更新；资质类变更联动刷新有效期与报价权限

1.2 本页端间关系

项内容
本页数据来源商户端 shanghu-APP/mine.html 的「商户资料」提交
本页操作的跨端影响通过 → 商户端资料立即更新；资质类 → 报价权限状态同步
依赖的其他端页面shanghu-APP/mine.html（提交入口）
不涉及的端买家端
一致性要求主档回写留痕（前后值 + 人 + 时间）

1.3 页面结构

区块内容
顶部标题「资料变更审核」+ 导出
统计卡待审核变更 / 本月通过 / 本月驳回（各带副值：待审核 / 已通过 / 已驳回计数）
筛选区关键词（商户名称 / 变更编号）+ 变更类型 + 状态 + 日期区间 + 查询 + 重置
列表8 列 + 分页
审核抽屉变更前后对比表（3 列：字段 / 变更前 / 变更后）+ 通过 / 驳回

1.7 业务规则与计算口径

编号规则触发处理影响端
R-07通过即回写主档通过前后值 + 操作人 + 时间入留痕商户端
R-08资质类变更联动通过（类型=资质）刷新资质有效期 → 报价权限状态同步商户端、10a
R-09驳回原因必填驳回字典 + 自由备注商户端
R-10只读字段过滤提交身份证/编号/类型/档口不进变更集—
R-11同一字段在途唯一提交同商户同字段只允许一条待审核商户端
