## 1. 资料变更审核 `merchant-change.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 审核商户提交的经营信息 / 资质变更，**通过后回写主档并留痕** |
| 使用角色 | 商户管理专员、运营主管 |
| 入口 | 菜单 → 商户管理 → 资料变更审核 |
| 前置 | 商户已在商户端提交变更申请 |
| 后置 | 主档更新；资质类变更联动刷新有效期与报价权限 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 商户端 `shanghu-APP/mine.html` 的「商户资料」提交 |
| 本页操作的跨端影响 | 通过 → 商户端资料立即更新；资质类 → 报价权限状态同步 |
| 依赖的其他端页面 | `shanghu-APP/mine.html`（提交入口） |
| 不涉及的端 | 买家端 |
| 一致性要求 | 主档回写留痕（前后值 + 人 + 时间） |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「资料变更审核」+ 导出 |
| **统计卡** | 待审核变更 / 本月通过 / 本月驳回（各带副值：待审核 / 已通过 / 已驳回计数） |
| 筛选区 | 关键词（商户名称 / 变更编号）+ 变更类型 + 状态 + 日期区间 + 查询 + 重置 |
| 列表 | **8 列** + 分页 |
| 审核抽屉 | 变更前后对比表（**3 列**：字段 / 变更前 / 变更后）+ 通过 / 驳回 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 提交时间倒序 |
| 分页 | 页码 |
| 筛选组合 | 条件之间 **且** |
| 变更类型 | 企业信息 / 联系方式 / 资质 / 经营类目（**已移除「商位」**） |
| 状态 | 待审核 / 已通过 / 已驳回 |
| 空结果 | 端上「暂无变更申请」 |

### 1.5 字段规格

**变更列表（8 列）**

| 列 | 字段 | 说明 |
|---|---|---|
| 变更编号 | `id` | 点击进详情 |
| 商户名称 | `merchantName` | 点击跳 P3 档案 |
| 商户类型 | `merchantType` | 仅线上 / 线上兼档口 / 仅线下档口 |
| 变更类型 | `type` | 四类枚举 |
| 变更内容摘要 | `diff` | **前后值对比**，多字段折叠 |
| 提交时间 | `submitAt` | — |
| 状态 | `state` | 待审核 / 已通过 / 已驳回 |
| 操作 | — | 审核 / 详情 |

**前后对比（3 列）**：字段 / 变更前 / 变更后

> 只读字段不可变更：**身份证、商户编号、商户类型、关联档口**（来源 02/05）。

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 审核 | 状态=待审核 | 专员/主管 | 抽屉（前后对比 + 备注） | — |
| 通过 | 待审核 | 专员/主管 | 回写主档 + 留痕 + 通知商户 | — |
| 驳回 | 待审核 | 专员/主管 | 必须选原因（字典 + 备注） | 未选 → M-11 |
| 详情 | 始终 | 始终 | 只读抽屉 | — |
| 跳档案 | 商户名称 | 始终 | 跳 `merchant-profile.html` | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-07 | 通过即回写主档 | 通过 | 前后值 + 操作人 + 时间入留痕 | 商户端 |
| R-08 | 资质类变更联动 | 通过（类型=资质） | 刷新资质有效期 → 报价权限状态同步 | 商户端、10a |
| R-09 | 驳回原因必填 | 驳回 | 字典 + 自由备注 | 商户端 |
| R-10 | 只读字段过滤 | 提交 | 身份证/编号/类型/档口不进变更集 | — |
| R-11 | 同一字段在途唯一 | 提交 | 同商户同字段只允许一条待审核 | 商户端 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 驳回未选原因 | 拦截 | 【已实现】「驳回原因必填，请先选择」 |
| 数据 | 列表为空 | 空态 | — |
| 权限 | 非专员点审核 | 按钮隐藏 | — |
| 并发 | 两人同时审同一条 | 后者收到冲突 | **【待实现】M-48** |
