1.1 页面说明

项内容
页面目标商户主档的查询、维护与画像；只含实体（档口）商户（纯线上商户归 10 商城）
使用角色商户管理专员（主）、运营主管、运营专员（只读 + 标签）、财务（只读口径字段）
入口菜单 → 商户管理 → 商户档案；也从 P1 建档成功、P2 变更页跳入
前置已由 05 合同「已存档」自动建档，或手工补档
后置编辑留痕；关联账号变更即时生效

1.2 本页端间关系

项内容
本页数据来源05 合同 + 02 档口（只读）；商户端提交的变更经 P2 回写
本页操作的跨端影响添加员工 → 被关联账号立刻可见档口信息 + 物业模块；解除 → 即时收回
依赖的其他端页面shanghu-APP/mine.html、property.html、contract.html、payment.html（均为写死档口号，需改读本页）
不涉及的端买家端（仅 shop-detail.html 商位信息间接引用）
一致性要求关联/解除关联即时生效并留痕

⑥变更与操作留痕建档来源 / 类型升降 / 权限开收 / 状态变更（人+时间+前后值）
⑦关联数据入口合同（05）/ 缴费（06）/ 店铺（10）/ 评价（买家端）
⑧物业权限与关联账号授权员工数 / 权限有效期 / 关联台账（档口 × 使用人 × 操作人 × 时间）+ 添加员工 / 解除

同一档口可多条（每份合同一条，以合同号区分）；空态「暂无历史租赁记录」（首次租赁，未换过档口）。
