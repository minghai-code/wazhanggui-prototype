1.1 原料市场六品类（Y-11，2026-11-03 增补）

买家端原料市场（F05）上线后，品类字典补入 6 个原料细类（与买家端对外叫法逐字一致）：

编号品类大类说明
CT-015纱线原料纱线由原「棉纱 CT-009」「氨纶包覆纱 CT-010」合并而来（两项已停用，历史数据保留）
CT-016化纤长丝原料纱线
CT-017染料助剂原料纱线
CT-018辅料橡筋原料纱线
CT-019包装物料原料纱线物料类，区别于「设计包装」大类的服务
CT-020纺机配件原料纱线

市场分流支点（F05-R2）：店铺 / 商户的「主营品类」是否包含「原料纱线」大类，决定其在买家端的可见市场——

  • 含原料大类 → 原料市场；仅袜品等其他大类 → 袜子市场；两者都有（混营）→ 两个市场都展示
  • 品类为空 → 未归类，两个市场都不展示，运营催补
  • 因此本字典是市场分流的唯一数据支点，品类项的增删停用直接影响市场归属

不做什么：不做品类层级树（大类是固定 5 类，不是可维护的树）；不做品类与商品的绑定（商品品类归 10 商城运营，本期只统一"商户经营品类"口径）。

3. 字段

字段必填规则
品类编号系统CT-xxx

所属大类是袜品 / 原料纱线 / 袜机设备 / 设计包装 / 其他（固定 5 类，只用于筛选与排序分组）

备注否如"2026-08 起无商户使用，暂时停用"

4. 操作与规则

操作条件效果
新增—立即进入商户档案 / 端上认证 / 变更审核的选择项（发布即生效）
编辑—改名会同步改写所有已引用商户的品类名；改大类/排序只影响展示与筛选
停用 / 启用除「其他」停用后不进新的选择项；已选该品类的商户数据保留，档案仍显示（灰标）
合并到…除「其他」选目标品类 + 填原因 → 源品类的关联商户自动改挂目标品类 → 源品类置停用并标注"已并入 X"（不删除，可追溯）
导出—含大类、关联商户数、使用状态
查看关联商户关联数 > 0列出商户名称与编号，可跳档案

规则

编号规则
CT-1品类名称全局唯一，重复即阻断（并提示用合并）
CT-2只停用不删除，保证历史商户档案可追溯
CT-3停用不影响历史数据，仅从新选择项消失；已选该品类的商户在档案列表与编辑抽屉仍显示（灰标 · 删除线 · 标「已停用」，不可再新增，可移除）
CT-4合并 = 改挂 + 源停用 + 写入商户档案变更留痕，不做物理删除
CT-5只是写法不同（男式袜 / 男袜）→ 用合并，不要改名或新增
CT-6「其他」为兜底项，不可停用、不可合并
