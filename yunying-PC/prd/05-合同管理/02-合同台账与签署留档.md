## 1. 合同台账与签署留档 `contract-list.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 全量合同台账 + 签署流程与用印归档；**档口「在租」状态的唯一数据源** |
| 使用角色 | 合同管理专员（主）、运营主管、物业（本楼栋只读）、财务（只读） |
| 入口 | 菜单 → 合同管理 → 合同台账与签署留档 |
| 前置 | 已有合同（发起链路见 P4，存量见本页录入） |
| 后置 | 生效 → 推送 02（档口在租）+ 04（自动建档）+ 生成应收计划 |

> **v1.17 关键口径（2026-11-10）——证件号「哪里能改、哪里不能改」**
> 客户样本合同正文抬头为 `承租方（乙方）：________ 社会信用代码（身份证号码）：________`，**个人填身份证号、企业填统一社会信用代码，共用一栏且不能为空**。但正文在「生成并发送」时已定型，因此本页按合同状态分三档：
> | 合同状态 | 证件号能否在台账直改 | 正确路径 |
> |---|---|---|
> | **待映射**（存量导入、尚未生效） | ✅ **可直接补录**（行内输入框 + 保存） | 保存 → 触发 02 重匹配 + 04 去重升级（K-16） |
> | **待发起 / 待商户签字 / 待签署审核**（签署中） | ❌ **不提供输入框**，显示「身份待补全」+ 补录链接 | 点补录 → 提示 **K-53** → 去 P4 发起页「撤回」退回待发起 → 重新生成 v+1 → 重发签署 |
> | **已存档·生效中 / 变更中** | ❌ **不允许后台直改** | 点补录 → 提示 **K-53** → 走本页「变更」（变更协议重签），变更原因注明「补录证件号」 |
> 另：合同文本预览的乙方抬头同步为「承租方 + 社会信用代码（身份证号码）」，并新增「联系人 / 联系电话」一行（**联系电话 = 签署匹配键，正文必须有**）。

### 3.6 履约保证金块（v2.0 新增）

放在合同详情「③ 合同状态与终止」之后、「④ 签署留档」之前：

| 区域 | 内容 |
|---|---|
| 四宫格 | 约定金额（每间单价 × 间数）｜已扣（罚款 / 环境费）｜当前余额｜收取状态（待收 / 已收 / 已扣除 / 已退还 / 已没收） |
| 流水表 | 时间 / 动作（收取·扣除·退还·没收）/ 金额 / 说明与依据（收据号、条款出处） |
| 操作 | 登记收取、登记扣除（罚款 / 环境费）、登记退还——**全部只登记结果**，收付在财务线下执行 |

> 依据合同**第五条**（每间 × 间数 = 合计，签订前支付，期满结清后退还、不计息）与**第七条 5 项**（罚款、环境影响费先现金收取，拒付时从保证金中扣除）。违约金与滞纳金系统仍不计算。
