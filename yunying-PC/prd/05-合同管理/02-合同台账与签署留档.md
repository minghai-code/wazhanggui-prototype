## 1. 合同台账与签署留档 `contract-list.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 全量合同台账 + 签署流程与用印归档；**档口「在租」状态的唯一数据源** |
| 使用角色 | 合同管理专员（主）、运营主管、物业（本楼栋只读）、财务（只读） |
| 入口 | 菜单 → 合同管理 → 合同台账与签署留档 |
| 前置 | 已有合同（发起链路见 P4，存量见本页录入） |
| 后置 | 生效 → 推送 02（档口在租）+ 04（自动建档）+ 生成应收计划 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | P4 发起链路产生的合同 + 存量合同录入 / 导入 |
| 本页操作的跨端影响 | 生效 → 商户端 `contract.html` 可查；档口映射 → 02 在租；建档 → 04；应收 → 06 |
| 依赖的其他端页面 | `shanghu-APP/contract.html`（**现为写死，需改读本页**）、`02/resource-unit.html`（档口） |
| 不涉及的端 | 买家端 |
| 一致性要求 | 按**档口编号**推送，失败回流 02 异常清单；**到期 ≠ 终止** |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「合同台账与签署留档」+ 导出 + 录入合同 + 批量导入 + 手动同步 |
| **统计卡** | 合同总数 / 生效中 / 待映射 / 90 天内到期 / 已终止（提前终止·人工）/ 待签署 |
| 筛选区 | 关键词 + 状态 + 到期范围 + 签署状态 + 资源类型 + 查询 + 重置 |
| 合同台账 | **11 列** + 分页 |
| 详情抽屉 | 签署流程与用印归档 + 应收计划表（**5 列**）+ 档口映射 + 留痕 |
| 导入结果 | 错误清单表（**2 列**：行号 / 错误原因） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 合同号倒序 |
| 分页 | 页码 |
| 筛选组合 | 条件之间 **且** |
| 到期范围 | 30 / 60 / 90 天内 / 已到期 |
| 签署状态 | 待发起 / 待商户签字 / 待签署审核 / 已存档 |
| 空结果 | 「没有符合条件的合同」 |
| 导出 | 身份证、权证号**已脱敏** |

### 1.5 字段规格

**合同台账（11 列）**

| 列 | 字段 | 说明 |
|---|---|---|
| 合同号 / 卷号 | `no` / `vol` | — |
| **摊位号 → 档口编号** | `stallNo` / `unitNo` | 映射成功才推 02；失败进异常清单 |
| 承租人 | `tenant` | 企业主体显示企业名称 + 联系人 |
| 面积 | `area` | ㎡ |
| 租期 | `start`~`end` | T-90/60/30 标色 |
| 年租金 / 总租金 | `annualRent` / `totalRent` | **年口径** |
| 摊位等级 | `level` | 精品摊（5 年 / 保证金 2 万）/ 普通摊（3 年 / 1 万） |
| 应收计划 | `plan` | 摘要，详情看 5 列表 |
| **签署状态（v1.2）** | `signState` | 待发起 / 待商户签字 / 待签署审核 / 已存档 + 盖章子标记 |
| 状态 | `state` | 见 §0.5 九态 |
| 操作 | — | 详情 / 映射 / 终止 / 签署 / 录入 / 导入 |

**应收计划（5 列）**：期次 · 所属租赁年度 · 应收金额 · 应收时点 · 状态

**导入错误（2 列）**：行号 · 错误原因

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 详情 | 始终 | 始终 | 抽屉（签署流程 + 应收计划 + 留痕） | — |
| 档口映射 | 待映射 / 映射失败 | 专员/物业 | 选档口编号 → 推送 02 | 映射失败保留原值 |
| **终止** | 状态=生效中 | 专员发起 + **必须勾选主管确认** | 置已终止 → 02 档口回空闲 → 04 回退 → 回收权限 | 未勾 → K-19 |
| 签署 | 待发起 / 待商户签字 | 专员 | 打开签署流程（P4） | — |
| 录入合同 | 始终 | 专员 | 存量录入（企业主体四连校验） | 缺必填 → K-22~K-26 |
| 批量导入 | 始终 | 专员 | 校验全部通过才入库 | 有错 → 错误清单 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-06 | 按**档口编号**推送 02 | 生效/变更 | 匹配失败进 02 异常清单，不静默 | 02 |
| R-07 | 合同生效即档口在租 | 生效 | 02 该档口「当前租户」= 承租人 | 02 |
| R-08 | 合同生效触发 04 建档 | 已存档 | 消费「已存档」事件 | 04 |
| R-09 | **终止需主管确认** | 终止 | 必须勾选，记录确认人 | 02/04 |
| R-10 | 到期 ≠ 终止 | 租期结束 | 自动置已到期，档口回「空闲（待竞拍）」，**无审批无原因** | 02/04 |
| R-11 | 签署匹配键 = 手机号 | 发送 | 与竞拍登记不一致 → 专员改绑 | 商户端 |
| R-12 | 盖章件不影响生效 | 归档 | 仅 `待回传/已回传` 子标记 | — |
| R-13 | 签约年限 / 保证金随等级 | 录入 | 精品 5 年 / 2 万；普通 3 年 / 1 万 | — |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-05 | 合同待映射 | 映射摊位号 → 档口 | 映射成功，02 该档口显示在租 | P0 |
| AC-06 | 生效中合同 | 点终止未勾确认 | 拦截并提示先勾选主管确认 | P0 |
| AC-07 | 已勾确认 | 点终止 | 合同已终止，02 档口回空闲，04 权限回收 | P0 |
| AC-08 | 合同正常到期 | 等待到期 | 自动置「已到期」，**不进清退台账**（04 P6） | P0 |
| AC-09 | 批量导入含错行 | 提交 | 整批不入库，错误清单列出原因 | P1 |
| AC-10 | 同一摊位号映射两个档口 | 保存 | 拦截或标记冲突 | P1 |
