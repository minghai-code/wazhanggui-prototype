## 1. 合同变更审核 `contract-change.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 审核合同在途变更（租金 / 租期 / 面积 / 承租人 / 主体信息 / 摊位号） |
| 使用角色 | 合同管理专员（发起）、运营主管（**敏感变更审批**） |
| 入口 | 菜单 → 合同管理 → 合同变更审核 |
| 前置 | 有在途变更单（商户端申请或专员发起） |
| 后置 | 合同号不变、生成新版本；重推 02 / 06 / 04 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 商户端变更申请（**端上入口缺**）+ 专员发起 |
| 本页操作的跨端影响 | 通过 → 04 档案主体同步 + **签署匹配键同步**（电话变更 → 签署手机号同步；在签署中则改绑重签）；重推 02/06 |
| 依赖的其他端页面 | `shanghu-APP/mine.html`（**变更入口缺，需新增**） |
| 不涉及的端 | 买家端 |
| 一致性要求 | 合同号不变；主体信息变更需重签补充协议 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「合同变更审核」+ 导出 |
| **统计卡** | 待审核 / 本月通过 / 本月驳回 / 待审中含敏感变更（含主体信息） |
| 筛选区 | 关键词 + 变更类型 + 状态 + 日期 + 查询 + 重置 |
| 列表 | **8 列** + 分页 |
| 审批抽屉 | 前后对比表（**3 列**：字段 / 改前 / 改后）+ 下游影响预览 + 通过 / 驳回 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 提交时间倒序 |
| 分页 | 页码 |
| 筛选组合 | 条件之间 **且** |
| 变更类型（**六类**） | 租金 / 租期 / 面积 / 承租人 / **主体信息变更** / 摊位号（拆"终止 + 新签"） |
| 状态 | 待审核 / 已通过 / 已驳回 |
| 空结果 | 「暂无变更单」 |

### 1.5 字段规格

**变更列表（8 列）**

| 列 | 字段 | 说明 |
|---|---|---|
| 变更单号 | `id` | — |
| 合同号 / 承租人 | `contractNo` / `tenant` | **企业主体显示企业名称 + 联系人** |
| 变更类型 | `type` | 六类；**敏感标记**（租金/租期/承租人/主体信息 = 需主管审批） |
| 变更前后对比 | `diff` | 摘要，含**主体信息组** |
| 来源 / 提交人 | `source` / `submitter` | 商户端申请 / 专员发起 |
| 提交时间 | `submitAt` | — |
| 状态 | `state` | 待审核 / 已通过 / 已驳回 |
| 操作 | — | 审核 / 详情 |

**前后对比（3 列）**：字段 / 改前 / 改后
> 主体信息组包含：主体类型切换 / 企业名称 / 统一社会信用代码 / 法定代表人·联系人 / 联系电话 / 企业类型。

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 审核 | 状态=待审核 | 专员/主管 | 抽屉（对比 + 下游影响预览） | — |
| **通过（敏感类）** | 待审核 | **主管** | 二次确认 → 回写 + 重推 | 非主管 → 隐藏 |
| 通过（普通类） | 待审核 | 专员/主管 | 回写 + 重推 02/06/04 | — |
| 主体信息变更 | 类型=主体 | 主管 | **必须先勾「主体变更核验」** | 未勾 → K-29 |
| 驳回 | 待审核 | 专员/主管 | 必须填原因 | 空 → K-31 |
| 详情 | 始终 | 始终 | 只读 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-14 | 合同号不变，生成新版本 | 通过 | 保留历史版本 | — |
| R-15 | 敏感类需主管审批 | 租金/租期/承租人/主体 | 主管确认 + 留痕 | — |
| R-16 | 主体变更核验 | 主体信息类 | 信用代码 18 位且不重复 + 已收工商变更证明 | 04 |
| R-17 | 电话变更同步签署键 | 联系电话变更 | 04 档案同步；在签署中 → 改绑重签 | 04、商户端 |
| R-18 | 需重签补充协议 | 租金/租期/主体类 | 打「需重签变更补充协议」标记 | 商户端 |
| R-19 | 摊位号变更 = 终止 + 新签 | 该类型 | 不直接改，拆两步 | 02 |
| R-20 | 通过后重推 02/06/04 | 通过 | 档口/应收/档案同步更新 | 三处 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 主体变更未核验 | 拦截 | 【已实现】「主体信息变更：请先勾选「主体变更核验」…」 |
| 数据 | 驳回未填原因 | 拦截 | 【已实现】「驳回原因必填」 |
| 数据 | 信用代码与他企重复 | 拦截 | 【待实现】应提示重复企业 |
| 权限 | 非主管通过敏感变更 | 按钮隐藏 | — |
