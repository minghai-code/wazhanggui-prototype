1.1 页面说明

项内容
页面目标审核合同在途变更（租金 / 租期 / 面积 / 承租人 / 主体信息 / 摊位号）
使用角色合同管理专员（发起）、运营主管（敏感变更审批）
入口菜单 → 合同管理 → 合同变更审核
前置有在途变更单（商户端申请或专员发起）
后置合同号不变、生成新版本；重推 02 / 06 / 04

1.2 本页端间关系

项内容
本页数据来源商户端变更申请（端上入口缺）+ 专员发起
本页操作的跨端影响通过 → 04 档案主体同步 + 签署匹配键同步（电话变更 → 签署手机号同步；在签署中则改绑重签）；重推 02/06
依赖的其他端页面shanghu-APP/mine.html（变更入口缺，需新增）
不涉及的端买家端
一致性要求合同号不变；主体信息变更需重签补充协议

1.6 交互规则

元素显示条件可点条件点击后禁止表现

1.7 业务规则与计算口径

编号规则触发处理影响端
R-14合同号不变，生成新版本通过保留历史版本—
R-15敏感类需主管审批租金/租期/承租人/主体主管确认 + 留痕—
R-16主体变更核验主体信息类信用代码 18 位且不重复 + 已收工商变更证明04

R-19摊位号变更 = 终止 + 新签该类型不直接改，拆两步02
R-20通过后重推 02/06/04通过档口/应收/档案同步更新三处
