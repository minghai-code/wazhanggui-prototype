## 工具

```powershell
node tools\build-prd.mjs              # md → prd.html（改完 md 后跑）
node tools\check-page-prd.mjs         # 一致性检查（交付前跑，ERROR 必须清零）
```

## 新增一个页面的步骤

1. 在对应模块目录下新建 `NN-页面名.md`（首篇才写 §0 模块通用说明）
2. 本表加一行
3. 页面末尾加 `<script src="../shared/page-prd.js"></script>`
4. 在 `shared/page-prd.js` 的 `PRD_MAP` 里加一行映射（**指向本页那一份**）
5. 跑 `build-prd.mjs`
