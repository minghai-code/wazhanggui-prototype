## 1. AI 服务助手配置 `ai-route.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 让运营自己维护「用户说什么 → 助手回什么 → 点了去哪」，**新增服务要上线、页面改路径、政策口径变更**都不再发版 |
| 现状缺口 | 买家端已实现「意图识别 + 分级路由（L1 直达 / L2 追问 / L3 知识 / L4 兜底）+ 服务自助推荐」，但 `CARDS` / `INTENTS` / `KB_ITEMS` **全部写死在端上** → 新服务上线要发版、改路径会 404、政策变更要发版 |
| 使用角色 | 平台运营（可配置 + 发布） |
| 入口 | 侧边栏 → 18 系统设置 → AI 服务助手配置 |
| 前置 | 端上页面清单已同步（本期为 mock，二期由端上页面资产注册表提供） |
| 后置 | 发布生成新版本号 → 端上下次启动拉取 → 命中行为改变 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 意图排序 | 按配置顺序（= 端上匹配顺序），不提供拖拽排序，调顺序用「优先级」字段 |
| 意图筛选 | 关键词（意图名 / ID / 关键词）· 类型（功能意图 / 知识问答）· 层级（L1 / L2 / L3）· 状态（启用 / 停用） |
| 类型 = 知识问答 | 在 Tab1 只作**聚合视图**（同一份 `kb` 数据，不重复存），操作列只给「去编辑」，跳 Tab2 |
| 知识筛选 | 关键词（标题 / ID / 关键词 / 答案正文）· 状态 |
| 行状态 | 停用行整体置灰；引用已下线页面的行**整行标红**（左侧红条 + 「目标页已下线」标签） |
| 空结果 | 意图表：`没有匹配的意图；知识问答题请在「知识问答」Tab 维护`；知识表：`没有匹配的知识问答` |
| 分页 | 不分页（本期内置量级：意图 < 30、知识 < 100） |

### 1.5 字段规格

**意图表（10 列）**

| 列 | 字段 | 说明 |
|---|---|---|
| 意图名 / ID | `label` / `id` | ID 为端上引用键，创建后不可改 |
| 类型 | 派生 | 功能意图 / 知识问答 |
| 关键词数 | `keys.length` | 悬停/点击进编辑；下方显示前 3 个词 |
| 层级 | 派生 | **配了追问 = L2**；只配目标页 = L1；知识 = L3（不手填） |
| 目标页数 | 派生 | L1 直出卡片数；L2 为追问选项内去重后的卡片数 |
| 优先级 | `priority` | 同分时高者胜（R-5） |
| 状态 | `enabled` | 启用 / 停用 |
| 近 7 天命中 | 派生（不进契约） | 端上报数据，本期 mock |
| 更新时间 | 派生（不进契约） | 最后一次保存草稿的时间 |
| 操作 | — | 编辑 · 启停 · 复制（副本默认停用）· 删除（二次确认 + 提示落到兜底） |

**知识表（8 列）**：标题 / ID · 关键词 · 答案正文（≤200 字，超出红字提示）· 相关入口（1–2）· 状态 · 近 7 天命中 · 更新时间 · 操作（编辑 · 启停 · 复制）

**意图编辑抽屉（P2）**

| 区块 | 字段 | 校验 |
|---|---|---|
| 基本信息 | 意图名 `label` · 意图 ID `id` · 优先级 `priority`（0–99）· 启用 `enabled` | 名称/ID 必填、ID 唯一且创建后不可改 |
| 层级（只读） | 自动判定结果 + 规则说明 | **不可手填**（R-3） |
| 关键词 | `keys[]` 标签式，回车/逗号追加；「批量粘贴」支持逗号 / 顿号 / 分号 / 空格 / 换行 | 至少 1 个；提示「单字不触发、词长加权」 |
| 追问 | `clarify[]`：问题 `q` 1 句 + 选项 `opts[]` 2–3 个，每选项绑 1–3 个目标页 | 有追问时 **L1 目标页区块禁用**并说明层级互斥；保存时清空 `cards` |
| 目标页 | `cards[]` 1–3 个（仅 L1 时出现） | 只能从选择器选，**无 URL 输入框**（R-1） |

**知识编辑抽屉（P3）**：标题 `t` · ID · 启用 · 关键词 `keys[]` · 答案正文 `a`（实时字数，>200 红字 + 发布拦截）· 相关入口 `cards[]` 1–2 个

**兜底（P4）**：文案 `fallback.text` · 常用入口 `fallback.cards` **固定 3 个**（缺失/多选均被发布拦截）

### 1.6 数据结构契约（与买家端一致 · 字段名冻结）

```json
{
  "version": "2026-11-06-1",
  "cards": {
    "market-socks.html": { "n": "袜子市场", "d": "按品类 / 价格筛选，可直接询价", "i": "fa-socks", "g": "linear-gradient(...)" }
  },
  "intents": [
    { "id": "find", "label": "找货", "keys": ["找货","找袜子","男袜"],
      "priority": 10, "enabled": true,
      "cards": ["market-socks.html","market-material.html"],
      "clarify": [ { "q": "想在哪找货？",
        "opts": [ { "t": "线上市场", "cards": ["market-socks.html","market-material.html"] } ] } ] }
  ],
  "kb": [
    { "id": "kb-fee", "keys": ["收费","费用"], "t": "平台怎么收费", "a": "买家侧不收费……", "cards": ["membership.html"] }
  ],
  "fallback": { "text": "这个问题我还没学会……", "cards": ["market-socks.html","orders.html","merchant-join.html"] }
}
```

| 约定 | 内容 |
|---|---|
| 字段清单 | `version` / `cards{n,d,i,g}` / `intents[{id,label,keys,priority,enabled,cards,clarify[{q,opts[{t,cards}]}]}]` / `kb[{id,keys,t,a,cards}]` / `fallback{text,cards}` |
| 停用处理 | 停用的意图以 `enabled:false` 下发（契约已有该字段）；**停用的知识问答不下发** —— `kb[]` 只含启用项，端上无需过滤代码 |
| 卡片只定义一次 | 同一入口的名称/说明/图标/渐变色只写在 `cards` 里，意图与追问**按 URL 引用**，避免同一入口多处描述不一致 |
| 空数组处理 | 意图没有 L1 卡片时不下发 `cards`；没有追问时不下发 `clarify`（保持与端上现状一致） |
| 改名禁令 | **任何已发布字段名不得修改**；买家端已按此结构实现，改名 = 二期切换要动两端 |

### 1.7 关键规则

| # | 规则 | 实现位置 |
|---|---|---|
| R-1 | **目标页只能选，不能填**：选择器从「已上线页面清单」选（按页面名/路径搜索，展示标题 + 路径 + 卡片说明），**没有 URL 输入框** —— 从根上杜绝 404 | 选择器弹窗 |
| R-2 | **页面下线联动**：页面下线后，引用它的意图 / 追问选项 / 知识卡 / 兜底入口**标红**，提示「目标页已下线，请更换或停用」，**未处理不允许发布**；停用项不阻塞（不推给端上） | 列表行 / 编辑抽屉 / 发布拦截 |
| R-3 | **层级自动判定，不手填**：配了追问 = L2；只配目标页 = L1；知识问答 = L3；**三者互斥**（有追问即清空 L1 卡片）；L4 只在兜底配 | 编辑抽屉只读区块 + 保存校验 |
| R-4 | **草稿 → 发布**：编辑即存草稿（可反复改）；点「发布」生成新版本号并推给端上；未发布的改动不影响线上；发布前展示变更摘要 | 发布卡 + 顶部发布 |
| R-5 | **同分优先级**：端上按关键词长度加权打分，同分看 `priority`（高者胜）；知识与意图同分时**知识优先**（端上规则，后台只提示） | 编辑抽屉字段说明 + 预览测试的判定过程 |
| R-6 | **删除保护**：删除意图二次确认并提示"买家端将落到兜底"；知识问答**可停用不必删** | 删除 / 停用 |
| R-7 | **发布即生效**：端上启动时拉配置（带版本号），版本未变则用本地缓存，避免每次开页都请求 | 发布动作 + 页脚提示 |
| R-8 | **可回滚**：保留最近 **20** 个版本，一键回滚并**生成新版本**（不回改历史） | 发布记录 / 回滚 |

### 1.8 关键交互与状态

| 场景 | 行为 |
|---|---|
| 保存（任意编辑） | 只写草稿：标记「草稿改动 N 处」+ 变更摘要逐条累积（`+ 新增意图「…」` / `改 意图「…」` / `- 删除意图「…」` / 停用 / 复制 / 改兜底） |
| 发布 | 校验链：① 下线引用数 = 0 ② 有未发布改动 ③ 兜底入口 = 3 ④ 知识正文 ≤200 字 → 生成版本号 `日期-序号` → 写入发布记录（含快照）→ 清空变更摘要 → 端上下次启动生效 |
| 发布被拦截 | 顶部红条 + 发布处红字说明 + Toast 指出第一条阻塞项；「处理第一处」直接打开对应编辑抽屉 |
| 预览测试 | 用**当前草稿**跑与端上同一套打分：词长加权求和、阈值 ≥2、同分看优先级、知识同分优先；输出「命中意图 / 命中关键词 / 层级 / 将输出卡片（含路径）」；**不写库**，最多 5 句 |
| 模拟下线（演示） | 选择器每行「模拟下线 / 恢复上线」→ 立即触发标红与发布拦截（对应验收 AC-5），用于给客户演示 R-2 |
| 回滚 | 确认后以所选版本内容替换当前草稿数据并**生成新版本**（`回滚到 2026-11-05-2`），历史版本保留 |
| 演示持久化 | 发布时另存 `localStorage.ai_route_config` + `ai_route_version`（仅演示；二期端上改为读服务端接口） |

### 1.9 验收（后台侧）

| # | 操作 | 预期 |
|---|---|---|
| AC-1 | 新增一个意图（选 2 个目标页）并发布 | 买家端助手输入对应话术能命中并给卡；**未发布时不生效**（草稿仅后台可见） |
| AC-2 | 把某意图的目标页从 A 换成 B 并发布 | 端上入口卡指向 B（预览测试里可直接看到卡片路径变化） |
| AC-3 | 停用某意图 | 端上不再命中该意图，落到兜底；该问法若命中知识问答则走知识 |
| AC-4 | 目标页选择器里搜关键词 | 只出已上线页面；**页面上没有任何可填 URL 的输入框** |
| AC-5 | 模拟某目标页下线 | 该意图 / 追问选项 / 知识卡**标红**且**无法发布**，直到更换目标页或停用该项 |
| AC-6 | 预览测试输入「我想找纯棉男袜」 | 显示命中「找货」+ **L2 追问** + 追问选项（命中关键词：想找、男袜） |
| AC-7 | 发布后回滚到上一版本 | 端上恢复上一版行为，且**生成新版本号**（历史版本不被改写） |
