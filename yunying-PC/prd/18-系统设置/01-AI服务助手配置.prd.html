1.5 字段规格

意图表（10 列）

列字段说明
意图名 / IDlabel / idID 为端上引用键，创建后不可改
类型派生功能意图 / 知识问答
关键词数keys.length悬停/点击进编辑；下方显示前 3 个词
层级派生配了追问 = L2；只配目标页 = L1；知识 = L3（不手填）
目标页数派生L1 直出卡片数；L2 为追问选项内去重后的卡片数
优先级priority同分时高者胜（R-5）
状态enabled启用 / 停用
近 7 天命中派生（不进契约）端上报数据，本期 mock
更新时间派生（不进契约）最后一次保存草稿的时间
操作—编辑 · 启停 · 复制（副本默认停用）· 删除（二次确认 + 提示落到兜底）

知识表（8 列）：标题 / ID · 关键词 · 答案正文（≤200 字，超出红字提示）· 相关入口（1–2）· 状态 · 近 7 天命中 · 更新时间 · 操作（编辑 · 启停 · 复制）

意图编辑抽屉（P2）

区块字段校验
基本信息意图名 label · 意图 ID id · 优先级 priority（0–99）· 启用 enabled名称/ID 必填、ID 唯一且创建后不可改
层级（只读）自动判定结果 + 规则说明不可手填（R-3）
关键词keys[] 标签式，回车/逗号追加；「批量粘贴」支持逗号 / 顿号 / 分号 / 空格 / 换行至少 1 个；提示「单字不触发、词长加权」
追问clarify[]：问题 q 1 句 + 选项 opts[] 2–3 个，每选项绑 1–3 个目标页有追问时 L1 目标页区块禁用并说明层级互斥；保存时清空 cards
目标页cards[] 1–3 个（仅 L1 时出现）只能从选择器选，无 URL 输入框（R-1）

知识编辑抽屉（P3）：标题 t · ID · 启用 · 关键词 keys[] · 答案正文 a（实时字数，>200 红字 + 发布拦截）· 相关入口 cards[] 1–2 个

兜底（P4）：文案 fallback.text · 常用入口 fallback.cards 固定 3 个（缺失/多选均被发布拦截）

约定内容
字段清单version / cards{n,d,i,g} / intents[{id,label,keys,priority,enabled,cards,clarify[{q,opts[{t,cards}]}]}] / kb[{id,keys,t,a,cards}] / fallback{text,cards}
停用处理停用的意图以 enabled:false 下发（契约已有该字段）；停用的知识问答不下发 —— kb[] 只含启用项，端上无需过滤代码
卡片只定义一次同一入口的名称/说明/图标/渐变色只写在 cards 里，意图与追问按 URL 引用，避免同一入口多处描述不一致
空数组处理意图没有 L1 卡片时不下发 cards；没有追问时不下发 clarify（保持与端上现状一致）
改名禁令任何已发布字段名不得修改；买家端已按此结构实现，改名 = 二期切换要动两端

1.7 关键规则

#规则实现位置
R-1目标页只能选，不能填：选择器从「已上线页面清单」选（按页面名/路径搜索，展示标题 + 路径 + 卡片说明），没有 URL 输入框 —— 从根上杜绝 404选择器弹窗
R-2页面下线联动：页面下线后，引用它的意图 / 追问选项 / 知识卡 / 兜底入口标红，提示「目标页已下线，请更换或停用」，未处理不允许发布；停用项不阻塞（不推给端上）列表行 / 编辑抽屉 / 发布拦截
R-3层级自动判定，不手填：配了追问 = L2；只配目标页 = L1；知识问答 = L3；三者互斥（有追问即清空 L1 卡片）；L4 只在兜底配编辑抽屉只读区块 + 保存校验
R-4草稿 → 发布：编辑即存草稿（可反复改）；点「发布」生成新版本号并推给端上；未发布的改动不影响线上；发布前展示变更摘要发布卡 + 顶部发布
R-5同分优先级：端上按关键词长度加权打分，同分看 priority（高者胜）；知识与意图同分时知识优先（端上规则，后台只提示）编辑抽屉字段说明 + 预览测试的判定过程
R-6删除保护：删除意图二次确认并提示"买家端将落到兜底"；知识问答可停用不必删删除 / 停用
R-7发布即生效：端上启动时拉配置（带版本号），版本未变则用本地缓存，避免每次开页都请求发布动作 + 页脚提示
R-8可回滚：保留最近 20 个版本，一键回滚并生成新版本（不回改历史）发布记录 / 回滚

1.8 关键交互与状态

场景行为
保存（任意编辑）只写草稿：标记「草稿改动 N 处」+ 变更摘要逐条累积（+ 新增意图「…」 / 改 意图「…」 / - 删除意图「…」 / 停用 / 复制 / 改兜底）
发布校验链：① 下线引用数 = 0 ② 有未发布改动 ③ 兜底入口 = 3 ④ 知识正文 ≤200 字 → 生成版本号 日期-序号 → 写入发布记录（含快照）→ 清空变更摘要 → 端上下次启动生效
发布被拦截顶部红条 + 发布处红字说明 + Toast 指出第一条阻塞项；「处理第一处」直接打开对应编辑抽屉
预览测试用当前草稿跑与端上同一套打分：词长加权求和、阈值 ≥2、同分看优先级、知识同分优先；输出「命中意图 / 命中关键词 / 层级 / 将输出卡片（含路径）」；不写库，最多 5 句
模拟下线（演示）选择器每行「模拟下线 / 恢复上线」→ 立即触发标红与发布拦截（对应验收 AC-5），用于给客户演示 R-2
回滚确认后以所选版本内容替换当前草稿数据并生成新版本（回滚到 2026-11-05-2），历史版本保留
演示持久化发布时另存 localStorage.ai_route_config + ai_route_version（仅演示；二期端上改为读服务端接口）

1.9 验收（后台侧）

#操作预期
AC-1新增一个意图（选 2 个目标页）并发布买家端助手输入对应话术能命中并给卡；未发布时不生效（草稿仅后台可见）

AC-5模拟某目标页下线该意图 / 追问选项 / 知识卡标红且无法发布，直到更换目标页或停用该项

AC-7发布后回滚到上一版本端上恢复上一版行为，且生成新版本号（历史版本不被改写）
