1. 推荐位管理 mall-recommend.html

1.1 页面说明

项内容
页面目标配置线下市场里被推荐的商铺（位次 / 推荐语 / 生效期），即买家端「实力商家」橱窗
使用角色商城运营专员（配置）、商城运营主管（上下架、强制替换）
入口菜单 → 商城运营 → 推荐位管理
前置商铺已在 04 建档且未清退
后置发布后买家端线下市场橱窗即时展示
与 09 内容管理的硬边界（Q6）：09 管内容位（资讯/公告/Banner），本页管商铺；两套位字典分表存放、互不引用，两处不得配置同一前端位。

1.2 本页端间关系

项内容
本页数据来源商铺来自 04 商户档案（只读引用）；位字典由平台预置
本页操作的跨端影响发布/下架 → 买家端 market-socks.html?view=offline 的「实力商家」橱窗即时增删
依赖的其他端页面mai-APP/market-socks.html（线下市场视图）
不涉及的端商户端、09 内容管理
一致性要求同位次同时段唯一；商铺清退自动下线

1.3 页面结构

区块内容
顶部标题 + 端上预览 + 新增推荐
统计卡（5）推荐位总数 / 在架推荐项 / 本周新增 / 位次冲突 / 待补位
Tab 2推荐项 / 位字典
筛选区（推荐项）商铺名·档口号 + 位次 + 状态
推荐项表8 列
位字典表6 列（位 ID / 区域 / 楼层 / 位次上限 / 当前占用 / 状态）
抽屉商铺 + 推荐位 + 位次 + 推荐语 + 生效期

1.4 列表、筛选与排序

项目规则

分页不分页
筛选组合条件之间 且

1.6 交互规则

元素显示条件可点条件点击后禁止表现
新增/编辑始终专员/主管抽屉位次冲突 → ML-24；推荐语超 20 字 → ML-29

1.7 业务规则与计算口径

编号规则触发处理影响端
R-23位次同时段唯一保存冲突拦截，主管可强制替换端上
R-24位次 ≤ 该位上限保存超限拦截—
R-25商铺必须有效保存清退/停用 → 拦截—
R-26商铺清退自动下线04 事件推荐项转已下线 + 通知配置人端上
R-27发布即生效上架无审核流端上
R-28推荐语 ≤20 字保存超长拦截端上单行
R-29与 09 位字典隔离任何时候下拉仅含本模块位；09 位不可选—
