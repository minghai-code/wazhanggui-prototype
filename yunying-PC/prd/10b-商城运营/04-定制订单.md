## 1. 定制订单 `mall-order-custom.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 查看定制大货订单：来源需求、是否经打样、**打样费抵扣了多少**、交期承诺 |
| 使用角色 | 商城运营专员、商城运营主管 |
| 入口 | 菜单 → 商城运营 → 订单管理 → 定制订单 |
| 前置 | 需求选标（直接大货）或打样单样衣确认（先样品后大货） |
| 后置 | 履约由外采承载 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 选标 / 样衣确认后生成 |
| 本页操作的跨端影响 | 金额区展示「打样费抵扣 -¥N」，买家端订单同步 |
| 依赖的其他端页面 | `mai-APP/custom-design.html`、`bulk-custom.html` |
| 不涉及的端 | 商户端（履约走普通订单） |
| 一致性要求 | 抵扣额度与 P3 打样单强一致（同一条额度不能两处使用） |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题 + **模拟创建定制单**（演示前置校验）+ 导出 |
| 状态 Tab | 全部 / 待付款 / 待生产 / 生产中 / 待发货 / 已完成 |
| **统计卡（5）** | 定制单总数 / 待生产 / 生产中 / 待发货 / **已抵扣打样费合计** |
| 筛选区 | 定制单号·需求号·打样单号 + 批量类型 + 抵扣情况 |
| 列表 | **11 列** |
| 详情抽屉 | 基础信息 / **定制块** / **金额明细（含抵扣行）** / **关联打样单** / 履约 / 日志 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 创建时间倒序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 批量类型 | 个性小批量 / 企业大批量 |
| 抵扣 | 有抵扣 / 无抵扣 |
| 空结果 | 「暂无匹配的定制订单」 |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 定制单号 | `no` | `CZ` + 日期 + 序号 |
| 来源需求 | `demand` | 可跳 |
| 来源打样单 | `sp` | **直接大货为 —**（无打样） |
| 批量类型 | `batch` | 个性小批量 / 企业大批量 |
| 数量 | `qty` | — |
| 单价 | `price` | — |
| **打样费抵扣** | `deduct` | >0 显示 `-¥N`，否则「无」 |
| 应付金额 | `amount` | 已扣减后的金额 |
| 交期承诺 | `promise` | — |
| 订单状态 | `state` | 外采主状态 + 生产态 |
| 操作 | — | 详情 |

**金额明细（详情内）**：商品金额 → **打样费抵扣（来源打样单 X）** → 应付金额

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 详情 | 始终 | 始终 | 抽屉（含金额明细） | — |
| 跳来源需求 | 有需求号 | 始终 | 提示跳转 | — |
| **查看打样单** | `sp` 有值 | 始终 | 跳 P3 并定位 | 直接大货 → 无按钮 |
| 模拟创建定制单 | 始终 | 专员 | 选打样单 → **校验样衣确认 + 额度未用** | 未确认 → ML-21；已用 → ML-22 |
| 导出 | 始终 | 专员/主管 | Excel | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-17 | 创建前置：SP 必须样衣确认 | 创建 | 未确认拦截 | — |
| R-18 | 打样费**订单立减** | 创建 | 金额 = 数量×单价 − 抵扣 | 两端 |
| R-19 | 抵扣须单列明细行 | 渲染 | 「打样费抵扣（来源打样单 X）」 | 买家端（F3） |
| R-20 | 额度一次性 | 抵扣 | 用后 P3 该单转"已用" | P3 |
| R-21 | 直接大货无抵扣 | 无 SP | 明细显示「无」 | — |
| R-22 | 抵扣不超订单金额 | 计算 | 上限 = 商品金额 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 直接大货 | 无打样单与抵扣 | 【已实现】本单为「直接大货」，无关联打样单与抵扣 |
| 数据 | SP 未确认 | 拦截创建 | 【已实现】打样单未确认样衣，不能创建定制单 |
| 数据 | 额度已用 | 拦截 | 【已实现】该打样单的抵扣额度已使用，不能重复抵扣 |
| 数据 | 有抵扣 | 金额明细行 | 【已实现】打样费抵扣（来源打样单 {订单号}） |

### 1.9 通知与消息

| 事件 | 接收人 | 渠道 | 抑制条件 |
|---|---|---|---|
| 定制单生成（含抵扣说明） | 买家 + 卖家 | 站内 + 推送 | 一次 |
| 待付款超 24h 取消 | 买家 | 站内 | 一次 |
| 交期临近（T-3） | 卖家 + 运营 | 站内 | 每单一次 |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-17 | SP 待制样 | 点模拟创建 | 拦截「打样单未确认样衣」 | P0 |
| AC-18 | SP 已确认且额度可用 | 点模拟创建 | 校验通过，可生成 CZ | P0 |
| AC-19 | 同一 SP 额度已用 | 再创建 | 拦截「额度已使用」 | P0 |
| AC-20 | 有抵扣的 CZ | 查看金额明细 | 出现「打样费抵扣（来源打样单 X） -¥N」单独一行 | P0 |
| AC-21 | 直接大货 CZ | 查看详情 | 无关联打样单，抵扣显示「无」 | P1 |
| AC-22 | 有 SP 的 CZ | 点「查看打样单」 | 跳到 P3 并定位该单 | P1 |
