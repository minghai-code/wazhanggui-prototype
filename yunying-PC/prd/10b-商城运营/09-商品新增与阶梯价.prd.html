项结论

1. 商品新增 mall-product-add.html

1.1 页面说明

项内容
页面目标商户 / 运营在同一套表单内维护商品，并配置拼单开关与阶梯价，保存后进入审核链路
使用角色商户（有电商模块权限者自助发布）、商城运营专员（监督、纠错、代发）
入口菜单 → 商城运营 → 商品管理 → 新增商品；或商品列表行内「编辑 / 详情」带 ?id= 进入编辑态
前置商户已通过入驻审核、已开通线上店铺；商品品类在品类字典内
后置提交 → 机器初筛（敏感词 + 敏感图）→ 命中警示级转人工判定 → 通过后上架；审核期间买家端仍展示上一版
编辑态?id=商品编号 打开时标题变「编辑商品」，页头出现编辑态提示条；字段取值沿用演示数据（原型不落库，接口实现以后端为准）

1.2 本页端间关系

项内容
数据来源商品图文由本页提交；阶梯价与拼单开关同属商品销售信息
跨端影响审核通过后买家端商品详情按阶梯价按实际下单数量落档计价；是否支持拼单=支持 时买家端多出「发起拼单」入口，不支持则只有「立即下单」
依赖的其他端页面买家端商品详情 / 拼单发起（消费方）；商户端商品发布（同一套表单，商户视角）；运营端 mall-product-audit.html（审核）、mall-ops.html（列表与入口）
一致性要求阶梯档位字段、拼单开关取值在三端（后台 / 商户端 / 买家端）同一口径，买家端不得自建档位规则

1.3 页面结构

区块内容
顶部标题「新增商品 / 编辑商品」+ 模块标签 + 「返回商品管理」
五个 Tab基本信息 / 销售信息 / 物流及配送 / 商品详情 / 高级信息（照搬外采）
销售信息 ①「是否支持拼单」开关（支持 / 不支持）
销售信息 ②（统一规格）阶梯价设置表：起始数量（双）/ 结束数量（双）/ 阶梯单价（元/双）/ 操作；「+ 添加档位」；末档留空 = 以上
销售信息 ③（多规格）规格维度维护 + 规格明细表，末列为「阶梯价」，每个规格组合一行一个「阶梯价」按钮，打开该规格独立的档位编辑弹层
附加服务商品附加服务列表（照搬外采）
底部取消 / 保存并提交审核

1.4 字段与规则

字段规则
是否支持拼单必选，默认「支持」；关闭后买家端不出现拼单入口
起始数量（双）必填；同规格内按升序排列
结束数量（双）可空，空 = 以上（不封顶）
阶梯单价（元/双）必填；同一规格内随档位递增而单价不升
档位数量统一规格至少 1 档；多规格每个规格至少 1 档
提交校验统一规格未设置阶梯价 → 拦「统一规格未设置阶梯价，请至少添加一档」；多规格有任一规格未设置 → 拦「还有 N 个规格未设置阶梯价，请补全」
审核联动提交后不直接同步买家端，先机审再人审；拼单开关与阶梯价随商品一起过审

1.5 状态与留痕

环节表现
保存提交提示「已提交（支持/不支持拼单 · N 个规格阶梯价均已设置）：已进入机器初筛」
机审通过进 mall-product-audit.html 人审队列（店铺开关决定是否需人审）
人审通过商品上架，买家端可见新版本；列表页状态变「已通过」
编辑已上架商品重审期间老版本继续展示，通过后替换

1.6 验收要点

编号场景预期
AC-01统一规格不添加任何档位直接提交阻断并提示至少添加一档
AC-02多规格中某规格未设阶梯价直接提交阻断并提示未设置规格数量
AC-03末档结束数量留空显示为「以上」，保存无报错
AC-04关闭拼单开关提交提示为「不支持拼单」；买家端无发起拼单入口
AC-05带 ?id= 打开标题变「编辑商品 + 编号」，页头出现编辑态提示条
AC-06提交后查看审核中心待审队列出现该商品，机审结论与命中项可查

2. 商品列表 mall-ops.html

2.1 页面说明

项内容
页面目标商品总台账：看状态、进审核、纠错编辑、查驳回原因
入口菜单 → 商城运营 → 商品管理 → 商品列表
列表列商品编号 / 商品 / 商户 / 品类 / 提交时间 / 机审结论 / 审核状态 / 操作
操作列编辑（进 mall-product-add.html?id=，维护阶梯价与拼单开关）· 详情（同编辑页只读回显）· 审核 / 复核 / 查看机审（进审核页并带单号）· 驳回原因（人工判定结论留痕）· 查看（商户修改中）
状态枚举待机审 / 机审拦截 / 待人审 / 已通过 / 已驳回 / 需修改（与 mall-product-audit.html 取值一致）

2.2 审核结论回写

项规则
回写方向审核页人审「通过 / 驳回」、拦截单「复核放行 / 维持拦截」均回写同一份商品状态
列表表现列表加载时合并回写结果：通过 → 已通过（机审结论置为通过），驳回 / 维持拦截 → 已驳回，复核放行 → 待人审
目的让「审核通过后阶梯价与拼单开关才生效」有可见的状态流转，不再两页各一套 mock

2.3 验收要点

编号场景预期
AC-07商品列表点「编辑」进商品页且标题为编辑态，页头有编辑提示条
AC-08审核页通过某商品后回到列表该商品状态变「已通过」，机审结论列显示通过
AC-09审核页驳回后回到列表该商品状态变「已驳回」，行内可查驳回原因
AC-10列表内任一操作无 toast 假跳；跳转目标页均存在
