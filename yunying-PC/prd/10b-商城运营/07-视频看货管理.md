## 1. 视频看货管理 `mall-video.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 维护买家端「视频看货」Tab 的短视频：**一条视频 = 一个店铺 + 最多 1 个在售商品**，视频下方直接出商品卡可下单 |
| 使用角色 | 平台运营（全量、审核、代发、精选、强制下架）；商户账号（只见/只改本店） |
| 入口 | 菜单 → 10 商城运营 → 商品管理 → 视频看货管理 |
| 前置 | ① 店铺已建档（店铺列表）② 商品已上架（商品列表）③ 视频文件已上传并转码完成 |
| 后置 | 审核通过 → 买家端 F01 §3 视频看货宫格 + 沉浸式播放流；驳回 → 商户端 App / 商户后台可见原因 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 视频本体由商户端 App（`shanghu-APP` #49）或本页（平台代发）创建；商品/店铺/在售状态来自商城侧 |
| 本页操作的跨端影响 | 通过/驳回/强制下架/精选 → 买家端视频可见性与排序；驳回原因 → 商户端展示 |
| 依赖的其他端页面 | 买家端 `mai-APP/video.html`（F01 §3）；商户端 App 视频看货管理 **`shanghu-APP/shop-video.html`（列表）+ `shop-video-edit.html`（发布/编辑）**，2026-11-04 已建（分册 S09） |
| 不涉及的端 | 商户端后台（同一页面，按账号过滤）；无 09 内容管理入口（视频不走内容管理） |
| 一致性要求 | 视频关联商品必须在售且属同店铺；商品下架 → 买家端商品卡置灰（F01 R-10） |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题 +「新增视频（平台代发）」 |
| **统计卡（4）** | 已上架 / 待审核 / 待处理（关联商品失效）/ 精选视频 |
| **Tab 条（6）** | 全部 / 待审核 / **待处理** / 已上架 / 已驳回 / 已下架（各带计数，待处理有未处理时标红） |
| 筛选区 | 关键词（标题 / 商品名 / 店铺名）+ 归属店铺 + 来源 + 精选 + 查询 / 重置 |
| 列表 | **9 列**：视频 / 归属店铺 / 关联商品（1 个）/ 品类（随商品）/ 精选 / 播放·收藏·点赞·分享 / 状态 / 发布时间 / 操作 |
| 编辑抽屉 | 视频文件（上传 + 换封面）/ 标题 / 描述 / 归属店铺 / 关联商品 / 品类（只读）/ 操作记录 |
| 审核抽屉 | 视频信息 + 关联商品在售状态 + 审核要点 + 审核意见（驳回必填） |
| 预览抽屉 | 复刻买家端竖屏播放流（右栏互动 + 左下商家/描述 + 商品卡或兜底卡） |
| 商品选择弹层 | 只列**所选店铺在售**商品，单选 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | mock 按创建顺序；正式实现按发布时间倒序 |
| 分页 | 原型单页展示全部；正式实现分页 |
| 筛选组合 | 条件之间 **且**；Tab 与筛选项叠加 |
| 「待处理」Tab | = 状态「已上架」**且** 关联商品不在售（标记，不是独立状态） |
| 空结果 | 「暂无数据」 |
| 行操作分派 | 待审核→审核；已上架→预览/编辑/精选/换品/强制下架；已驳回→编辑重提；已下架→预览/重新上架/编辑；草稿→预览/编辑/提交审核/删除 |

### 1.5 字段规格

| 字段 | 录入 | 列表 | 详情/抽屉 | 下游/落点 |
|---|---|---|---|---|
| 视频文件 | 上传（mp4/mov ≤200MB ≤3 分钟） | 封面缩略图 | 上传预览 | 转码服务；转码完成才可提交审核 |
| 封面 | 默认首帧，可自传替换 | 缩略图 | 预览 | 买家端宫格与播放流封面 |
| 标题 | ≤30 字 | ✓ | ✓ | 买家端；关键词搜索 |
| 描述 | ≤100 字 | — | ✓ | 买家端播放流（2 行） |
| 时长 | 自动读取 | 封面角标 | ✓ | 买家端 |
| **归属店铺** | 必选（已关闭店铺不可选） | ✓ + 来源 | ✓ | 店铺关闭 → 视频自动下架 |
| **关联商品** | ≤1，只列该店铺在售 | ✓（含在售状态） | ✓ | 买家端商品卡；下单跳 `product-detail.html?from=video` |
| **品类** | **只读派生**（= 商品品类） | ✓ | ✓ | 买家端品类 chips 筛选 |
| 精选 | 运营开关（仅已上架） | ✓ | — | 买家端综合分 +5000、排序前移 |
| 来源 | 商户上传 / 平台代发 | ✓ | ✓ | 商户上传必挂商品；平台代发可不挂 |
| 状态 | 系统流转 | ✓ | ✓ | 买家端可见性 |
| 播放/点赞/收藏/分享 | 端上回传，只读 | ✓ | ✓（预览） | 综合分计算 |
| 提交人/时间 | 系统记录 | 状态列（已上架显示审核留痕） | 操作记录 | 追溯 |
| 审核人/时间 | 审核动作写入 | 状态列小字 | 操作记录 | 追溯 |
| 下架人/时间/原因 | 下架动作写入 | 状态列（已下架显示原因） | 操作记录 | 追溯 / 商户端可见原因 |

### 1.6 交互规则

| 元素 | 可点条件 | 点击后 |
|---|---|---|
| 新增视频 | 始终 | 打开编辑抽屉（来源固定「平台代发」） |
| Tab / 筛选 / 重置 | 始终 | 过滤列表并回到全量渲染 |
| 预览 | 始终 | 打开竖屏播放流（按当前筛选顺序） |
| 审核（待审核） | 状态=待审核 | 审核抽屉：通过（→已上架）/ 驳回（原因必填 →已驳回） |
| 设为/取消精选 | 状态=已上架 | 切换精选（待审核不可设，提示拦截） |
| 强制下架 | 状态=已上架 | →已下架，写原因与操作人 |
| 换品 | 已上架且商品失效 | 打开编辑抽屉的换品模式，选新商品后回待审核 |
| 重新上架 | 状态=已下架 | 校验店铺未关闭 + 商品在售，通过则 →已上架 |
| 删除 | 仅草稿 | 二次确认后物理删除（不可恢复） |
| 关联商品选择 | 归属店铺已选定 | 弹层只列该店铺在售商品，单选 |
| 清空关联商品 | 始终 | 置为「纯内容」（平台代发可保存；商户上传提交时拦截） |
| 更换封面 | 始终 | 选图（建议 9:16），不选则取首帧 |

### 1.7 业务规则与口径

| 编号 | 规则 |
|---|---|
| V-1 | **视频品类 = 关联商品的品类**，只读派生，不建视频品类字典；无商品时品类为「—」 |
| V-2 | **一条视频最多 1 个商品**；商户上传必挂本店在售商品，平台代发可不挂（买家端走兜底卡） |
| V-3 | **上传入口两端并存**（本页 + 商户端 App #49），同一份数据；审核与精选只在运营端 |
| VD-R1 | 已上架视频被修改（含换品）→ 自动转「待审核」并从买家端撤下 |
| VD-R2 | 店铺关闭 → 其名下已上架视频系统自动下架（留原因、不删除）；店铺重开后需逐条复审上架；已关闭店铺不可新增/编辑其视频 |
| VD-R3 | 提交人/时间、审核人/时间、下架人/时间/原因均留痕，列表状态列与「操作记录」可查 |
| VD-R4 | **话题标签已下线**（2026-11-04）：无搜索/筛选/排序/统计落点、系统无标签库 → 本页与买家端均不提供该字段（实现时**不要**再加标签输入与展示） |
| VD-R5 | 上传后系统转码，转码完成方可提交审核（技术状态，不进业务状态机） |
| VD-R6 | 草稿删除不可恢复（二次确认）；已上架只能下架不能删除 |
| VD-R7 | 商品价格/起批量以商品库实时值为准；商品删除 → 商品卡「商品已删除」，需换品 |
| VD-R8 | 精选仅「已上架」可勾；强制下架、转待审核时自动取消精选 |

**状态机**

```
草稿 ──提交──→ 待审核 ──通过──→ 已上架 ⇄ 强制/自下架 ──→ 已下架
                   └──驳回（原因必填）──→ 已驳回 ──改后重提──→ 待审核
```

### 1.8 异常与边界

| 场景 | 处理 | 提示文案 |
|---|---|---|
| 归属店铺已关闭 | 新建/编辑拦截；已上架视频加载时自动下架 | 该店铺已关闭，不能新增或编辑其视频 |
| 关联商品已下架 | 进「待处理」；买家端商品卡置灰 | 关联商品不在售，请重新选择 |
| 商品已删除 | 关联商品列显示「商品已删除」 | 商品已删除 |
| 已关闭店铺的视频重新上架 | 拦截 | 店铺已关闭，不能重新上架 |
| 关联商品失效时通过审核 | 拦截 | 关联商品已下架，请先让商户换品或驳回 |
| 商户上传不挂商品 | 提交拦截 | 商户上传的视频必须关联 1 个本店在售商品 |
| 驳回未填原因 | 拦截 | 驳回需填写审核意见 |
| 非草稿删除 | 拦截 | 仅草稿可删除；已上架请用「强制下架」 |
| 待审核视频设精选 | 拦截 | 仅「已上架」视频可设精选 |
| 切换归属店铺 | 原关联商品清空 | 归属店铺已变更，原关联商品已清空，请重新选择 |
| 无数据 | 空态 | 暂无数据 |
| 无关联商品（预览） | 兜底卡 | 该视频未关联商品 |

### 1.10 验收标准

| # | 前置 | 操作 | 预期 | 优先级 |
|---|---|---|---|---|
| AC-V1 | 已登录运营 | 新增视频并选本店在售商品 | 保存成功；品类自动带出；列表可搜到 | P0 |
| AC-V2 | 商户上传视频无商品 | 提交审核 | 拦截并提示必须关联商品 | P0 |
| AC-V3 | 待审核视频 | 审核通过 | 状态已上架；买家端可见；留审核人/时间 | P0 |
| AC-V4 | 待审核视频 | 驳回不填原因 | 拦截；填原因后状态已驳回且原因回传商户端 | P0 |
| AC-V5 | 已上架视频商品被下架 | 打开列表 | 进「待处理」；买家端商品卡置灰；可换品或强制下架 | P0 |
| AC-V6 | 已上架视频 | 修改标题后保存 | 转「待审核」、取消精选、买家端暂时不可见 | P0 |
| AC-V7 | 店铺已关闭 | 打开其视频 / 尝试上架 | 已上架视频已自动下架且显示原因；不允许重新上架 | P1 |
| AC-V8 | 换品 | 选择新在售商品 | 品类随之变化；回到待审核 | P1 |
| AC-V9 | 已下架视频 | 重新上架 | 校验店铺与商品状态后成功 | P1 |
| AC-V10 | 草稿 | 删除 | 二次确认后删除；不可恢复 | P2 |

## 2. 落点核对（每个入口都有前置与后置）

| 入口/字段 | 前置从哪来 | 后置到哪去 |
|---|---|---|
| 视频文件 | 本地文件；需转码 | 转码完成 → 可提交审核 → 买家端播放 |
| 封面 | 首帧 / 自传图 | 买家端宫格 + 播放流 |
| 归属店铺 | 店铺列表（已关闭不可选） | 视频归属；店铺关闭 → 自动下架 |
| 关联商品 | 商品列表（同店铺、在售） | 买家端商品卡 → 商品详情下单 |
| 品类 | 商品分类（派生） | 买家端品类 chips 筛选 |
| 精选 | 运营勾选 | 买家端综合分排序 |
| 驳回原因 | 审核填写 | 商户端 App / 商户后台展示 |
| 下架原因 | 强制下架/系统 | 列表状态列、操作记录、商户端 |
| 播放/点赞/收藏/分享 | 买家端回传 | 本页只读展示 + 综合分计算 |
| 删除草稿 | 二次确认 | 物理删除（无归档，已声明不做回收站） |
