## 1. 商户设置 `mall-merchant-setting.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 配置商城商户入驻的全局规则与入驻协议，**保存后即时生效** |
| 使用角色 | 商城运营主管（全局规则影响所有新入驻商户） |
| 入口 | 菜单 → 商城运营 → 商户管理 → 商户设置 |
| 前置 | 无 |
| 后置 | 规则对后续新入驻生效；协议为端上入驻页勾选内容 |

### 1.2 页面结构

| 区块 | 内容 |
|---|---|
| 基本设置 | 是否允许个人入驻（是 / 否）、商户入驻是否需要审核（是 / 否，附提示）、单个商户最大店铺数量（数字输入，默认 100） |
| 入驻协议内容 | 富文本工具栏（正文 / 引用 / 加粗 / 斜体 / 下划线 / 对齐 / 有序·无序列表 / 插入图片 / 插入链接 / 撤销 / 重做）+ 可编辑正文 +「提交」+「上次保存：时间 · 操作人」 |

### 1.3 字段规格

| 字段 | 取值 | 默认 | 影响 |
|---|---|---|---|
| 是否允许个人入驻 | 是 / 否 | 是 | 关闭后个人主体不能提交入驻（影响端上入驻入口与校验） |
| 商户入驻是否需要审核 | 是 / 否 | 是 | 关闭后新商户提交即自动通过（页面已标「谨慎操作」） |
| 单个商户最大店铺数量 | 正整数 | 100 | 超过上限不允许再开新店 |
| 入驻协议内容 | 富文本 | 外采默认模板 | 端上入驻页展示并要求勾选同意 |

### 1.4 操作与规则

| 操作 | 规则 |
|---|---|
| 单选切换 | 三组开关点选即切换选中态，保存前不落库（原型态） |
| 提交 | 校验最大店铺数为正整数；通过后刷新「上次保存」时间与操作人并提示保存成功 |
| 富文本 | 工具栏各按钮有响应；保存时整段正文随规则一并提交 |
| 协议生效 | 保存后新入驻流程展示新协议；已入驻商户不追溯 |

### 1.5 提示文案

| 场景 | 提示文案 | 形式 |
|---|---|---|
| 店铺数非法 | 单个商户最大店铺数量需大于 0 | Toast |
| 保存成功 | 商户设置已保存并生效 | Toast |

### 1.6 验收标准

| 编号 | 前置 | 操作 | 预期 |
|---|---|---|---|
| AC-S1 | 打开商户设置 | 最大店铺数填 0 后提交 | 拦截并提示，不刷新保存时间 |
| AC-S2 | 同上 | 填 50 后提交 | 保存成功，保存时间与操作人更新 |
| AC-S3 | 关闭「是否需要审核」 | 保存 | 提示保存成功；端上入驻不再走审核（接口期验证） |
| AC-S4 | 编辑协议正文 | 提交后刷新页面 | 正文与提交内容一致 |
