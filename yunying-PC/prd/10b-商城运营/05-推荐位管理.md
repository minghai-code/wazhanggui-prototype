## 1. 推荐位管理 `mall-recommend.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 配置**线下市场**里被推荐的商铺（位次 / 推荐语 / 生效期），即买家端「实力商家」橱窗 |
| 使用角色 | 商城运营专员（配置）、商城运营主管（上下架、强制替换） |
| 入口 | 菜单 → 商城运营 → 推荐位管理 |
| 前置 | 商铺已在 04 建档且未清退 |
| 后置 | 发布后买家端线下市场橱窗即时展示 |

> **与 09 内容管理的硬边界**（Q6）：09 管内容位（资讯/公告/Banner），本页管**商铺**；**两套位字典分表存放、互不引用**，两处不得配置同一前端位。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 商铺来自 04 商户档案（只读引用）；位字典由平台预置 |
| 本页操作的跨端影响 | 发布/下架 → 买家端 `market-socks.html?view=offline` 的「实力商家」橱窗即时增删 |
| 依赖的其他端页面 | `mai-APP/market-socks.html`（线下市场视图） |
| 不涉及的端 | 商户端、09 内容管理 |
| 一致性要求 | 同位次同时段唯一；商铺清退自动下线 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题 + 端上预览 + 新增推荐 |
| **统计卡（5）** | 推荐位总数 / 在架推荐项 / 本周新增 / 位次冲突 / 待补位 |
| **Tab 2** | 推荐项 / 位字典 |
| 筛选区（推荐项） | 商铺名·档口号 + 位次 + 状态 |
| 推荐项表 | **8 列** |
| 位字典表 | **6 列**（位 ID / 区域 / 楼层 / 位次上限 / 当前占用 / 状态） |
| 抽屉 | 商铺 + 推荐位 + 位次 + 推荐语 + 生效期 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 楼层升序 + 位次升序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 状态 | 草稿 / 已发布 / 已下线 / 已过期 |
| 空结果 | 「暂无推荐项」 |

### 1.5 字段规格

**推荐项（8 列）**

| 列 | 字段 | 说明 |
|---|---|---|
| 位次 | `slot` + `pos` | 副行显示位 ID 与上限/占用 |
| 商铺 | `shop` | 来自 04；冲突时打「位次冲突」红标 |
| 区域/楼层 | 由 `slot` 带出 | — |
| 推荐语 | `words` | ≤20 字（端上单行） |
| 生效期 | `start`~`end` | — |
| 排序 | `pos` | 同一位内序号 |
| 状态 | `state` | 草稿 / 已发布 / 已下线 / 已过期 |
| 操作 | — | 编辑 / 上架下架 / 删除（仅草稿） |

**位字典（6 列）**：位 ID · 区域 · 楼层 · 位次上限 · 当前占用 · 状态

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新增/编辑 | 始终 | 专员/主管 | 抽屉 | 位次冲突 → ML-24；推荐语超 20 字 → ML-29 |
| **主管强制替换** | 位次冲突弹窗 | **主管** | 原推荐项下线 + 替换 + 留痕 | 非主管 → 无此按钮 |
| 上架 / 下架 | 始终 | **主管** | 端上橱窗即时增删 | 有冲突 → 先调整 |
| 删除 | **仅草稿** | 专员 | 物理删除 | 非草稿 → 提示用下架 |
| 端上预览 | 始终 | 始终 | 弹窗展示「实力商家」卡组 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-23 | 位次同时段唯一 | 保存 | 冲突拦截，主管可强制替换 | 端上 |
| R-24 | 位次 ≤ 该位上限 | 保存 | 超限拦截 | — |
| R-25 | 商铺必须有效 | 保存 | 清退/停用 → 拦截 | — |
| R-26 | 商铺清退自动下线 | 04 事件 | 推荐项转已下线 + 通知配置人 | 端上 |
| R-27 | 发布即生效 | 上架 | 无审核流 | 端上 |
| R-28 | 推荐语 ≤20 字 | 保存 | 超长拦截 | 端上单行 |
| R-29 | 与 09 位字典隔离 | 任何时候 | 下拉仅含本模块位；09 位不可选 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 位次被占 | 拦截 + 弹窗（可强制替换） | 【已实现】位次 {n} 已被「{商铺}」占用（{生效期}），请调整位次或等其下线 |
| 权限 | 主管强制替换 | 原项下线 + 留痕 | 【已实现】已强制替换位次 {n}（原「{商铺}」已下线，留痕已记录） |
| 数据 | 商铺已清退 | 拦截 | 【已实现】该商铺已清退/停用，无法推荐 |
| 数据 | 推荐语超长 | 拦截 | 【已实现】推荐语不超过 20 字（端上单行展示） |
| 数据 | 引用 09 位 | 下拉不含 | 【已实现】09 内容管理的位（如「买家端首页轮播」）属平台级内容位，不得在此引用 |
| 数据 | 无推荐项 | 端上整块隐藏 | 【已实现】当前无已发布推荐项，端上「实力商家」橱窗将整块隐藏 |
