## 1. 拼单集采订单 `mall-order-group.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 查看拼单集采产生的订单，回溯"谁发起的、谁参团、按哪档结算" |
| 使用角色 | 商城运营专员（查看/异常标记）、商城运营主管（取消） |
| 入口 | 菜单 → 商城运营 → 订单管理 → 拼单集采订单 |
| 前置 | 拼单成团后由系统生成（每参团人一笔） |
| 后置 | 履约（支付/物流/售后）由外采 igshop 承载 |

> **拼单只由买家发起**（F1），本页**没有"新建拼单"入口**。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 买家端发起拼单 → 成团后系统生成本类订单 |
| 本页操作的跨端影响 | 取消订单 → 触发退款（外采规则）→ 买家端订单状态变更 |
| 依赖的其他端页面 | `mai-APP/group-buy.html`、`group-buy-join.html`、`group-records.html` |
| 不涉及的端 | 商户端（卖家侧走普通订单履约） |
| 一致性要求 | 成团后订单数 = 参团人数；单价 = 所在档单价 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题 + 导出 |
| 状态 Tab | 全部 / 待付款 / 待发货 / 已发货 / 已完成 / 已取消（对齐外采主状态） |
| **统计卡（5）** | 订单总数 / 进行中（待付款）/ 已成团待发货 / 已失效（退款中）/ 本月成交额 |
| 筛选区 | 订单号·拼单号·商品 + 拼单发起人 |
| 列表 | **11 列** |
| 详情抽屉 | 基础信息 / **拼单溯源 + 参团人明细** / 履约信息 / 操作日志 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 成团时间倒序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 状态 Tab | 与列表状态互斥联动 |
| 空结果 | 「暂无匹配的拼单订单」 |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 订单号 | `no` | `GB` + 日期 + 序号 |
| 拼单号 | `gid` | 可跳拼单活动（端上发起，后台只读） |
| 发起人 | `starter` | 脱敏 |
| 参团人 | `members` | 人数，详情看明细 |
| 商品 | `goods` | 副行显示档位达成情况 |
| 数量 | `qty` | — |
| 单价（档位） | `price` | 按所在档结算 |
| 金额 | `amount` | — |
| 成团时间 | `doneAt` | 未成团为 — |
| 订单状态 | `state` | 外采主状态 |
| 操作 | — | 详情 |

**参团人明细（详情内）**：参团人 · 数量 · 实付 · 占比

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 详情 | 始终 | 始终 | 抽屉 | — |
| 跳拼单活动 | 有拼单号 | 始终 | 提示跳转（端上发起，后台只读） | — |
| 异常标记 | 始终 | 专员/主管 | 填备注 → 入异常清单 | 缺备注 → 拦截 |
| **取消订单** | 非终态 | **主管** | 原因必填 → 已取消 → 退款 | 缺原因 → ML-11 |
| 导出 | 始终 | 专员/主管 | Excel | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-07 | 成团为每个参团人生成一笔 | 成团 | 订单数 = 参团人数 | 买家端 |
| R-08 | 单价 = 所在档单价 | 成团 | 跨档按该档结算 | — |
| R-09 | 未成团不进本页 | 失效 | 活动失效 + 全额退款，不产生订单 | 买家端 |
| R-10 | 主状态跟随外采 | 履约 | 本页只读 | — |
| R-11 | 取消需主管 + 原因 | 取消 | 触发退款 | 两端 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 未成团 | 无订单（活动失效） | 【已实现】未达起拼档 → 活动已失效并全额退款 |
| 数据 | 部分参团人未付款 | 订单各自独立 | — |
| 操作 | 取消未填原因 | 拦截 | 【已实现】取消原因必填（将触发退款流程） |
| 数据 | 无匹配订单 | 空态 | 「暂无匹配的拼单订单」 |

### 1.9 通知与消息

| 事件 | 接收人 | 渠道 | 抑制条件 |
|---|---|---|---|
| 成团 | 全部参团人 | 站内 + 推送 | 一次 |
| 未成团（全额退款） | 全部参团人 | 站内 + 短信 | 一次 |
| 订单被取消 | 参团人 + 卖家 | 站内 | 一次 |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-07 | 成团 5 人 | 查看订单数 | **生成 5 笔订单**，参团人明细 5 行 | P0 |
| AC-08 | 同上 | 查看单价 | 等于所在档单价，不是原价 | P0 |
| AC-09 | 未成团活动 | 查看本页 | 无该订单（活动已失效并退款） | P0 |
| AC-10 | 进行中订单 | 专员点取消 | 无按钮（仅主管） | P1 |
| AC-11 | 主管取消并填原因 | 提交 | 状态已取消，退款流程触发 | P1 |
