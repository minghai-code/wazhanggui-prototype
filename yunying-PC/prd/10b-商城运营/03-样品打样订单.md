## 1. 样品打样订单 `mall-order-sample.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 跟进打样全过程：轮次、样衣状态、**打样费抵扣额度是否已用** |
| 使用角色 | 商城运营专员、商城运营主管 |
| 入口 | 菜单 → 商城运营 → 订单管理 → 样品打样订单 |
| 前置 | 定制需求中"仅样品定制"或"先样品后大货"选标后生成 |
| 后置 | 样衣确认后可生成定制单（先样品后大货）；仅样品则结案 |

> **本页是"打样费抵扣"的账本**：额度是否可用、被哪张定制单用掉，都在这里看。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 需求选标后生成；买家在端上支付打样费 |
| 本页操作的跨端影响 | 样衣确认 → 端上解锁"下单大货"（生成 CZ） |
| 依赖的其他端页面 | `mai-APP/custom-design.html`（申请打样 ¥200） |
| 不涉及的端 | 商户端（卖家履约走普通订单） |
| 一致性要求 | 打样费抵扣只在同一需求链路内有效；额度用后不可重复 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题 + 导出 |
| 状态 Tab | 全部 / 待付款 / 待制样 / 已寄样 / 已完成 / 已取消 |
| **统计卡（5）** | 打样单总数 / 待制样 / 已寄样待确认 / 待付款 / 已抵扣 |
| 筛选区 | 打样单号·需求号·商品 + 抵扣状态（可用/已用） |
| 列表 | **10 列** |
| 详情抽屉 | 基础信息 / **打样块（含轮次时间线 + 抵扣额度）** / **关联定制单** / 履约 / 日志 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 创建时间倒序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 抵扣状态 | 可用 / 已用 |
| 空结果 | 「暂无匹配的打样单」 |
| 红标 | 改样轮次 >3 显示「超 3 轮」 |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 打样单号 | `no` | `SP` + 日期 + 序号 |
| 来源需求 | `demand` | 可跳需求 |
| 设计方案 | `design` | 副行显示商品名 |
| 打样轮次 | `round` | >3 红标 |
| 打样费 | `fee` | ¥200（个性）/ ¥500（企业） |
| 可抵扣 | `deduct` + `deductState` | 可用 / 已用 / 无 |
| 样衣状态 | `sampleState` | 待制样 / 已寄样 / 样衣确认 |
| 订单状态 | `state` | 外采主状态 |
| 关联定制单 | `cz` | 可跳 P4 |
| 操作 | — | 详情 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 详情 | 始终 | 始终 | 抽屉 | — |
| 跳来源需求 | 有需求号 | 始终 | 提示跳转 | — |
| **查看定制单** | 有 `cz` | 始终 | 跳 P4 并定位 | 额度已用但无单号 → 提示已被使用 |
| 导出 | 始终 | 专员/主管 | Excel | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-12 | 样衣确认才解锁定制单 | 确认 | 端上出现"下单大货" | 买家端 |
| R-13 | 改样超 3 轮提醒 | round>3 | 列表红标 + 详情提示，不强制 | — |
| R-14 | 抵扣额度一次性 | 用于 CZ | 状态转"已用"并记录被哪单使用 | P4 |
| R-15 | 仅样品定制确认后结案 | 确认 | 不生成 CZ | — |
| R-16 | 打样费 | 200（个性）/ 500（企业，可抵扣） | 端上展示 | 买家端 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 改样 4 轮 | 红标 + 提示运营介入 | 【已实现】该打样单已改样 {n} 轮，建议运营介入 |
| 数据 | 额度已用 | 详情显示被哪张 CZ 使用 | 【已实现】该打样单的抵扣额度已被定制单 {订单号} 使用 |
| 数据 | 待付款超 24h | 订单取消 | — |
| 数据 | 无匹配 | 空态 | 「暂无匹配的打样单」 |

### 1.9 通知与消息

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-12 | 打样单样衣=已寄样 | 查看详情 | 无「查看定制单」跳转（尚未确认） | P0 |
| AC-13 | 已确认且生成 CZ | 点「查看定制单」 | 跳到 P4 并定位该单 | P0 |
| AC-14 | 额度已被使用 | 查看抵扣列 | 显示「已用」+ 被哪张 CZ 使用 | P0 |
| AC-15 | 第 4 轮改样 | 查看列表 | 出现「超 3 轮」红标 | P1 |
| AC-16 | 仅样品定制确认 | 查看端上 | 结案，无"下单大货"入口 | P1 |
