1. 商户列表 mall-merchant-list.html

1.1 页面说明

项内容
页面目标查看已入驻商城的商户主体及其店铺绑定、认证状态，支持运营代建档与维护
使用角色商城运营专员（查询 / 代建档）、商城运营主管（删除）
入口菜单 → 商城运营 → 商户管理 → 商户列表
前置商户已通过 04 入驻审核（或运营代录）
后置不改变 04 主档；仅维护商城侧可见的商户记录与认证资料

1.2 页面结构

区块内容
顶部标题 + 模块标签「10 商城运营 · 商户管理」+ 右侧「添加商户」
筛选区商户名称（模糊）+ 商户类型（企业认证 / 个人认证）+ 认证状态（正常 / 已过期）+ 搜索 / 重置
表格8 列：商户所属单位（附「企业 / 个人」标签）/ 商户所属会员(ID) / 商户类型 / 管理员 / 已绑定店铺 / 认证状态 / 认证日期 / 操作（详情 · 编辑 · 删除）
空态「暂无数据」
分页底部「共 N 条记录」+ 上一页 / 页码 / 下一页
抽屉添加 / 编辑商户（标题随模式切换）

1.3 字段规格（抽屉）

字段必填形式说明
商户所属单位是文本企业名或个人名
商户所属会员(ID)是文本与 04 商户账号一致，如 dz_10101
商户类型是二选一卡片企业认证（营业执照）/ 个人认证（身份证实名）
管理员是文本管理员账号名
认证资料否图片上传营业执照 / 身份证等认证材料，选中后缩略位转勾选态并显示文件名

1.4 操作与规则

操作规则
搜索 / 重置三个条件交集过滤；重置清空条件并恢复全量
添加商户校验通过后插入列表首行，绑定店铺数默认 0，认证状态默认「正常」
编辑商户回填全部字段；商户类型可改（企业 / 个人标签跟随变化）
详情展示商户名 · 类型 · 已绑定店铺数（外采详情页为准）
删除已绑定店铺 > 0 的商户不可删除，需先解绑店铺；可删除时二次确认后移除
绑定店铺数只读，由外采店铺数据汇总，本页不提供维护入口

删除成功商户「{商户名}」已删除Toast

1.6 验收标准

编号前置操作预期
AC-M1任一商户点「详情」返回商户名 / 类型 / 绑定店铺数，无空响应
AC-M2有店铺的商户点「删除」拦截并提示绑定店铺数，记录不被删除
AC-M3无店铺的商户点「删除」二次确认后移除，列表与「共 N 条」同步
AC-M4打开添加抽屉三项必填留空提交逐项拦截，文案见 §1.5
AC-M5新建企业认证商户保存后看列表「企业」标签 + 认证状态「正常」+ 认证日期为保存日期
