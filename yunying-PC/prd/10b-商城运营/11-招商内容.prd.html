1. 招商内容 mall-merchant-recruit.html

1.1 页面说明

项内容
页面目标维护买家端「诚邀入驻」页的招商内容，分块编辑、保存后即时生效
使用角色商城运营专员
入口菜单 → 商城运营 → 商户管理 → 招商内容
前置无（内容型页面，不依赖单据）
后置保存后买家端招商页同步展示最新内容

1.2 页面结构

区块内容
左侧锚点招商首页 / 招商计划 / 招商标准 / 入驻流程（点击滚动定位，当前区块高亮）
招商首页「招商Banner」（主标题 + 副标题 + 背景图）+「合作模式」四卡（经销合作 / 企业模式 / 供给模式 / 直营入驻）+「平台模式流程」五步（提交入驻 → 平台审核 → 开店装修 → 上架商品 → 经营结算）
招商计划四类分档文案：袜品类、原料类、设备类、服务类，各含引进方向与计划引入家数（当前 120 / 40 / 20 / 15 家）
招商标准四条准入要求（合法经营资质 / 品牌店铺商标或授权书 / 商品质量与检测报告优先 / 认可平台规范与协议）
入驻流程六步流程文案 + 底部说明（是否需审核、是否允许个人入驻由「商户设置」控制）
编辑抽屉每个区块右上「编辑」打开对应抽屉：Banner 为主标题 / 副标题 / 背景图，其余为图文内容

1.3 操作与规则

操作规则
分块编辑每个 openEdit(key) 只改对应区块，互不影响；抽屉底部「取消 / 保存」
图片上传Banner 背景图走真实文件选择，选中后预览位转勾选态
保存关闭抽屉并提示同步结果；买家端「诚邀入驻」页为唯一消费方
锚点联动点击锚点滚动到对应区块并高亮，不产生数据变更
