## 1. 拼单集采需求管理 `mall-group-manage.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | **团维度**监管拼单活动：团状态、进度、取消全团、退款记录与重试 |
| 使用角色 | 商城运营专员、运营主管 |
| 入口 | 菜单 → 商城运营 → **拼单集采需求管理**（与「个性定制需求管理」同级，直属项，不在「订单管理」分组下） |
| 前置 | 商户商品已配置 `groupEnabled` 与阶梯价（配置主体是商户，运营监管；商户端 App 无配置入口，实际在运营端「新增商品」代配） |
| 后置 | 取消 → 全员退款 3 个工作日；成团 → 已有订单转「待发货」；失效/取消 → 订单统一转「已取消（已退款）」（跳「拼单集采订单」页看逐笔） |

> **与「拼单集采订单」页的分界**：那一页是**逐笔订单**（每个参团人一条），本页是**团**（一条团一行）。订单页可跳团详情，本页取消/退款影响整团。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 买家端拼单发起 / 参团（本页**无新建入口**——拼单只由买家发起，M01 BR-1） |
| 本页操作的跨端影响 | 取消全团 → 全部参团人收到通知 + 全额原路退款；买家端参团记录置「已取消」，商户端该团同步置「已取消」、订单置「已取消（已退款）」且不可发货 |
| 依赖的其他端页面 | 买家端拼单列表 / 详情 / 我的拼单；商户端「拼单团管理」（`shanghu-group.html`，**未建**，商户端待办 #72）；本端拼单集采订单页 |
| 商户端的角色 | **可见 + 申请取消**：商户能看到本店商品的进行中团（`cum`/`targetQty`/参团人），可提交取消申请（原因必填），由本页审核；**无**强制取消、无改档改价 |
| 一致性要求 | 成团判定以后台为准（**累计达目标档即成团**）；已成团不可取消；三端状态名逐字一致（10b v2.1 §2.0.13 ⑥） |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| **口径条** | 顶部蓝条常驻：「团长选定目标档，累计达该档成团，按目标档单价锁档结算；超档不升价；到期未达则失效退款」 |
| **统计卡（4）** | 进行中 / 已成团（锁目标档 · 逐笔 GB 订单）/ 已失效（已退款）/ 已取消（退款中或已退） |
| 筛选区 | 状态（四态）+ 团号 / 商品名称 / 团长 / 商户 + 目标档下拉 + 查询 + 重置 |
| 团列表 | **11 列**：团号 · 商品 · **商户** · 档位 · **目标档**（含单价）· 团长下单 · 累计/人数 · 进度（÷目标档）· 截止时间 · 状态 · 操作 |
| 抽屉 | 团信息（含起批量与参团下限）+ 成团结算说明 + 参团人明细 / 取消记录 + 退款记录（失败可重试）+ 操作日志 |

### 1.4 团状态机（10b v2.1 §2.0.13 ①）

```
进行中 ──(cum ≥ targetQty)────────→ 已成团 ──(按 targetPrice 锁档，GB 转待发货)──→ 终局
   ├──(到期 cum < targetQty)──────→ 已失效 ──→ 全额退款 3 个工作日
   └──(团长取消 / 商户申请 / 平台强制)─→ 已取消 ──→ 全员全额退款 3 个工作日
```

> **判定要点**：即便 `cum` 已过阶梯第一档，只要未达 `targetQty` 就**不算成团**，到期照样失效退款。

### 1.5 字段规格

| 列 / 字段 | 字段名 | 说明 |
|---|---|---|
| 团号 | `groupId` | `T` + 年月日 + 3 位流水 |
| 商品 / 档位 | `goods` / `tier` | 档位 = 该规格完整阶梯表（起始–结束数量 · 单价） |
| 商户 | `merchant` | 商品所属商户；商户端数据隔离依据 |
| **目标档** | `targetQty` | **团长发起时选定档位的起始数量 = 成团阈值**（旧字段 `minTier` 作废） |
| 目标档单价 | `targetPrice` | 全员预付价、锁档结算价；超档不升价 |
| 起批量 | `tierQty` | 该规格阶梯**最小档**起始数量，仅用于算参团下限 |
| 参团下限 | `groupMin` | `max(10, ceil(tierQty × 20%))`，对齐 10 的倍数 |
| 团长下单 | `leadQty` | 支付首笔即进入「进行中」（支付 ≠ 成团） |
| 累计 / 人数 | `cum` / `people` | 进度 = `cum ÷ targetQty`（达 100% 即成团）；`people` 仅展示，不参与判定 |
| 状态 | `state` | 四态：进行中 / 已成团 / 已失效 / 已取消 |
| 退款 | `refund` | 涉及人数 · 金额 · 状态（成功 / 失败挂起可重试） |
| 参团人订单 | `orders[]` | **与 `members[]` 一一对应**（支付即生单：每参团人一笔 GB 订单，成团前为「待成团」） |

### 1.6 主要操作

| 操作 | 可用条件 | 说明 |
|---|---|---|
| **取消全团** | 状态 = 进行中 | 原因必填（通知全部参团人）→ 全员全额退款 3 个工作日；已成团**拦截**（M-06） |
| **审核商户取消申请** | 状态 = 进行中 且存在商户申请 | 抽屉内提示块显示申请时间 / 原因 / 说明；**通过并取消** → 团置已取消（`cancelBy='商户申请取消'`）+ 全员退款；**驳回申请** → 团继续，日志留痕 |
| 退款重试 | 退款记录有失败项 | 重试后失败清零，状态转「已退」 |
| 详情 | 全部 | 团信息 + 结算/取消/退款记录 + **参团人明细（含对应 GB 订单号）** + 操作日志 |
| **查看订单** | 全部（进行中为「订单」） | 跳 `mall-order-group.html?tid={团号}`，订单页按团号预筛本团逐笔订单 |

### 1.7 业务规则

| 编号 | 规则 | 依据 |
|---|---|---|
| R-G1 | 取消全团仅限「进行中」；已成团不可取消 | 分册裁决一 / M-06 |
| R-G2 | 团长退出 ≠ 取消全团：退出份额保留、不解散（FR-24） | 分册裁决一 |
| R-G3 | 退款 SLA：3 个工作日原路退回 | M01 Q4 / FR-23 |
| R-G4 | 参团下限 = `max(10, ceil(tierQty × 20%))`，对齐 10 的倍数；`tierQty` 取阶梯**最小档**，**与团长所选目标档无关** | 10b v2.1 §2.0.13 ④ |
| R-G5 | **支付即生单**：参团人付款即生成 GB 订单（`sourceGroupId` 溯源，状态「待成团」）；成团统一转「待发货」，失效/取消统一转「已取消（已退款）」 | 10b v2.0 §2.0.2 |
| R-G6 | 本页无新建入口（拼单只由买家发起） | M01 BR-1 |
| R-G7 | **成团 = `cum ≥ targetQty`**；超档不升价，仍按 `targetPrice` 结算 | 10b v2.1 §2.0.13 ①② |
| R-G8 | **已取消**的 `cancelBy` 取值：团长取消 / 商户申请取消 / 平台强制取消；商户申请需本页审核通过才生效 | 10b v2.1 §2.0.13 ⑦ |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 交互 | 成团后点取消 | 拦截 | 该团已成团并锁定结算，不可取消；如需处理请走售后（M-06） |
| 交互 | 取消原因未填 | 拦截 | 取消原因必填（会通知全部参团人） |
| 交互 | 商户提交取消申请 | 进审核队列，团状态不变 | 商户申请取消本团：{商品}，原因 {原因}，待审核 |
| 数据 | 退款失败 | 挂起，可重试 | 失败原因：{原因}；重试后状态清零 |

### 1.9 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-G1 | 团进行中 | 取消全团（填原因） | 状态转已取消，产生退款记录，badge 更新 | P0 |
| AC-G2 | 团已成团 | 尝试取消 | 拦截 M-06 | P0 |
| AC-G3 | 退款有失败项 | 点重试 | 失败清零，状态转「已退」 | P0 |
| AC-G4 | 输入团号 / 商品 / 商户关键字 | 查询 | 精确过滤；重置恢复全量 | P1 |
| AC-G5 | 任一进行中团 | 点「订单」/团号 | 跳拼单集采订单页并按 `?tid=团号` 预筛本团逐笔订单（订单数 = 参团人数） | P1 |
| AC-G6 | 已成团 / 已失效团 | 看参团人明细 | 每行显示对应 GB 订单号，可点跳订单页 | P1 |

| AC-G9 | 商户端提交取消申请 | 本页查看 | 出现「商户申请取消」待审核条目；审核通过后团置已取消、`cancelBy='商户申请取消'` | P1 |
