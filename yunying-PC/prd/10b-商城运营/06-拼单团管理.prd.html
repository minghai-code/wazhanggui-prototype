1. 拼单集采需求管理 mall-group-manage.html

1.1 页面说明

项内容
页面目标团维度监管拼单活动：团状态、进度、取消全团、退款记录与重试
使用角色商城运营专员、运营主管
入口菜单 → 商城运营 → 拼单集采需求管理（与「个性定制需求管理」同级，直属项，不在「订单管理」分组下）
前置商户商品已配置 groupEnabled 与阶梯价（配置主体是商户，运营监管；商户端 App 无配置入口，实际在运营端「新增商品」代配）
后置取消 → 全员退款 3 个工作日；成团 → 已有订单转「待发货」；失效/取消 → 订单统一转「已取消（已退款）」（跳「拼单集采订单」页看逐笔）
与「拼单集采订单」页的分界：那一页是逐笔订单（每个参团人一条），本页是团（一条团一行）。订单页可跳团详情，本页取消/退款影响整团。

1.2 本页端间关系

项内容
本页数据来源买家端拼单发起 / 参团（本页无新建入口——拼单只由买家发起，M01 BR-1）
本页操作的跨端影响取消全团 → 全部参团人收到通知 + 全额原路退款；买家端参团记录置「已取消」，商户端该团同步置「已取消」、订单置「已取消（已退款）」且不可发货
依赖的其他端页面买家端拼单列表 / 详情 / 我的拼单；商户端「拼单团管理」（shanghu-group.html，未建，商户端待办 #72）；本端拼单集采订单页
商户端的角色可见 + 申请取消：商户能看到本店商品的进行中团（cum/targetQty/参团人），可提交取消申请（原因必填），由本页审核；无强制取消、无改档改价
一致性要求成团判定以后台为准（累计达目标档即成团）；已成团不可取消；三端状态名逐字一致（10b v2.1 §2.0.13 ⑥）

1.3 页面结构

区块内容
口径条顶部蓝条常驻：「团长选定目标档，累计达该档成团，按目标档单价锁档结算；超档不升价；到期未达则失效退款」
统计卡（4）进行中 / 已成团（锁目标档 · 逐笔 GB 订单）/ 已失效（已退款）/ 已取消（退款中或已退）
筛选区状态（四态）+ 团号 / 商品名称 / 团长 / 商户 + 目标档下拉 + 查询 + 重置
团列表11 列：团号 · 商品 · 商户 · 档位 · 目标档（含单价）· 团长下单 · 累计/人数 · 进度（÷目标档）· 截止时间 · 状态 · 操作
抽屉团信息（含起批量与参团下限）+ 成团结算说明 + 参团人明细 / 取消记录 + 退款记录（失败可重试）+ 操作日志

1.4 团状态机（10b v2.1 §2.0.13 ①）

进行中 ──(cum ≥ targetQty)────────→ 已成团 ──(按 targetPrice 锁档，GB 转待发货)──→ 终局
   ├──(到期 cum < targetQty)──────→ 已失效 ──→ 全额退款 3 个工作日
   └──(团长取消 / 商户申请 / 平台强制)─→ 已取消 ──→ 全员全额退款 3 个工作日
判定要点：即便 cum 已过阶梯第一档，只要未达 targetQty 就不算成团，到期照样失效退款。

1.5 字段规格

列 / 字段字段名说明
团号groupIdT + 年月日 + 3 位流水
商品 / 档位goods / tier档位 = 该规格完整阶梯表（起始–结束数量 · 单价）
商户merchant商品所属商户；商户端数据隔离依据
目标档targetQty团长发起时选定档位的起始数量 = 成团阈值（旧字段 minTier 作废）
目标档单价targetPrice全员预付价、锁档结算价；超档不升价
起批量tierQty该规格阶梯最小档起始数量，仅用于算参团下限
参团下限groupMinmax(10, ceil(tierQty × 20%))，对齐 10 的倍数
团长下单leadQty支付首笔即进入「进行中」（支付 ≠ 成团）
累计 / 人数cum / people进度 = cum ÷ targetQty（达 100% 即成团）；people 仅展示，不参与判定
状态state四态：进行中 / 已成团 / 已失效 / 已取消
退款refund涉及人数 · 金额 · 状态（成功 / 失败挂起可重试）
参团人订单orders[]与 members[] 一一对应（支付即生单：每参团人一笔 GB 订单，成团前为「待成团」）

1.6 主要操作

操作可用条件说明
取消全团状态 = 进行中原因必填（通知全部参团人）→ 全员全额退款 3 个工作日；已成团拦截（M-06）
审核商户取消申请状态 = 进行中 且存在商户申请抽屉内提示块显示申请时间 / 原因 / 说明；通过并取消 → 团置已取消（cancelBy='商户申请取消'）+ 全员退款；驳回申请 → 团继续，日志留痕
退款重试退款记录有失败项重试后失败清零，状态转「已退」
详情全部团信息 + 结算/取消/退款记录 + 参团人明细（含对应 GB 订单号） + 操作日志
查看订单全部（进行中为「订单」）跳 mall-order-group.html?tid={团号}，订单页按团号预筛本团逐笔订单
