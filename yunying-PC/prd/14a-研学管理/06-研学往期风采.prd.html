1.1 页面说明

项内容
页面目标配置买家端「研学往期风采」展示内容（图文素材的选取与排序），供招生宣传
使用角色文商旅运营专员、运营主管
入口菜单 → 文商旅管理 → 研学 → 研学往期风采
前置已有已完成的历史研学批次 / 照片
后置端上「往期风采」区块展示

1.2 本页端间关系

项内容
本页数据来源已完成批次（P2）+ 手工上传照片
本页操作的跨端影响更新展示状态 → 买家端「往期风采」即时同步
依赖的其他端页面买家端研学页「往期风采」区块
不涉及的端商户端
一致性要求端上预览与配置一致；只展示已授权照片

1.3 页面结构

区块内容
顶部标题「研学往期风采」+ 预览买家端 + 更新展示
统计卡无（展示配置页）
内容区风采卡片列表（照片 + 标题 + 场次 + 展示开关 + 排序）
右侧手机壳端上预览

1.4 内容规则

项目规则
素材来源已完成批次照片 / 手工上传
单条字段照片（必填）/ 标题 / 关联场次 / 展示状态 / 排序
排序拖拽或填序号，端上按序号展示
展示开关关闭即端上隐藏，不删除
照片授权仅使用已获家长/学校授权的照片（合规要求）

1.5 字段规格

字段必填说明
照片是建议 4:3，≤2MB
标题否缺省用场次名称
关联场次否取自 P4 已完成场次
展示状态是展示 / 隐藏
排序否数字，越小越靠前

1.6 交互规则

元素显示条件可点条件点击后禁止表现
预览买家端始终专员/主管打开端上预览页—
更新展示有改动专员/主管同步端上—

排序始终专员/主管调整顺序—
