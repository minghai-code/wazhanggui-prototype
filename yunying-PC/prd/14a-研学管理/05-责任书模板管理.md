## 1. 责任书模板管理 `study-letter.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 维护安全责任书模板（版本化 + 条款编辑 + 签署记录），供买家端签署使用 |
| 使用角色 | **仅文商旅运营主管**（专员无此菜单） |
| 入口 | 菜单 → 文商旅管理 → 研学 → 责任书模板管理 |
| 前置 | 无 |
| 后置 | 启用的模板版本用于新报名签署；旧版本归档保留 |

> **安全责任书是事故追责凭证**，因此：版本化、停用不删、归档不可编辑、签署记录永久保留。

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 主管编辑 |
| 本页操作的跨端影响 | 启用版本 → 端上签署页展示该版本条款；停用 → 新报名用新版本，已签的仍可查 |
| 依赖的其他端页面 | 买家端责任书签署页（手写签名） |
| 不涉及的端 | 商户端 |
| 一致性要求 | 签署记录绑定**签署时的版本号**，模板改版不影响已签记录 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「责任书模板管理」+ 新建模板 |
| **统计卡** | **无**（模板管理页，指标无意义） |
| 筛选区 | 关键词 / 适用类型 / 启用状态 |
| 列表 | **7 列** |
| 抽屉 | 模板块（版本 / 适用类型 / 条款列表）；签署记录块（批量催收 + 导出） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 启用中优先，其次版本号降序 |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 适用类型 | 个人报名 / 团体研学 / 通用 |
| 空结果 | 「暂无模板」 |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 模板名称 | `name` | — |
| 适用类型 | `applyType` | 个人 / 团体 / 通用 |
| 版本 | `version` | 如 v2.1，**只增不改** |
| 条款数 | `clauseCount` | — |
| 启用状态 | `state` | 启用 / 停用 / 归档 |
| 更新时间 | `updatedAt` | — |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 编辑条款 | 启用 / 停用 | **主管** | 增删条款 | **归档后不可编辑 → S-20** |
| 复制为新版本 | 始终 | 主管 | 生成 v+0.1 草稿 | 已归档 → 隐藏 |
| 停用 | 启用中 | 主管 | 新报名不再使用该版本 | — |
| 归档 | 停用 | 主管 | 只读保留 | — |
| 批量催收 | 签署记录块 | 主管/专员 | 批量短信催收未签 | — |
| 导出签署记录 | 有记录 | 主管 | 含签名图与时间的 Excel | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-23 | 版本只增不改 | 编辑条款 | 改动须走"复制新版本" | 端上 |
| R-24 | 同一适用类型只有一个启用版本 | 启用 | 启用新的自动停用旧的 | 端上 |
| R-25 | 归档不可编辑 | 归档 | 只读，保留历史 | — |
| R-26 | 签署记录绑版本 | 签署 | 记录 `version` + 签名图 + 时间 + IP | 审计 |
| R-27 | 停用不影响已签 | 停用 | 已签记录照常可查 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 归档后再编辑 | 拦截 | 【已实现】已归档，不可编辑 |
| 数据 | 停用模板 | 提示影响范围 | 【已实现】模板已停用，新报名不再使用 |
| 数据 | 无模板 | **无空态提示**（待补） | — |
| 权限 | 专员访问本页 | 菜单不可见 | — |
