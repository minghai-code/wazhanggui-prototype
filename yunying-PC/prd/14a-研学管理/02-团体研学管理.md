## 1. 团体研学管理 `study-group.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 团体申请审核通过后生成的**批次**跟进：责任书签署进度、签到进度 |
| 使用角色 | 文商旅运营专员、运营主管 |
| 入口 | 菜单 → 文商旅管理 → 研学 → 团体研学管理 |
| 前置 | P1 团体申请已审核通过（生成批次） |
| 后置 | 责任书全部签署后可导出；签到进度实时可见 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | P1 审核通过自动生成批次；家长/学校在端上签署 |
| 本页操作的跨端影响 | 一键催收 → 未签家长收到短信；隐藏 → 端上不可见 |
| 依赖的其他端页面 | 买家端「我的研学」进度、责任书签署页 |
| 不涉及的端 | 商户端 |
| 一致性要求 | 责任书签署数 = 已签署人数；签到进度来自现场扫码 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「团体研学管理」+ 一键催收未签 + 导出批次 |
| **统计卡（4）** | 进行中批次 / 待签署责任书 / 本月已签到 / 本月接待人次 |
| 筛选区 | 关键词 / 学校 / 路线 / 日期 / 状态 + 查询 + 重置 |
| **Tab 条（3）** | 批次列表 / 责任书签署 / 签到记录 |
| 列表 | **10 列** + 分页 |
| 抽屉 | 批次详情（名单 / 责任书签署记录 / 签到记录 / 评价） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 研学日期升序（近期在前） |
| 分页 | 页码 |
| 筛选组合 | 条件之间 **且** |
| 状态 | 待签署 / 待出行 / 进行中 / 已完成 / 已取消 |
| 空结果 | 「暂无团体批次」 |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 批次编号 | `id` | 由 P1 申请单生成 |
| 学校名称 | `school` | — |
| 研学路线 | `route` | 跳 P4 路线详情 |
| 研学日期 | `date` | — |
| 参加人数 | `headcount` | — |
| 负责人/电话 | `leader` / `phone` | 脱敏 |
| **责任书签署** | `signProgress` | 已签/总数，进度条 |
| **签到进度** | `checkinProgress` | 已签到/总数 |
| 状态 | `state` | 五态 |
| 操作 | — | 详情 / 催收 / 精选 / 隐藏 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 一键催收未签 | 有未签成员 | 专员/主管 | 批量短信催收 | 全部已签 → 按钮置灰 |
| 导出批次 | 始终 | 专员/主管 | 含名单 + 签署记录的 Excel | — |
| 详情 | 始终 | 始终 | 抽屉（名单 / 签署 / 签到 / 评价） | — |
| 精选 / 隐藏 | 已完成批次 | 专员/主管 | 端上展示控制 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-08 | 批次由 P1 通过自动生成 | 审核通过 | 一条申请一个批次 | — |
| R-09 | 签署进度 = 已签 / 应签 | 签署 | 实时更新 | 端上 |
| R-10 | 全员已签才可导出行程单 | 导出 | 部分未签 → 提示并对未签标红 | — |
| R-11 | 未签提醒 3 天 / 1 天 | 定时 | 短信 + 站内 | 端上 |
| R-12 | 签到进度来自现场扫码 | 扫码 | 实时 | 端上 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 全部已签仍点催收 | 按钮置灰 | — |
| 数据 | 无批次 | **无空态提示**（待补） | — |
| 依赖 | 短信通道失败 | 记录失败并可重发 | — |

### 1.9 通知与消息

| 事件 | 接收人 | 渠道 | 抑制条件 |
|---|---|---|---|
| 未签催收 | 未签家长 / 负责人 | 短信 + 站内 | 每次点击只发未签者 |
| 出行前 3 天 / 1 天 | 全员 | 短信 | 每档一次 |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-07 | 批次 30 人，已签 20 | 点一键催收 | 只对 10 位未签者发短信 | P0 |
| AC-08 | 同上 | 查看签署进度 | 显示 20/30 | P0 |
| AC-09 | 全部已签 | 查看催收按钮 | 置灰不可点 | P1 |
| AC-10 | 扫码签到 5 人 | 查看签到进度 | 显示 5/30 | P1 |
