## 1. 研学基地管理 `study-base.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 维护研学基地（供线路关联），含位置打点与图片 |
| 使用角色 | 文商旅运营专员、运营主管 |
| 入口 | 菜单 → 文商旅管理 → 研学 → 研学基地管理 |
| 前置 | 基地资料线下收取 |
| 后置 | 被 P4 线路引用；端上展示 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 专员录入 |
| 本页操作的跨端影响 | 基地信息 → 端上线路详情中的基地介绍 |
| 依赖的其他端页面 | 买家端线路详情页（基地区块） |
| 不涉及的端 | 商户端 |
| 一致性要求 | **已关联路线的基地不可删除** |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「研学基地管理」+ 新增基地 |
| **统计卡（4）** | 基地总数 / 已关联路线 / 本月接待批次 / 待完善资料 |
| 筛选区 | 关键词 / 分类 / 状态 + 查询 + 重置 |
| 列表 | **8 列** + 分页 |
| 抽屉 | 名称 / 分类 / 位置（**地图打点**）/ 图片 / 简介 / 评分 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 更新时间倒序 |
| 分页 | 页码 |
| 筛选组合 | 条件之间 **且** |
| 分类 | 工业研学 / 文化研学 / 自然研学 / 科技研学 |
| 空结果 | 「暂无基地，请先新增」 |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 基地名称 | `name` | — |
| 分类 | `category` | 四类枚举 |
| 所在位置 | `address` + 经纬度 | 地图打点 |
| 评分 | `rating` | 来自评价聚合 |
| 关联路线 | `routes[]` | **只读**，来自 P4 |
| 状态 | `state` | 启用 / 停用 |
| 更新时间 | `updatedAt` | — |
| 操作 | — | 编辑 / 删除 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新增/编辑 | 始终 | 专员/主管 | 抽屉 | — |
| 地图打点 | 编辑态 | 同上 | 打开地图选点 → 回填经纬度 | — |
| 图片选择 | 编辑态 | 同上 | 上传封面 | — |
| 删除 | 无关联路线 | 专员 | 二次确认后删除 | **有路线 → S-07** |
| 跳路线 | 关联路线 > 0 | 始终 | 跳 P4 筛选该基地 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-13 | 有路线的基地不可删 | 删除 | 提示先解绑 | — |
| R-14 | 位置需经纬度 | 保存 | 地图打点必填 | 端上地图 |
| R-15 | 评分来自评价聚合 | 评价提交 | 端上展示 | 端上 |
| R-16 | 停用后不可被新线路引用 | 停用 | 线路选择器过滤 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 有关联路线删除 | 拦截 | 【已实现】该基地已关联 {n} 条路线，请先解绑后再删除 |
| 数据 | 删除成功 | 提示 | 【已实现】基地已删除 |
| 数据 | 无基地 | **无空态提示**（待补） | — |
| 数据 | 未打点 | 保存拦截 | 【待实现】应提示补位置 |

#### 1.8.1 本页提示语清单（来源：分册 §7.6，编号可回溯）

### 1.9 通知与消息

本页不发通知（基础资料维护类）。

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-11 | 基地关联 3 条路线 | 点删除 | 拦截并提示先解绑 | P0 |
| AC-12 | 新建基地 | 地图打点后保存 | 经纬度回填，端上可见位置 | P0 |
| AC-13 | 基地已停用 | 在 P4 新建线路选基地 | 停用基地不在可选列表 | P1 |
