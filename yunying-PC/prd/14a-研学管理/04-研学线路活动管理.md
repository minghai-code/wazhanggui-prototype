## 1. 研学线路活动管理 `study-route.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 维护研学**线路**与其**场次**（日期 / 名额 / 报名 / 余席 / 候补），上下架同步端上 |
| 使用角色 | 文商旅运营专员（维护）、运营主管（**上下架**） |
| 入口 | 菜单 → 文商旅管理 → 研学 → 研学线路活动管理 |
| 前置 | 已有基地（P3） |
| 后置 | 端上可见线路与可报名场次 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 专员维护 |
| 本页操作的跨端影响 | 上架 → 端上展示可报名；下架 → 端上隐藏（已报名者仍可在「我的研学」查看） |
| 依赖的其他端页面 | 买家端线路列表 / 详情 / 场次选择 / 报名 |
| 不涉及的端 | 商户端 |
| 一致性要求 | 场次余席实时；名额满按钮置灰 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「研学线路活动管理」+ 新增路线 |
| **统计卡（4）** | 在售路线 / 本月场次 / 本月报名人次 / 平均评分 |
| 筛选区 | 关键词 / 分类 / 状态 + 查询 + 重置 |
| **Tab 条（2）** | 线路 / 场次 |
| Tab 线路 | 路线表（**10 列**）+ 分页 |
| Tab 场次 | 场次表（**10 列**）+ 分页 |
| 抽屉 | 路线（名称 / 分类 / 时长 / 人数区间 / 关联基地 / 亮点 / 环节 / 简介） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 路线：排序号升序；场次：日期升序 |
| 分页 | 页码 |
| 筛选组合 | 条件之间 **且** |
| Tab 切换 | 线路 ⇄ 场次（带当前路线上下文） |
| 空结果 | 「暂无线路」/「暂无场次」 |

### 1.5 字段规格

**路线表（10 列）**：路线名称 · 分类标签 · 时长 · 人数区间 · 关联基地 · 评分 · 已开展场次 · 累计参与 · 状态 · 操作

**场次表（10 列）**：场次编号 · 所属路线 · 日期 · 星期 · 名额上限 · 已报名 · **余席** · 状态 · 候补 · 操作

| 关键字段 | 说明 |
|---|---|
| `duration` | 半天 / 一天 / 两天一夜 |
| `headcountRange` | 起–止人数 |
| `bases[]` | 关联基地（多选，来自 P3） |
| `highlights[]` / `sections[]` | 亮点 / 环节（影响端上详情） |
| `remaining` | 余席 = 名额上限 − 有效报名 | 
| `waitlist` | 候补人数（**本期不自动递补**） |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 新增/编辑路线 | 始终 | 专员/主管 | 抽屉 | — |
| **上架 / 下架** | 始终 | **仅主管** | 端上同步展示 / 隐藏 | 专员 → 隐藏 |
| 切换到场次管理 | 路线行 | 专员/主管 | 切 Tab 并带路线 | — |
| 添加亮点 / 环节 | 编辑态 | 同上 | 追加一项 | — |
| 精选 / 隐藏 | 路线 | 专员/主管 | 端上排序控制 | — |
| 场次新增 | 场次 Tab | 专员/主管 | 日期 + 名额上限 | 日期冲突 → 拦截 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-17 | 余席 = 上限 − 有效报名 | 报名/驳回 | 实时重算（**待审核也占位**） | 端上 |
| R-18 | 下架不影响已报名 | 下架 | 端上列表隐藏，「我的研学」仍可查 | 端上 |
| R-19 | 上下架仅主管 | 操作 | 专员按钮隐藏 | — |
| R-20 | 候补不自动递补 | 满员 | 仅记录候补人数 | 端上 |
| R-21 | 同路线同日期不可重复开场次 | 保存 | 拦截 | — |
| R-22 | 关联基地停用不影响已有场次 | 停用 | 仅新线路不可选 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 重复日期场次 | 拦截 | 【待实现】应提示日期冲突 |
| 数据 | 名额上限 < 已报名 | 拦截 | 【待实现】应提示不可低于已报名 |
| 权限 | 专员点上下架 | 按钮隐藏 | — |
| 数据 | 无场次 | **无空态提示**（待补） | — |

### 1.9 通知与消息
