## 1. 研学往期风采 `study-promo.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 配置买家端「研学往期风采」展示内容（图文素材的选取与排序），供招生宣传 |
| 使用角色 | 文商旅运营专员、运营主管 |
| 入口 | 菜单 → 文商旅管理 → 研学 → 研学往期风采 |
| 前置 | 已有已完成的历史研学批次 / 照片 |
| 后置 | 端上「往期风采」区块展示 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 已完成批次（P2）+ 手工上传照片 |
| 本页操作的跨端影响 | 更新展示状态 → 买家端「往期风采」即时同步 |
| 依赖的其他端页面 | 买家端研学页「往期风采」区块 |
| 不涉及的端 | 商户端 |
| 一致性要求 | 端上预览与配置一致；只展示已授权照片 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 标题「研学往期风采」+ 预览买家端 + 更新展示 |
| **统计卡** | **无**（展示配置页） |
| 内容区 | 风采卡片列表（照片 + 标题 + 场次 + 展示开关 + 排序） |
| 右侧 | 手机壳端上预览 |

### 1.4 内容规则

| 项目 | 规则 |
|---|---|
| 素材来源 | 已完成批次照片 / 手工上传 |
| 单条字段 | 照片（必填）/ 标题 / 关联场次 / 展示状态 / 排序 |
| 排序 | 拖拽或填序号，端上按序号展示 |
| 展示开关 | 关闭即端上隐藏，**不删除** |
| 照片授权 | 仅使用已获家长/学校授权的照片（**合规要求**） |

### 1.5 字段规格

| 字段 | 必填 | 说明 |
|---|---|---|
| 照片 | 是 | 建议 4:3，≤2MB |
| 标题 | 否 | 缺省用场次名称 |
| 关联场次 | 否 | 取自 P4 已完成场次 |
| 展示状态 | 是 | 展示 / 隐藏 |
| 排序 | 否 | 数字，越小越靠前 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 预览买家端 | 始终 | 专员/主管 | 打开端上预览页 | — |
| 更新展示 | 有改动 | 专员/主管 | 同步端上 | — |
| 展示 / 隐藏 | 每条 | 专员/主管 | 切换（不删数据） | — |
| 上传照片 | 始终 | 专员/主管 | 上传并生成卡片 | 超规格 → 拦截 |
| 排序 | 始终 | 专员/主管 | 调整顺序 | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-28 | 隐藏不删数据 | 隐藏 | 端上不展示，后台保留 | 端上 |
| R-29 | 保存后需「更新展示」才同步 | 保存 | 避免编辑中被看到 | 端上 |
| R-30 | 照片须已授权 | 上传 | 合规要求（人工确认） | — |
| R-31 | 端上按排序号展示 | 渲染 | 序号相同按上传时间 | 端上 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 照片超规格 | 拦截 | 【待实现】应提示尺寸/大小 |
| 数据 | 无素材 | **无空态提示**（待补） | — |
| 数据 | 未点更新展示 | 端上无变化 | — |
