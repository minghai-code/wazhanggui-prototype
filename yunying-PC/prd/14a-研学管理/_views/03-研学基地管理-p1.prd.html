1. 研学基地管理 study-base.html

1.1 页面说明

项内容
页面目标维护研学基地（供线路关联），含位置打点与图片
使用角色文商旅运营专员、运营主管
入口菜单 → 文商旅管理 → 研学 → 研学基地管理
前置基地资料线下收取
后置被 P4 线路引用；端上展示

1.2 本页端间关系

项内容
本页数据来源专员录入
本页操作的跨端影响基地信息 → 端上线路详情中的基地介绍
依赖的其他端页面买家端线路详情页（基地区块）
不涉及的端商户端
一致性要求已关联路线的基地不可删除

1.3 页面结构

区块内容
顶部标题「研学基地管理」+ 新增基地
统计卡（4）基地总数 / 已关联路线 / 本月接待批次 / 待完善资料
筛选区关键词 / 分类 / 状态 + 查询 + 重置
列表8 列 + 分页
抽屉名称 / 分类 / 位置（地图打点）/ 图片 / 简介 / 评分

1.4 列表、筛选与排序

项目规则
默认排序更新时间倒序
分页页码
