1. 研学线路活动管理 study-route.html

1.1 页面说明

项内容
页面目标维护研学线路与其场次（日期 / 名额 / 报名 / 余席 / 候补），上下架同步端上
使用角色文商旅运营专员（维护）、运营主管（上下架）
入口菜单 → 文商旅管理 → 研学 → 研学线路活动管理
前置已有基地（P3）
后置端上可见线路与可报名场次

1.2 本页端间关系

项内容
本页数据来源专员维护
本页操作的跨端影响上架 → 端上展示可报名；下架 → 端上隐藏（已报名者仍可在「我的研学」查看）
依赖的其他端页面买家端线路列表 / 详情 / 场次选择 / 报名
不涉及的端商户端
一致性要求场次余席实时；名额满按钮置灰

1.3 页面结构

区块内容
顶部标题「研学线路活动管理」+ 新增路线
统计卡（4）在售路线 / 本月场次 / 本月报名人次 / 平均评分
筛选区关键词 / 分类 / 状态 + 查询 + 重置
Tab 条（2）线路 / 场次
Tab 线路路线表（10 列）+ 分页
Tab 场次场次表（10 列）+ 分页
抽屉路线（名称 / 分类 / 时长 / 人数区间 / 关联基地 / 亮点 / 环节 / 简介）

1.4 列表、筛选与排序

项目规则
默认排序路线：排序号升序；场次：日期升序
分页页码
筛选组合条件之间 且
Tab 切换线路 ⇄ 场次（带当前路线上下文）
空结果「暂无线路」/「暂无场次」

1.5 字段规格

路线表（10 列）：路线名称 · 分类标签 · 时长 · 人数区间 · 关联基地 · 评分 · 已开展场次 · 累计参与 · 状态 · 操作

场次表（10 列）：场次编号 · 所属路线 · 日期 · 星期 · 名额上限 · 已报名 · 余席 · 状态 · 候补 · 操作

关键字段说明
duration半天 / 一天 / 两天一夜
headcountRange起–止人数
bases[]关联基地（多选，来自 P3）
highlights[] / sections[]亮点 / 环节（影响端上详情）
remaining余席 = 名额上限 − 有效报名
waitlist候补人数（本期不自动递补）

1.6 交互规则

元素显示条件可点条件点击后禁止表现
新增/编辑路线始终专员/主管抽屉—
上架 / 下架始终仅主管端上同步展示 / 隐藏专员 → 隐藏
切换到场次管理路线行专员/主管切 Tab 并带路线—
添加亮点 / 环节编辑态同上追加一项—
精选 / 隐藏路线专员/主管端上排序控制—
场次新增场次 Tab专员/主管日期 + 名额上限日期冲突 → 拦截

1.7 业务规则与计算口径

编号规则触发处理影响端
R-17余席 = 上限 − 有效报名报名/驳回实时重算（待审核也占位）端上
R-18下架不影响已报名下架端上列表隐藏，「我的研学」仍可查端上
R-19上下架仅主管操作专员按钮隐藏—
R-20候补不自动递补满员仅记录候补人数端上
R-21同路线同日期不可重复开场次保存拦截—
R-22关联基地停用不影响已有场次停用仅新线路不可选—

类型场景系统行为提示文案
