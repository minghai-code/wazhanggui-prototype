0. 模块通用说明（本模块其他页面不再重复）

0.1 这个模块解决什么问题

研学活动靠电话报名、纸质责任书、到场点名：名额超卖、责任书找不到、谁来了没人知道。 本模块把「线路发布 → 报名审核 → 责任书签署 → 现场签到 → 评价」串成一条线，名额与签到以系统为准。

不做：报名靠微信群接龙；安全责任书签完锁抽屉，出事找不到；到场人数靠人工点。

1. 报名审批 study-approve.html

1.1 页面说明

项内容
页面目标集中处理买家端提交的个人报名与团体申请，支持批量审核与名单导出
使用角色文商旅运营专员（普通审核）、运营主管（≥50 人团体终审）
入口菜单 → 文商旅管理 → 研学 → 团体申请审批
前置买家端已提交报名
后置通过 → 生成待签署任务；驳回 → 释放名额并通知

1.2 本页端间关系

项内容
本页数据来源买家端个人报名 / 学校团体申请
本页操作的跨端影响通过 → 端上进「已通过（待签署）」并可签责任书；驳回 → 端上显示驳回
依赖的其他端页面买家端研学报名页、责任书签署页
不涉及的端商户端
一致性要求同手机号 + 同场次幂等；驳回释放名额
