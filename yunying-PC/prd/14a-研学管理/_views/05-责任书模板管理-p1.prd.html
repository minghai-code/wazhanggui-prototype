1. 责任书模板管理 study-letter.html

1.1 页面说明

项内容
页面目标维护安全责任书模板（版本化 + 条款编辑 + 签署记录），供买家端签署使用
使用角色仅文商旅运营主管（专员无此菜单）
入口菜单 → 文商旅管理 → 研学 → 责任书模板管理
前置无
后置启用的模板版本用于新报名签署；旧版本归档保留
安全责任书是事故追责凭证，因此：版本化、停用不删、归档不可编辑、签署记录永久保留。

1.2 本页端间关系

项内容
本页数据来源主管编辑
本页操作的跨端影响启用版本 → 端上签署页展示该版本条款；停用 → 新报名用新版本，已签的仍可查
依赖的其他端页面买家端责任书签署页（手写签名）
不涉及的端商户端
一致性要求签署记录绑定签署时的版本号，模板改版不影响已签记录

1.3 页面结构

区块内容
顶部标题「责任书模板管理」+ 新建模板
统计卡无（模板管理页，指标无意义）
筛选区关键词 / 适用类型 / 启用状态
列表7 列
抽屉模板块（版本 / 适用类型 / 条款列表）；签署记录块（批量催收 + 导出）
