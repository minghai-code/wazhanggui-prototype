## 1. 活动创建 / 编辑 `activity-create.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 四段式录入一场活动：基本信息 → 时间与地点 → 报名设置 → 签到设置 |
| 使用角色 | 运营（平台活动）、商户（申请，仅 3 类） |
| 入口 | 活动列表「创建活动」；或行内「编辑」带 `?id=` |
| 前置 | 已登录；商户仅能编辑自己的待审批前活动 |
| 后置 | 平台活动直接进入「未开始/报名中」并上架；商户活动进入「待审批」 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 运营手工录入；地点可从 02 市场资源只读选择 |
| 本页操作的跨端影响 | 发布/提交后：商户端「活动参与」可见（平台活动立即；商户活动待批后才可见） |
| 依赖的其他端页面 | `shanghu-APP/shanghu-activity-apply.html`（商户申请同一套字段，类型限 3 项） |
| 不涉及的端 | 买家端 |
| 一致性要求 | 发布后 ≤5s 商户端可见；编辑时间后通知全部已报名者 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 返回按钮 + 标题（创建活动 / 编辑活动）+ 副标题（平台自办免审核）+ 右上操作区 |
| **第 1 段 基本信息** | 名称 / 类型 / 主办方（只读）/ 联系人·电话 / 封面 / 一句话简介 / 活动详情 |
| **第 2 段 时间与地点** | 报名开始 / 报名截止 / 活动开始 / 活动结束 + **时间警告条（红）** + 地点类型 + 资源·地址·链接 + 场地备注 + **资源冲突弱提示（橙）** |
| **第 3 段 报名设置** | 总名额 / 是否审核 / 同行上限 / 报名字段（5 个勾选，姓名手机固定）/ 报名须知 |
| **第 4 段 签到设置** | 启用签到 / 签到方式 / 签到窗（前 N 分钟 ~ 后 N 分钟）+ **展示位置说明（固定）** + 提交后会发生什么 |
| 底部 | 取消 / 保存草稿 / 提交并发布 |

### 1.4 列表、筛选与排序

不适用（表单页）。

### 1.5 字段规格

**第 1 段 基本信息**

| 字段 | 标识 | 必填 | 默认 | 校验 | 说明 |
|---|---|---|---|---|---|
| 活动名称 | `f-name` | 是 | — | ≤40 字；**禁绝对化用语**（最/第一/唯一） | 提示文案见 A-09/A-16 |
| 活动类型 | `f-type` | 是 | 请选择 | 7 选 1：展会 / 直采节 / 培训 / 沙龙 / 会议 / 应急演练 / 其他 | 商户仅 3 项 |
| 主办方 | `f-owner` | — | 平台自办（市场运营中心） | **只读** | 商户活动显示商户名 |
| 主办方联系人 / 电话 | `f-contact` / `f-phone` | 否 | — | 电话若填需 11 位 | — |
| 封面图 | `f-cover` | 否 | — | 建议 750×422 | 原型点击仅提示（A-08） |
| 一句话简介 | `f-brief` | 是 | — | ≤60 字 | 展示在列表与详情头部 |
| 活动详情 | `f-detail` | 否 | — | 支持换行 | 议程 / 亮点 / 参与对象 |

**第 2 段 时间与地点**

| 字段 | 标识 | 必填 | 校验 | 说明 |
|---|---|---|---|---|
| 报名开始 | `f-ss` | 是 | date | — |
| 报名截止 | `f-se` | 是 | date，**signEnd ≥ signStart 且 ≤ start** | — |
| 活动开始 | `f-st` | 是 | datetime-local | — |
| 活动结束 | `f-en` | 是 | datetime-local，**> start** | — |
| 地点类型 | `f-ptype` | 是 | 市场资源 / 自定义地址 / 线上 | 切换下方字段显隐 |
| 选择资源 | `f-place` | 条件 | 地点类型=市场资源时必填 | 从 02 只读选 |
| 详细地址 | `f-addr` | 条件 | =自定义地址时必填 | — |
| 线上链接 | `f-link` | 条件 | =线上时必填 | — |
| 场地备注 | `f-pnote` | 否 | — | 如「1F 中庭 + 直播间」 |

**第 3 段 报名设置**

| 字段 | 标识 | 必填 | 默认 | 校验 | 说明 |
|---|---|---|---|---|---|
| 总名额 | `f-quota` | 是 | — | ≥1；**不得小于已报名人数** | 提示 A-14/A-15 |
| 是否需要审核 | `f-audit` | — | 免审核 | 免审核 / 需要审核 | 审核制下先占位、驳回释放 |
| 同行人数上限 | `f-comp` | — | 不允许带人 | 0 / 1 / 2 / 3 / 5 / 10 | 同行按人数占名额 |
| 报名字段 | `f-f1~f-f3` | — | 单位勾选 | 姓名、手机号**固定必填不可取消**；单位 / 职务 / 备注可选 | 勾选即必填 |
| 报名须知 | `f-notice` | 否 | — | — | 与商户端所见一致 |

**第 4 段 签到设置**

| 字段 | 标识 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| 启用签到 | `f-ckon` | — | 启用 | 不启用则不生成签到码 |
| 签到方式 | `f-ckway` | — | 扫码核销 | 扫码 / 手工 / 两者 |
| 签到窗 | `f-cb` / `f-ca` | — | 前 60 / 后 60 分钟 | 窗口外核销拒绝 |
| 展示位置 | — | — | **固定** | 商户端 → 物业服务 → 待办事项 → 活动参与；**无其他投放位** |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 封面图 | 始终 | 始终 | 提示「演示环境：上传后自动裁剪 16:9」 | — |
| 地点类型切换 | 始终 | 始终 | 显示对应字段（资源 / 地址 / 链接），隐藏其余 | — |
| 时间填写 | 始终 | 始终 | 校验不通过 → **红色时间警告条显示**，禁用提交 | — |
| 选择资源 | 地点类型=市场资源 | 始终 | 若该时段已有活动 → **橙色弱提示**（不阻断） | — |
| 保存草稿 | 始终 | 始终 | 保存为草稿，不生成报名入口 | — |
| 提交并发布 | 始终 | 校验通过 | 平台活动直接上架；商户活动提交审批 | 校验不过 → 拦截 |
| 取消 | 始终 | 始终 | 返回列表（未保存丢失需确认） | — |

> **编辑态差异**：报名已开始的活动，**时间 / 名额 / 地点**字段禁用（避免通知全体报名者），见 A-20。

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-08 | 时间链校验 | 输入变化 | `signStart < signEnd ≤ start < end` | 无 |
| R-09 | 名额不得小于已报名 | 保存 | `quota ≥ hold` | 商户端余量 |
| R-10 | 绝对化用语拦截 | 名称输入 | 命中「最/第一/唯一」→ 拦截 | 无 |
| R-11 | 资源冲突只提示不阻断 | 选资源 | 同时段已有活动 → 橙色提示 | 无 |
| R-12 | 平台 vs 商户分野 | 提交 | 平台=直接发布；商户=待审批 | 商户端可见性 |
| R-13 | 草稿不生成报名入口 | 保存草稿 | 商户端不可见 | 商户端 |
| R-14 | 报名中禁改关键字段 | 编辑态 | 时间/名额/地点禁用 | 商户端 |
| R-15 | 重复提交 | 保存/发布 | 按钮 loading 锁 1.5s | 无 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 名称含绝对化用语 | 拦截 | 【已实现】「文案含绝对化用语「{词}」」 |
| 数据 | 时间倒挂 | 警告条 + 禁提交 | 【已实现】「时间不合法：报名截止须早于活动开始，结束须晚于开始」 |
| 数据 | 名额小于已报名 | 拦截 | 【已实现】「名额不得小于已报名人数（当前 {n}）」 |
| 权限 | 商户编辑已提交活动 | 按钮隐藏 | — |
| 并发 | 两人同时编辑同一活动 | 后提交冲突 | 【待实现】原型无并发校验 |
| 网络 | 保存失败 | 保留填写内容 | 【待实现】原型无失败处理 |
