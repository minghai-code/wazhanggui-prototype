1. 活动详情 activity-detail.html

1.1 页面说明

项内容
页面目标单场活动的第一现场：状态、指标、报名与签到概况、正文与日志
使用角色运营专员 / 主管
入口活动列表行内「详情」；审批页「查看活动详情」；必须带 ?id=
前置URL 带有效活动 id
后置全量数据跳报名管理 / 签到台

1.2 本页端间关系

项内容
本页数据来源活动主数据 + 报名单汇总
本页操作的跨端影响无写操作（纯展示 + 跳转）；编辑跳 P2
依赖的其他端页面shanghu-APP/activity-detail.html（商户看到的是同一场，字段更少）
不涉及的端买家端
一致性要求指标与 P4/P5 同源，点进去条数一致

1.3 页面结构

区块内容
面包屑商户活动运营 / 活动详情
头部封面 + 名称 + 编号 / 类型 / 主办方 + 状态标签 + 按状态显隐的操作（去审批 / 报名管理 / 签到台 / 编辑 / 返回列表）
状态提示条待审批 / 已驳回（含原因）/ 已取消 / 已下架 / 草稿，各一条说明
指标卡（按状态切换）见 §1.5
报名漏斗曝光 → 转化率 → 已占位 → 签到率 → 已签到
报名记录（最近 5 条）6 列表格 + 「查看全部报名（N）」
签到记录（最近 5 条）4 列表格 + 「进入签到台（已签/应到）」
报名趋势按报名期动态生成日期
详情正文 + 报名须知与商户端所见一致
右栏当前阶段（状态 / 下一步 / 展示位置）+ 操作日志

1.4 内嵌表规则

项目规则
条数各显示最近 5 条（按时间倒序）
全量底部按钮跳 P4 / P5（带 ?id=）
分页无（内嵌摘要不分页）
空态「还没有报名 / 签到记录」

1.5 字段规格

指标卡（三组，按派生态切换）

状态组卡片
未开始 / 报名中 / 草稿曝光 · 已占位 · 余量 · 报名进度
进行中 / 已结束应到（已通过）· 已签到 · 签到率 · 未签到（结束后为爽约）
已取消 / 已下架报名人数 · 已取消 · 已驳回 · 曝光

报名记录（6 列）：姓名 · 商户 · 同行 · 来源 · 审核 · 提交时间

签到记录（4 列）：姓名 · 商户 · 签到时间 · 方式

头部字段：封面 / 名称 / 活动编号 / 类型 / 主办方 / 状态标签

1.6 交互规则

元素显示条件可点条件点击后
去审批状态=待审批运营跳 P3 ?id=
报名管理全部运营跳 P4 ?id=
签到台状态=进行中运营跳 P5 ?id=
编辑草稿 / 未开始 / 报名中运营跳 P2 ?id=
返回活动列表始终始终跳 P1
查看全部报名（N）有报名始终跳 P4 ?id=
进入签到台有签到数据始终跳 P5 ?id=

1.7 业务规则与计算口径

编号规则触发处理影响端
R-35无 id 或无匹配不回退渲染显示「未指定活动或活动不存在」+ 返回按钮无
R-36指标按状态切换渲染三组互斥无
R-37签到率仅活动开始后计算渲染未开始显示 —，不得显示 0%无
R-38漏斗口径渲染已占位 = 待审核 + 已通过；已取消/已驳回不占名额无
R-39趋势按报名期动态渲染不写死 7 天；取 signStart~signEnd 且 ≤7 天无
R-40内嵌只取最近 5 条渲染排序按时间倒序无
