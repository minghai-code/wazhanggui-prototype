## 1. 报名管理 `activity-signup.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | **跨活动**查看与处理报名：审核、驳回、取消、补录、导出 |
| 使用角色 | 运营专员 / 主管 |
| 入口 | 活动列表行内「报名」；活动详情「报名管理」 |
| 前置 | 已有报名数据 |
| 后置 | 审核结果同步商户端；名额占用/释放实时生效 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 商户端自主报名 + 现场补录 + 批量导入 |
| 本页操作的跨端影响 | 通过 → 商户端「我的报名」状态变更 + 生成签到码；驳回/取消 → **释放名额** |
| 依赖的其他端页面 | `shanghu-APP/activity-signup.html`、`shanghu-APP/my-activities.html` |
| 不涉及的端 | 买家端 |
| 一致性要求 | 审核结果 ≤5s 同步；名额释放即时；手机号脱敏不可绕过 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 返回 + 标题 + 「报名名单」跳转 + 「导出名单」 |
| **筛选区（7 项）** | 活动名称（**可搜索下拉**）/ 关键词 / 审核状态 / 签到状态 / 来源 / 提交时间 / 查询·重置 |
| **摘要条** | 活动数 · 已占位 · 待审核 · 已通过 · 已签到 · 已取消 · 已驳回 · 爽约（随筛选变） |
| 批量操作条 | 批量通过 / 批量驳回 / 取消选择（勾选后出现） |
| 表格 | **勾选 + 11 列** |
| 弹窗 | 批量导入（粘贴 CSV）/ 现场补录 / 驳回（原因）/ 取消报名 / 导出留痕 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 提交时间倒序 |
| 分页 | 不分页（本期单活动报名 < 500） |
| 筛选组合 | 条件之间 **且** |
| 活动下拉 | 可输入关键词过滤；每项显示该活动报名条数；含「全部活动」 |
| 摘要条口径 | 随当前筛选范围计算，不是全库 |
| 空结果 | 「没有符合条件的报名记录 —— 换个筛选条件试试」 |
| 导出 | 当前筛选范围内导出，**脱敏 + 留痕** |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| ☐ | — | 勾选列（无表头文字） |
| 报名编号 | `id` | — |
| 活动名称 | `actName` | 下方小字显示活动编号 |
| 姓名 | `name` | — |
| 手机号 | `phone` | **脱敏 `138****6688`**；查看完整需填原因 + 留痕 |
| 商户 / 岗位 | `org` / `post` | — |
| 同行 | `comp` | 人数（占名额） |
| 来源 | `src` | 商户端 / 现场 / 导入 |
| 审核 | `audit` | 待审核 / 已通过 / 已驳回 / 已取消 |
| 签到 | `ck` | 未签到 / 已签到 / 爽约 |
| 提交时间 | `at` | — |
| 操作 | — | 详情 / 通过 / 驳回 / 取消报名 / 标记签到 |

**补录弹窗**

| 字段 | 必填 | 校验 |
|---|---|---|
| 所属活动 | **是** | 可搜索下拉（补录必须指定活动） |
| 姓名 | 是 | — |
| 手机号 | 是 | 11 位；**同活动内不重复** |
| 商户 / 岗位 | 否 | — |
| 同行人数 | 否 | 0 ~ 活动配置上限 |
| 超名额 | — | 超了需 **confirm 二次确认** 才继续 |

**导入弹窗**

| 项 | 规则 |
|---|---|
| 模板 | CSV 5 列：姓名 / 手机 / 商户 / 岗位 / 同行 |
| 输入 | 粘贴文本，非文件上传 |
| 校验 | 逐行：姓名 + 11 位手机；同活动手机号不重复 |
| 结果 | 「已导入 N 条」，失败行不提示具体（原型简化） |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 批量通过 | 勾选 ≥1 且含待审核 | 运营 | 仅待审核行变已通过，其余忽略 | 未勾选 → 提示 A-29 |
| 批量驳回 | 勾选 ≥1 且含待审核 | 运营 | 弹窗填原因 → 驳回并释放名额 | 同上 |
| 批量导入 | 始终 | 运营 | 弹窗（下载模板 + 粘贴） | — |
| 现场补录 | 始终 | 运营 | 弹窗（必选活动） | 缺姓名/手机 → 拦截 |
| 导出名单 | 始终 | 运营/主管 | 填原因留痕 → 导出 | 当前筛选 0 条 → 拦截 |
| 查看完整手机号 | 有手机号 | 运营 | 填原因 → 显示 + 留痕 | — |
| 行内通过/驳回 | 待审核 | 运营 | 直接处理 | 非待审核 → 不显示 |
| 取消报名 | 非已取消 | 运营 | 确认 → 释放名额 | — |
| 标记签到 | 未签到 | 运营 | 直接置已签到 | 已签到 → 换为撤销入口（在签到页） |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-21 | 只有待审核参与批量 | 批量操作 | 其他状态跳过，不报错 | 商户端 |
| R-22 | 驳回/取消释放名额 | 状态变更 | `hold -= (1+同行)` | 商户端余量 |
| R-23 | 补录手机号同活动唯一 | 保存 | 重复 → 拦截 | — |
| R-24 | 超名额需二次确认 | 补录保存 | `hold > quota` → confirm | 商户端余量 |
| R-25 | 导出必留痕 | 点导出 | 记录操作人/时间/范围 | 审计 |
| R-26 | 手机号默认脱敏 | 渲染 | 列表全部脱敏 | — |
| R-27 | 补录必选活动 | 保存 | 未选 → 拦截 | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 筛选无结果 | 空态 | 【已实现】「没有符合条件的报名记录 —— 换个筛选条件试试」 |
| 数据 | 未勾选就批量 | 拦截 | 【已实现】「请先选择」 |
| 数据 | 补录缺姓名/手机 | 行内拦截 | 【已实现】「请填写姓名与 11 位手机号」 |
| 数据 | 补录手机号重复 | 行内拦截 | 【已实现】「该手机号在本活动已报名，请核对后再补录」 |
| 数据 | 导入未粘贴 | 拦截 | 【已实现】「请先粘贴名单」 |
| 数据 | 导出无数据 | 拦截 | 【已实现】「当前筛选无数据，无法导出」 |
