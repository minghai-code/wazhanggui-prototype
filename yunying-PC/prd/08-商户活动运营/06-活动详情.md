## 1. 活动详情 `activity-detail.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 单场活动的第一现场：状态、指标、报名与签到概况、正文与日志 |
| 使用角色 | 运营专员 / 主管 |
| 入口 | 活动列表行内「详情」；审批页「查看活动详情」；**必须带 `?id=`** |
| 前置 | URL 带有效活动 id |
| 后置 | 全量数据跳报名管理 / 签到台 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 活动主数据 + 报名单汇总 |
| 本页操作的跨端影响 | **无写操作**（纯展示 + 跳转）；编辑跳 P2 |
| 依赖的其他端页面 | `shanghu-APP/activity-detail.html`（商户看到的是同一场，字段更少） |
| 不涉及的端 | 买家端 |
| 一致性要求 | 指标与 P4/P5 同源，点进去条数一致 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 面包屑 | 商户活动运营 / 活动详情 |
| 头部 | 封面 + 名称 + 编号 / 类型 / 主办方 + 状态标签 + **按状态显隐的操作**（去审批 / 报名管理 / 签到台 / 编辑 / 返回列表） |
| **状态提示条** | 待审批 / 已驳回（含原因）/ 已取消 / 已下架 / 草稿，各一条说明 |
| **指标卡（按状态切换）** | 见 §1.5 |
| **报名漏斗** | 曝光 → 转化率 → 已占位 → 签到率 → 已签到 |
| **报名记录（最近 5 条）** | 6 列表格 + 「查看全部报名（N）」 |
| **签到记录（最近 5 条）** | 4 列表格 + 「进入签到台（已签/应到）」 |
| 报名趋势 | 按报名期动态生成日期 |
| 详情正文 + 报名须知 | 与商户端所见一致 |
| 右栏 | 当前阶段（状态 / 下一步 / 展示位置）+ 操作日志 |

### 1.4 内嵌表规则

| 项目 | 规则 |
|---|---|
| 条数 | 各显示**最近 5 条**（按时间倒序） |
| 全量 | 底部按钮跳 P4 / P5（带 `?id=`） |
| 分页 | 无（内嵌摘要不分页） |
| 空态 | 「还没有报名 / 签到记录」 |

### 1.5 字段规格

**指标卡（三组，按派生态切换）**

| 状态组 | 卡片 |
|---|---|
| 未开始 / 报名中 / 草稿 | 曝光 · 已占位 · 余量 · 报名进度 |
| 进行中 / 已结束 | 应到（已通过）· 已签到 · 签到率 · 未签到（结束后为爽约） |
| 已取消 / 已下架 | 报名人数 · 已取消 · 已驳回 · 曝光 |

**报名记录（6 列）**：姓名 · 商户 · 同行 · 来源 · 审核 · 提交时间

**签到记录（4 列）**：姓名 · 商户 · 签到时间 · 方式

**头部字段**：封面 / 名称 / 活动编号 / 类型 / 主办方 / 状态标签

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 |
|---|---|---|---|
| 去审批 | 状态=待审批 | 运营 | 跳 P3 `?id=` |
| 报名管理 | 全部 | 运营 | 跳 P4 `?id=` |
| 签到台 | 状态=进行中 | 运营 | 跳 P5 `?id=` |
| 编辑 | 草稿 / 未开始 / 报名中 | 运营 | 跳 P2 `?id=` |
| 返回活动列表 | 始终 | 始终 | 跳 P1 |
| 查看全部报名（N） | 有报名 | 始终 | 跳 P4 `?id=` |
| 进入签到台 | 有签到数据 | 始终 | 跳 P5 `?id=` |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-35 | **无 id 或无匹配不回退** | 渲染 | 显示「未指定活动或活动不存在」+ 返回按钮 | 无 |
| R-36 | 指标按状态切换 | 渲染 | 三组互斥 | 无 |
| R-37 | **签到率仅活动开始后计算** | 渲染 | 未开始显示 `—`，**不得显示 0%** | 无 |
| R-38 | 漏斗口径 | 渲染 | 已占位 = 待审核 + 已通过；已取消/已驳回**不占名额** | 无 |
| R-39 | 趋势按报名期动态 | 渲染 | 不写死 7 天；取 `signStart~signEnd` 且 ≤7 天 | 无 |
| R-40 | 内嵌只取最近 5 条 | 渲染 | 排序按时间倒序 | 无 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | URL 无 id | 整页替换为提示 | 【已实现】「未指定活动或活动不存在」 |
| 数据 | id 不存在 | 同上 | 【已实现】同上 |
| 数据 | 无报名 / 无签到 | 内嵌表空态 | 【待实现】原型无独立空态 |
| 数据 | 签到率在活动前 | 显示 `—` | 【已实现】 |

#### 1.8.1 本页提示语清单（来源：分册 §8.6，编号可回溯）

| 编号 | 场景 | 提示文案 | 形式 | 状态 |
|---|---|---|---|---|
| A-54 | 无 id / 活动不存在 | 未指定活动或活动不存在 | 整页提示 + 返回按钮 | ✅ |

> 本页为纯展示页，无表单与写操作，故提示语仅 1 条。

### 1.9 通知与消息

本页不发通知（通知由 P1/P4/P5 触发）。

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-29 | 直接访问 `activity-detail.html`（无 id） | 打开 | 显示「未指定活动或活动不存在」+ 返回按钮，**不展示任何活动** | P0 |
| AC-30 | 活动未开始 | 看指标卡 | 显示曝光/已占位/余量/进度，**签到率为 `—` 而非 0%** | P0 |
| AC-31 | 活动已结束 | 看指标卡 | 切换为 应到/已签到/签到率/爽约 | P1 |
| AC-32 | 有 12 条报名 | 查看报名记录 | 只显示最近 5 条，按钮显示「查看全部报名（12）」 | P1 |
| AC-33 | 点「查看全部报名」 | 跳转 | P4 且已按该活动筛选 | P1 |
