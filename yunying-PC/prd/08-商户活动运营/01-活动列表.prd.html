0. 模块通用说明（本模块其他页面不再重复）

0.1 这个模块解决什么问题

商户培训、沙龙、消防演练这类活动靠微信群接龙 + Excel 记名字，名额经常超、签到靠纸质点名、商户自己办的活动没人管。 本模块把「发布 → 审批 → 报名 → 签到 → 统计」收到一个入口，名额与签到状态以系统为准。 不做：活动就只能继续用微信群，事后说不清谁到过、办了几场、商户活动该不该批。

1. 活动列表 activity.html

1.1 页面说明

项内容
页面目标一屏看清"有哪些活动、什么状态、报名到哪了"，并承载全部单条操作
使用角色运营专员（常规操作）、运营主管（多"取消"）
入口菜单 → 商户活动运营 → 活动列表
前置已登录且有本模块权限
后置本页是操作起点；下钻进详情 / 报名 / 签到

1.2 本页端间关系

项内容
本页数据来源运营创建 + 商户申请（待审批）
本页操作的跨端影响上架 → 商户端「活动参与」出现；下架/取消 → 立即消失或标已取消；改期 → 通知已报名者
依赖的其他端页面shanghu-APP/activity-list.html、shanghu-APP/activity-detail.html
不涉及的端买家端（全面不涉及）
一致性要求状态/余量 ≤5s 同步商户端；取消即时生效

1.3 页面结构

区块内容
顶部标题「商户活动运营」+ 说明行 + 「活动审批」（带红点数字，跳 P3） + 「创建活动」
统计卡（4）进行中 / 报名中 / 待审批 / 已结束（按派生态计数，带图标与色）
筛选区关键词（活动编号 / 名称）+ 类型 + 状态（10 态）+ 主办方（平台 / 商户）+ 查询 + 重置

表格9 列

1.4 列表、筛选与排序

项目规则
