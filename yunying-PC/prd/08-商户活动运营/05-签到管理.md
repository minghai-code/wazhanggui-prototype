## 1. 签到管理 `activity-checkin.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 现场核销 + 签到记录管理（手工补签、撤销、爽约） |
| 使用角色 | 运营专员 / 主管 |
| 入口 | 活动列表行内「签到」；活动详情「签到台」 |
| 前置 | 活动处于进行中（签到窗内） |
| 后置 | 签到状态回写报名单，签到率与爽约进统计 |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 报名单（已通过）+ 现场核销 |
| 本页操作的跨端影响 | 核销 → 商户端「我的报名」显示已签到 + 时间；撤销 → 回到未签到 |
| 依赖的其他端页面 | `shanghu-APP/shanghu-activity-checkin.html`（商户自己主办的活动）、`my-activities.html`（签到码） |
| 不涉及的端 | 买家端 |
| 一致性要求 | 核销即时（≤2s）；**重复核销幂等**，返回首次时间 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 面包屑（活动名）+ 标题 + 「报名名单」「导出签到表」 |
| **筛选区（6 项）** | 活动名称（**可搜索下拉**，显示核销中/未开始/已关闭）/ 签到状态 / 签到方式 / 签到时间 / 关键词 / 查询·重置 |
| **核销台（2/3 宽）** | 标题 + 当前活动名 + **演示码提示** + 输入框（6 位 / 扫码）+ 核销按钮 + **结果区** |
| **签到进度（1/3 宽）** | 已签到 / 应到 / 签到率（范围随筛选变） |
| 表格 | **10 列** |
| 行操作 | 手工核销 / 标记爽约 / 撤销核销 / 改回未签到 |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| 默认排序 | 签到时间倒序（未签到按提交时间） |
| 分页 | 不分页 |
| 筛选组合 | 条件之间 **且** |
| 活动下拉 | 可搜索；每项显示人数与状态（核销中 / 未开始 / 已关闭） |
| 进度口径 | 选中活动 → 本场签到率；全部活动 → 全局签到率 |
| 空结果 | 「没有符合条件的签到记录」 |
| 导出 | 当前筛选范围导出 |

### 1.5 字段规格

| 列 | 字段 | 说明 |
|---|---|---|
| 活动名称 | `actName` | 下方小字活动编号 |
| 姓名 | `name` | — |
| 商户 / 岗位 | `org` / `post` | — |
| 手机号 | `phone` | 脱敏 |
| 同行 | `comp` | `+N` 或 `—` |
| 签到码 | `code` | 6 位，等宽字体 |
| 签到时间 | `ckAt` | 未签到 `—` |
| 方式 | `way` | 扫码 / 手工（不同底色） |
| 状态 | `ck` | 未签到 / 已签到 / 爽约 |
| 操作 | — | 按状态显隐 |

**核销结果区（5 类反馈，不是 Toast）**

| 类型 | 标题 | 说明 |
|---|---|---|
| 成功（绿） | 签到成功 | `{姓名}　{单位}（同行 +N）` |
| 警告（黄） | 已签到 | `「{姓名}」已于 {时间} 签到，不重复记录` |
| 失败（红） | 请先选择活动 | 核销必须指定一场活动 |
| 失败（红） | 签到未开始 / 签到窗已关闭 | 附窗口时间说明 |
| 失败（红） | 签到码格式不对 | 请输入 6 位数字码 |
| 失败（红） | 无效签到码 | 该码不存在，请核对后重试 |
| 失败（红） | 活动不匹配 | 该码属于「{活动}」，请切换活动 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| 核销 | 始终 | 已选活动 + 窗口内 | 校验 6 位 → 查码 → 判活动 → 判重复 → 置已签到 | 五类失败见 §1.5 |
| 扫码 / 输码 | 始终 | 始终 | 回车即核销 | — |
| 手工核销 | 状态=未签到 | 运营 | 直接置已签到 + 记录方式=手工 | — |
| 标记爽约 | 状态=未签到 | 运营 | 置爽约 | 活动未结束也可标（人工判断） |
| 撤销核销 | 状态=已签到 | 运营 | 二次确认 → 回未签到 | 原型**未要求填原因**（见 A-53） |
| 改回未签到 | 状态=爽约 | 运营 | 回未签到 | — |
| 导出签到表 | 始终 | 运营/主管 | 当前筛选导出 | 0 条 → 拦截 |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-28 | 核销必须有活动上下文 | 渲染 | 未选活动 → 结果区提示 | — |
| R-29 | 窗口外拒绝核销 | 核销 | `now` 不在 `[start-N, end+N]` → 拒绝 | — |
| R-30 | 签到码 6 位数字 | 输入 | 非 6 位 → 格式错 | — |
| R-31 | 码必须属于当前活动 | 核销 | 不匹配 → 拒绝并提示应切到哪场 | — |
| R-32 | **幂等**：已签到不重复记 | 核销 | 返回首次签到时间，不改数据 | 商户端不变 |
| R-33 | 撤销核销记方式 | 撤销 | 回到未签到，清空 ckAt/way | 商户端 |
| R-34 | 签到率活动开始后才算 | 渲染 | 未开始显示 `—` | 详情/看板 |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 未选活动就核销 | 结果区红 | 【已实现】「请先选择活动」/「核销必须指定一场活动」 |
| 数据 | 窗口未开 / 已关 | 结果区红 | 【已实现】「签到未开始」/「签到窗已关闭」 |
| 数据 | 输入非 6 位 | 结果区红 | 【已实现】「签到码格式不对」/「请输入 6 位数字码」 |
| 数据 | 码不存在 | 结果区红 | 【已实现】「无效签到码」/「该码不存在，请核对后重试」 |
| 数据 | 码属于其他活动 | 结果区红 | 【已实现】「活动不匹配」/「该码属于「{活动}」，请切换活动」 |
| 重复 | 同一码再核销 | 结果区黄 | 【已实现】「已签到」/「{姓名}」已于 {时间} 签到，不重复记录 |
| 数据 | 筛选无结果 | 空态 | 【已实现】「没有符合条件的签到记录」 |
| 数据 | 无数据导出 | 拦截 | 【已实现】「当前筛选无数据，无法导出」 |
