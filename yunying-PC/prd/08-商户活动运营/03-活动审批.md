## 1. 活动审批 `activity-approve.html`

### 1.1 页面说明

| 项 | 内容 |
|---|---|
| 页面目标 | 商户提交的活动在这里审核：左边队列、右边预览、底部决策 |
| 使用角色 | 运营专员 / 主管 |
| 入口 | 活动列表顶部「活动审批」（红点=待审数）；或列表行内「审批」带 `?id=` |
| 前置 | 存在待审批活动 |
| 后置 | 通过 → 上架并在商户端可见；驳回 → 通知商户改后重提（编号不变） |

### 1.2 本页端间关系

| 项 | 内容 |
|---|---|
| 本页数据来源 | 商户端 `shanghu-activity-apply.html` 提交的申请 |
| 本页操作的跨端影响 | **通过** → 商户端「活动参与」立即出现；**驳回** → 商户端显示驳回原因且可改后重提 |
| 依赖的其他端页面 | `shanghu-APP/shanghu-activity-manage.html`（商户看状态与原因） |
| 不涉及的端 | 买家端 |
| 一致性要求 | 审批结果 ≤5s 同步商户端；驳回原因必填且商户可见 |

### 1.3 页面结构

| 区块 | 内容 |
|---|---|
| 顶部 | 返回 + 标题「活动审批」+ 说明（商户活动需审核；平台自办免审） |
| **左侧队列（340px）** | **Tab（待审批 / 已通过 / 已驳回）** + 卡片列表（活动名 / 商户 / 提交时间 / 名额） |
| **右侧预览** | 基本信息 + 详情正文 + 地点 + 报名设置 + **系统预检清单** |
| 底部操作 | 「驳回」「通过并上架」（在预览区或弹窗） |
| 弹窗 | 驳回（原因枚举 + 说明必填） |

### 1.4 列表、筛选与排序

| 项目 | 规则 |
|---|---|
| Tab | 待审批（默认）/ 已通过 / 已驳回，Tab 上带条数 |
| 排序 | 提交时间倒序（最早提交在上，先到先审） |
| 分页 | 不分页（队列滚动） |
| 空态 | 每个 Tab 各自空态（见 A-24） |

### 1.5 字段规格

**队列卡片**

| 字段 | 说明 |
|---|---|
| 活动名称 | 加粗 |
| 类型 | 标签 |
| 商户 | 提交方名称 |
| 提交时间 | `2026-10-15 10:20` |
| 名额 | 人数 |
| 版本 | `ver`（重提 +1，用于识别改过几次） |

**右侧预览**

| 分区 | 内容 |
|---|---|
| 基本信息 | 名称 / 类型 / 商户 / 联系人电话 / 简介 / 详情正文 |
| 时间与地点 | 报名起止 + 活动起止 + 地点 |
| 报名设置 | 名额 / 是否审核 / 同行上限 / 报名字段 |
| **系统预检** | 4 项，逐项 ✅/⚠️：时间合法、名额合理、地点与联系人已填、无绝对化用语 |

**驳回弹窗**

| 字段 | 必填 | 可选值 |
|---|---|---|
| 驳回原因（枚举） | 是 | 内容不合规 / 信息不完整 / 时间地点冲突 / 名额设置不合理 / 其他 |
| 具体说明 | **是** | 自由文本，「商户需要知道怎么改」 |

### 1.6 交互规则

| 元素 | 显示条件 | 可点条件 | 点击后 | 禁止表现 |
|---|---|---|---|---|
| Tab 切换 | 始终 | 始终 | 切队列，右侧预览清空或保持 | — |
| 队列卡片 | 始终 | 始终 | 右侧加载该活动预览 | — |
| 通过并上架 | 选中待审批 | 运营 | 二次确认 → 状态置已通过 + 上架 | 预检有 ⚠️ 仍允许（人工判断） |
| 驳回 | 选中待审批 | 运营 | 弹窗（枚举 + 说明）→ 确认 | 说明为空 → 拦截 |
| 查看活动详情 | 选中任一 | 始终 | 跳 P6 `?id=` | — |

### 1.7 业务规则与计算口径

| 编号 | 规则 | 触发 | 处理 | 影响端 |
|---|---|---|---|---|
| R-16 | 通过即上架 | 点通过 | `audit=已通过` + `online=上架` + 按时间定位 life | 商户端立即可见 |
| R-17 | 驳回原因 + 说明双必填 | 点驳回 | 任一为空 → 拦截 | 商户端可改后重提 |
| R-18 | 重提编号不变、版本 +1 | 商户重提 | `ver++`，`id` 不变 | 本页显示版本号 |
| R-19 | 预检只提示不阻断 | 渲染 | ⚠️ 项黄标，运营仍可通过 | — |
| R-20 | 平台活动不进队列 | 渲染 | 只列 `owner=商户` | — |

### 1.8 异常与边界

| 类型 | 场景 | 系统行为 | 提示文案 |
|---|---|---|---|
| 数据 | 待审批为空 | 空态 | 【待实现】原型无独立空态文案 |
| 权限 | 商户访问本页 | 菜单不可见 | — |
| 并发 | 两人同时审同一活动 | 后提交提示已被处理 | 【待实现】原型无并发校验 |
| 数据 | 预览活动已被删除 | 提示不存在 | 【待实现】 |

#### 1.8.1 本页提示语清单（来源：分册 §8.6，编号可回溯）

| 编号 | 场景 | 提示文案 | 形式 | 状态 |
|---|---|---|---|---|
| A-21 | 通过成功 | 已通过：「{活动名}」，已上架并通知商户 | Toast | ✅ |
| A-22 | 驳回未填说明 | 请填写具体说明，商户需要知道怎么改 | 行内 | ✅ |
| A-23 | 驳回成功 | 已驳回并通知商户（{原因}） | Toast | ✅ |
| A-24 | 无待审批（空态） | 暂无{tab}活动（如「暂无待审批活动」） | 空态 | ✅ |

### 1.9 通知与消息

| 事件 | 接收人 | 渠道 | 抑制条件 |
|---|---|---|---|
| 审批通过 | 提交商户 | 站内 + 短信 | — |
| 审批驳回 | 提交商户 | 站内 + 短信（含原因） | — |

### 1.10 验收标准

| 编号 | 前置 | 操作 | 预期 | 级别 |
|---|---|---|---|---|
| AC-13 | 存在待审批活动 | 点「通过并上架」 | 状态已通过 + 上架，商户端活动参与出现 | P0 |
| AC-14 | 同上 | 点「驳回」不填说明 | 拦截，说明必填 | P0 |
| AC-15 | 已被驳回的活动 | 商户改后重提 | 队列里编号不变、版本 +1 | P1 |
| AC-16 | 预检有 ⚠️（名额偏少） | 点通过 | 允许通过（不阻断） | P1 |
