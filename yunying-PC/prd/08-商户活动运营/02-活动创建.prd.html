1. 活动创建 / 编辑 activity-create.html

1.1 页面说明

项内容
页面目标四段式录入一场活动：基本信息 → 时间与地点 → 报名设置 → 签到设置
使用角色运营（平台活动）、商户（申请，仅 3 类）
入口活动列表「创建活动」；或行内「编辑」带 ?id=
前置已登录；商户仅能编辑自己的待审批前活动
后置平台活动直接进入「未开始/报名中」并上架；商户活动进入「待审批」

1.2 本页端间关系

项内容
本页数据来源运营手工录入；地点可从 02 市场资源只读选择
本页操作的跨端影响发布/提交后：商户端「活动参与」可见（平台活动立即；商户活动待批后才可见）
依赖的其他端页面shanghu-APP/shanghu-activity-apply.html（商户申请同一套字段，类型限 3 项）
不涉及的端买家端
一致性要求发布后 ≤5s 商户端可见；编辑时间后通知全部已报名者

1.3 页面结构

区块内容
顶部返回按钮 + 标题（创建活动 / 编辑活动）+ 副标题（平台自办免审核）+ 右上操作区
第 1 段 基本信息名称 / 类型 / 主办方（只读）/ 联系人·电话 / 封面 / 一句话简介 / 活动详情
第 2 段 时间与地点报名开始 / 报名截止 / 活动开始 / 活动结束 + 时间警告条（红） + 地点类型 + 资源·地址·链接 + 场地备注 + 资源冲突弱提示（橙）
第 3 段 报名设置总名额 / 是否审核 / 同行上限 / 报名字段（5 个勾选，姓名手机固定）/ 报名须知
第 4 段 签到设置启用签到 / 签到方式 / 签到窗（前 N 分钟 ~ 后 N 分钟）+ 展示位置说明（固定） + 提交后会发生什么
底部取消 / 保存草稿 / 提交并发布

1.4 列表、筛选与排序

不适用（表单页）。

1.5 字段规格

第 1 段 基本信息

字段标识必填默认校验说明
活动名称f-name是—≤40 字；禁绝对化用语（最/第一/唯一）提示文案见 A-09/A-16
活动类型f-type是请选择7 选 1：展会 / 直采节 / 培训 / 沙龙 / 会议 / 应急演练 / 其他商户仅 3 项
主办方f-owner—平台自办（市场运营中心）只读商户活动显示商户名
主办方联系人 / 电话f-contact / f-phone否—电话若填需 11 位—
封面图f-cover否—建议 750×422原型点击仅提示（A-08）
一句话简介f-brief是—≤60 字展示在列表与详情头部
活动详情f-detail否—支持换行议程 / 亮点 / 参与对象

第 2 段 时间与地点

字段标识必填校验说明
报名开始f-ss是date—
报名截止f-se是date，signEnd ≥ signStart 且 ≤ start—
活动开始f-st是datetime-local—
活动结束f-en是datetime-local，> start—
地点类型f-ptype是市场资源 / 自定义地址 / 线上切换下方字段显隐
选择资源f-place条件地点类型=市场资源时必填从 02 只读选
详细地址f-addr条件=自定义地址时必填—
线上链接f-link条件=线上时必填—
场地备注f-pnote否—如「1F 中庭 + 直播间」

第 3 段 报名设置

字段标识必填默认校验说明
总名额f-quota是—≥1；不得小于已报名人数提示 A-14/A-15
是否需要审核f-audit—免审核免审核 / 需要审核审核制下先占位、驳回释放
同行人数上限f-comp—不允许带人0 / 1 / 2 / 3 / 5 / 10同行按人数占名额
报名字段f-f1~f-f3—单位勾选姓名、手机号固定必填不可取消；单位 / 职务 / 备注可选勾选即必填
报名须知f-notice否——与商户端所见一致

第 4 段 签到设置

字段标识必填默认说明
启用签到f-ckon—启用不启用则不生成签到码
签到方式f-ckway—扫码核销扫码 / 手工 / 两者
签到窗f-cb / f-ca—前 60 / 后 60 分钟窗口外核销拒绝
展示位置——固定商户端 → 物业服务 → 待办事项 → 活动参与；无其他投放位

1.6 交互规则

元素显示条件可点条件点击后禁止表现
封面图始终始终提示「演示环境：上传后自动裁剪 16:9」—
地点类型切换始终始终显示对应字段（资源 / 地址 / 链接），隐藏其余—
时间填写始终始终校验不通过 → 红色时间警告条显示，禁用提交—
选择资源地点类型=市场资源始终若该时段已有活动 → 橙色弱提示（不阻断）—
保存草稿始终始终保存为草稿，不生成报名入口—
提交并发布始终校验通过平台活动直接上架；商户活动提交审批校验不过 → 拦截
取消始终始终返回列表（未保存丢失需确认）—
编辑态差异：报名已开始的活动，时间 / 名额 / 地点字段禁用（避免通知全体报名者），见 A-20。
